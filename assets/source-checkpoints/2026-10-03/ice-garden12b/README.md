# 氷の庭 — 接触12b / 未採用の表示試作

11cの主結晶・床・配置はそのまま保護し、接触する短い動作だけを変更した保存点です。ゲームコードへの採用は行っていません。

左右の細い翼を、閉じた厚い氷片3つへ変更しました。大きい片が先に割れ、低い反対片が遅れて出ます。主片は約70ms、反対片は約85msで出切り、155msから回転して落ちます。460msで退場します。確認済み接点に残り、動く敵を追いかけません。同時に描くのは最新接触の3片だけです。これは表示の仮値で、ダメージ・CC・ボス耐性は変更していません。

`preview/viewer.html`をブラウザーで開くと、11c→12の通常速度比較、12単独、11段階の静止画、近距離・斜め・明暗、32コマの手動送りを見られます。比較は各0.8秒の接触窓を続けて表示します。制作環境の空きメモリが約0.9GBだったため、640×360、低優先度の単一レンダーに限定しました。

## 確認したこと

- 技術テスト8件PASS。11c公開431ファイルとZIP、今回コピーした基礎コード・既存モデルをハッシュ/バイトで照合。
- 新接触モデル3閉立体・116面。インストール済みMinecraft 26.2の実パーサーで座標・UVを確認。新規ダウンロードやゲーム起動なし。
- 接触前・接触なし・退場後の画面は11cと同じ。最新接触だけに制限、範囲外拒否、穴に床描画しない、剛体変形、固定接点、頂点の間と落下を確認。
- 標準視点32コマをすべて実見。頭・胴の遮蔽0、脚の見える量は最小99.2%。これはこの視点・軌道での結果です。
- 既存EdgeでGIF2本の通常再生、閲覧ボタン7つ、コマ送り8箇所を確認。専用ブラウザーは終了済み。負荷下のスクリーンショット取得に遅れがあるため、ブラウザーの取得時刻を演出の正確な体感時間や実機FPSの証明に使いません。

## まだ合格にしていないこと

方向の非対称性と厚みは11cより読めますが、断面の細部と接点から押し出される強さは引き続きFIX-FIRSTです。主結晶・床の再制作は今回の範囲外です。MatE品質、実機の手触り、音、Minecraftの描画・FPS、自由視点、ゲーム側の敵死亡/再接続/ボス挙動を今回の表示試作で合格とはしていません。

公式Glacial Breakerの0.52–0.98秒、24フレームを実見し、低い青い塊→太い部分と細い先端の斜め展開→落ち着く形を参照しました。モデルビューアーの映像であり、敵への実ヒットや破片の物理挙動を示す映像ではありません。公式素材の原本は納品とGit保存候補から除外しています。
