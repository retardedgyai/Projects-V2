ProjectS cloth30 / 顔口・首・胸の構造を繋ぎ直した別モデル

Blockbenchでは cloth-structure-30/model/model.bbmodel を開いてください。
編集用の実メッシュと3枚のPNGが埋め込まれています。OBJ/MTLも同じmodelフォルダにあります。
原本、承認済みの塗り、25/27/29のモデルは変更していません。30は別の制作ソースです。

主な変更
・フードの顔口に薄い実際の折り返しを作り、頬の前角と側面を繋ぎました。
・首布をフードから繋ぎ、胸の前合わせと縦の折れを実メッシュで作りました。
・肩布の落ち方を左右で変え、前面の大きな扇状の三角面を縦の折れへ整理しました。
・腰・脚の明るい矩形を縦の布の面へ整理し、頭・襟・胸・腰の見え方を合わせました。
・肩布の厚みは0.055、顔口は0.05、頬前角は0.04、胸は0.06モデル単位です。
静止した低polyの実メッシュです。画像の切り抜き板やcloth simulationを使っていません。

実表示と検証
Blockbench5.2.1で29/30を実際に読み込み、同じカメラ・照明・画面範囲で18枚撮影しました。
正面・背面・斜め・側面、上半身と全身、斜めの通常照明/無照明比較を含みます。
無照明切替は Canvas.updateShading() で実際に反映し、画素が変化したことを検証しています。
preview64は実撮影の全身範囲を高さ64pxにnearest縮小した画像です。
4倍拡大はその同じ64pxの画素をnearest拡大したものです。ゲームrendererの出力ではありません。

身体、金具、腰ベルト、29のブーツのgeometry/UVは保持しています。

GUI負荷について
データ編集、モデル生成、UV/干渉/原本保護の検査はすべてBlockbenchなしで行いました。
実表示QAだけ専用portable版を短時間使い、撮影後に自分のプロセスを終了しました。
CDPのウィンドウ制御はこの版で未対応でした。Windowsで自分のウィンドウを最小化し、
同じカメラ/照明の全身背面を取得して通常表示とのRGBA差0を確認しています。
最小化してもElectronの実rendererとメモリは使います。完全headlessで同等とは未検証です。
現在の安全な運用はGUIなし編集・数値検証と、最後の必要な実表示を最小化して短く行うことです。
他タスクのBlockbenchや未保存の窓は操作していません。

制作状態
品質作業を継続するための保存点です。MatE同等の完成・新しい出自/能力の採用・ゲーム着用完成は
確定していません。技術検査の数字を芸術面の合格として扱っていません。
今回修正した主要問題は頬の三角形の隙間、胸の左右同じUパッチ、肩布前面の扇状の面です。
さらに詰める箇所はフード側面の大きな面と肩布側面の落ち方です。評価待ちを制作停止理由にしません。
首・頭の動的ポーズや現ゲームの装備renderer対応は今回の静止検証に含みません。

編集ソースの再生成
ZIPのフォルダ関係を保ったまま展開してください。Python、Pillow、NumPyがある環境で:
python cloth-structure-30/build30.py
python cloth-structure-30/verify30.py --portable
8個の生成物が配布元とバイト一致することを展開した保存点で確認しています。
Blockbench編集だけならPythonは不要です。
native撮影スクリプトは今回のWindows実行環境と既存portable版を使うQAソースです。
アプリ、profile、認証情報、参考作品原本、大きな動画は同梱していません。
