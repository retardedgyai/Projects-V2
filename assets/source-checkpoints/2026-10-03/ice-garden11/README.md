# 氷の庭 11 — 主結晶群を主役にする短い試作

10を保護した独立した造形試作。MatE相当の品質、ゲームの完成、実機の手触りの合格を意味しません。本編・他技・main・既存Library10は変更していません。

主柱・副柱・細い針を同じ根元へ接続し、根元の濃青から先端の淡色へ向かう材質を新作しました。広い淡色の床枝を細い暗青の補助経路へ変更。形成は根元→主柱→副柱→針、保持は静止、接触は確認された足元に短い実体と光、終了は主柱から沈下します。

`preview/viewer.html`をブラウザで開くと、4秒の10→11比較、11単独、終了比較、同条件の静止画、全125フレームのスクラブを確認できます。動画はCPUの確認用描画です。石床・カメラ・解像度・敵の経路を揃えました。黒背景への差し替えや画面への描き足しはありません。

最初の右群は範囲外の敵を遮ったため、11aを`checkpoints/11a-tall-right`へ保管し、右群の高さと位置を修正しました。接触は厚くしつつ足元に開口を設けています。横帯が強かった材質の11bも`checkpoints/11b-banded-material`へ保管し、11cでは軸方向に長く伸びる不揃いな明暗へ修正しました。

既存Minecraft26.2のパーサーで3モデル654面の読込、回転・UVを確認。16個の閉じた実体、同じ根元との包囲箱の重なり、静止保持、支持セルと穴、接触の局所性・寿命、複数接触の表示上限、終了、10の738ファイルとZIPの不変を自動確認しています。実際の結晶同士の面交差の完全な証明、ゲームのネットワーク・CC・ボス耐性・FPS・音との同期はこの造形試作では確認していません。

主要コードは`author11.py`（造形・軸方向の材質）、`scene11.py`（形成・保持・接触・終了）、`field_math11.py`（床と局所反応）。検証結果は`asset-validation.json`・`static-evidence.json`・`render-evidence.json`・`test-result.txt`。再生成はPython、NumPy、Pillowが既にある環境で`review11.py --clip`。モデル再読込の`run_native_probe.py`は既存26.2/JDKが必要で、ゲーム起動やダウンロードはしません。

参照は[MatE公式Cryomancer](https://mcmodels.net/vi/products/17407/mates-rpg-classes-cryomancer)の保存済み公開GIFと[Rali Sketch27 Ice](https://realtimevfx.com/t/rali-sketch-27-ice/10494)の実見資料。高さの序列、青から淡い先端への方向性、素早い展開と静かな保持を観察し、モデルと材質は独自に作りました。参照原本は同梱しません。指定X投稿はIce Storm503、Lord of Night403、Dark Sister403で直接は閲覧できず、その観察は親の報告と区別しています。

残る品質差は、接触がまだ左右に開く小さな峰に寄り、厚い氷が割れた瞬間の重さと破断方向を十分に表せていない点、近距離では主柱の先端が画面から切れる点です。主柱の材質は横帯を減らしたものの、面同士の映り込み・破断部分の色の関係には改善余地があります。少数の固定配置による確認に留まり、自由移動・戦闘中の視認性は未確認です。これらを完成扱いにせず、次の造形判断に残します。
