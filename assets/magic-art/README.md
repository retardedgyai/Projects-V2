# 魔術の絵（Playground）

魔術の道で使うドット絵の元データ。ゲームのリソースパックにはまだ入れていない。

- `aspects/`：相のアイコン16種（32px）
  - 基本の6相（Aer・Aqua・Ignis・Terra・Ordo・Perditio）は真鍮の枠、組み合わせの10相は銀の枠。
  - 記号は枠のど真ん中に、左右対称に置く。光は左上から。
- `items/return_scroll.png`：帰還の巻物（32px）。AION2 の帰還の巻物の形（上に巻き軸、紙が垂れて下の端が丸まる）。`_lean` は少し傾けた版。
- `aspects_preview.png`：16種を並べた確認用の画像。
- `tools/`：描いたスクリプト（Python + Pillow）。

## 描き方の決まり

- UIのアイコンと手に持つアイテムは32pxで、面ごとに明暗を分けた立体の描き方。ワールドのブロックは16px。
- 1つの素材は4〜5色。影から光へ色相をずらす。黒い輪郭線は引かない。
- 光らせるのは1か所だけ（溝・目・宝石・ルーン）。
- 形は左右対称でも、光と影は左上から当てる。
