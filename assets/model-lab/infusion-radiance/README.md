# Original native ritual effect sprites

Four original RGBA pixel images: 32×32 halo, 16×32 column, 16×16 wave and hollow burst. Native custom-model-data tint, light emission 15 and translucent textures. They are visual effects and introduce no inventory materials or currencies.

The game presenter uses center billboard, vertical billboard and an up-facing fixed model on the same bounded local ItemDisplay/lease path. The approved core, supports, trays and Jar assets are unchanged. No Bloom shader, dynamic coloured world light or client extension is included.

Generator: `scripts/build-infusion-radiance-art.py`; integration and preview scope: `docs/development/world-infusion-radiance.md`.
