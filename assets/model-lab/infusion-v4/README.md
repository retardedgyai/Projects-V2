# 浮遊核と支柱：本人の具体的フィードバックに合わせた形状改訂

「浮遊核もっと大きく禍々しく、支柱はもっと鋭くグネグネはダサい」への2モデル限定の改訂。核は大きい複数の石片に分割し、深い貫通空隙・不揃いな尖端・欠けを実形状で作る。単純な箱の拡大ではなく、中心の亀裂と分離した尖った欠片を持つ。一式の正面で主役になる量感を狙う。

支柱は中間の白石／金属の関節と折れ曲がる上腕をなくす。安定した低い足の上から、1方向22.5度の傾斜を持つ石刃が伸び、先へ細くなる。核へ向く支柱4本は表示yawのみを変える。蛇腹や波打つ形は使用しない。

変更モデルは `core` / `support` のみ。中央台・材料台・Jarはv3を直接参照し、6種類の16px材質も元のPNGを一切編集せず共有。旧v3全17ファイルをSHA-256で保護する。新モデルのモデル／item IDは `projects:infusion-v4/...`、参照材質は `projects:infusion-v3/...`。このディレクトリの材質コピーは独立レビュー用で、元画像と同一。

再生成：`scripts/build-infusion-stone-revision.py`（Pillow/NumPy、既存26.2 jarをread-only参照）。前後の全景は正面0°/12°、斜め38°/26°、同じカメラ・照明・縮尺で比較。核と支柱の拡大、変更後単独全景も出す。旧核の設置高2.75、新核2.9（中心装備の空間を残すためのモデルプレビュー配置）。拡大核のworld軸boundsは旧核に対し幅約1.68倍、高さ約2.18倍、奥行約1.18倍。

この案も**モデル先行・ゲームruntimeへ未接続**。旧ゲームの構造判定・表示・霧ロジック・レシピ・経済・保存は変更しない。Jarからの霧、装備、液面は今回の静止画へ未収録。ゲームクライアントの照明と最終描画は未確認。専用一式の採用時には当たり判定、占有、核の焦点、装備高さを合わせる必要がある。

画像生成やTCのdecompileコード、元モデル／元テクスチャのコピーは使用しない。本人評価前に中央台や素材皿の別方向再設計へ拡張しない。
