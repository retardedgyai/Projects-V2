# 浮遊刻印石と専用祭壇一式：材質付き初稿

TC6の実物を見て、厚い斜めの石の核・複数面の刻印・下の対象品を見せる余白を参照したProjectS独自モデルです。原作の形状やテクスチャをコピーしていません。核は段差のある八角形の石と離れた欠片、22.5度の傾き。暗い石・暖かい灰白石・少量の真鍮接点を一式で共有します。

- `core`: 浮遊する石の主役。厚み、刻印、欠け、二つの小さな金属接点。
- `support`: 二ブロック高の専用支柱。上部が核の方向へ傾く。材料を載せる台ではありません。
- `center`: 装備を置く実際の凹みがある中央台。
- `offering`: 脚が細く、浅い受け皿を持つ副素材台。
- `jar`: 同じ石と金属の接点、広い貯蔵部と細い口。液面は将来の別表示で、静止画は空瓶です。

全てネイティブMinecraft JSONと手描き／コードによる16px PNGです。`scripts/build-infusion-stone-kit.py`で再生成し、`scripts/render-world-models.py`が実UV・テクスチャ・ネイティブelement rotationを直接描画します。画像生成は使いません。ソースとZIPに参照写真は含めません。

このモデル一式の構成にはバニラブロックを含めません。ただし、**本稿はモデル先行の比較案であり、現在のゲーム側に接続したモデルではありません**。旧実装のバニラ支柱構造／ヒット判定は次の接続段階で専用配置情報へ合わせる必要があります。単に見た目だけ差し替えて本体へ接続済みとはしません。

ゲームへ採用する際は、中央キット設置で専用中央台・支柱・浮遊核をまとめて所有し、`structureCells`は配置占有情報として扱う案です。ユーザーに銅や石のバニラブロック組立を要求しません。4支柱の向き、装備の高さ、Jarの口、核の受取点、クリック用の不可視当たり判定、清掃・保存の一貫性を同時に変更します。まだ確定ルールではありません。

以前の十字付き箱、v2 A/B灰色案は別の場所に保護されています。本稿の造形・材質は本人の評価待ち。Minecraftクライアントでの透明ソート、照明、FPS、最終見た目は未確認です。
