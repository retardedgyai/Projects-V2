### nativeアイテムからアクションモデルを選択

当初のitem定義は静止モデルだけを参照し、12ポーズは生成されても選択できなかった。
`build_texture_first_sword.py` の `item_definition()` で、既存サーバーと同じ
CustomModelData float0の12〜17を構え、18〜23を放出へ接続した。
0〜11は静止（この原稿には待機ループ未制作）。未設定/負値/24以上も静止へ戻す。

一人称/三人称の左右の手持ちだけがこの分岐を使う。GUI・額縁・ドロップ・頭などは
常に静止モデル。`hand_animation_on_swap=false` は、ポーズ切替を武器の持ち替えとして
毎回振り下ろさないためのnative設定であり、クライアント改造ではない。

テスト10件成功。追加検査は実際に書き出したitem定義を読み、全12ポーズ・境界値・
非手持ちコンテキストの参照先とモデルファイルの存在を確認する。
これはJSON分岐の検証で、Minecraftでの見え方・実際のスキル発動との接続確認ではない。
出力は引き続き `.tools/texture-first-native` のみ。通常RP登録と装備差し替えはしていない。
問題が出たら同ディレクトリのitem定義→float0→対応するmodel JSONの順で確認する。
