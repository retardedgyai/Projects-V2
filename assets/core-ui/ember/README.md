# Ember workbench UI

Native Minecraft menu artwork and typography rework, 2026-09-05.

- Charcoal stone, aged brass fittings, subdued neutral choices and warm selected/execute states.
- A central equipment cradle and enhancement caption replace the large method cards.
- Body: DotGothic16, 16px source / 8 GUI px. Emphasis: Noto Sans JP weight500, 20px / 10GUI px.
- Existing original pixel-relic icon sources remain unchanged; this revision does not generate new images.
- All frame/card/cradle artwork is generated by the existing native `build_core_menu_assets.py` pipeline.

`previews/` contains 13 actual `CoreMenuCanvas.snapshot()` renders and their strict
audit reports. They use the resource-pack bitmaps, measured widths and exact draw
order. They are not screenshots from a live Minecraft session. Vanilla inventory
items, hover, the inventory label and item Tooltips are deliberately not fabricated.

Key previews: [workpiece](previews/forge-weapon.png), [near maximum](previews/forge-near-max.png),
[missing materials](previews/forge-empty.png), [journal](previews/journal.png),
[storage](previews/storage.png).

The equipment art is a category illustration, not a live view of arbitrary item models.
Gameplay, persistence, the in-world greatsword model, HUD and detailed gear Tooltips
remain unchanged. Design and verification notes are in `docs/development/ember-forge-ui-v0.md`.
