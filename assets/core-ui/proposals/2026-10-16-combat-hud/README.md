# 戦闘HUD 2026-10-16（近代MMO × マイクラ）

藍が「良い感じ これで実装」と承認した方向。モックの描画は `scripts/mock_combat_hud_final.py`
（`design_j(job, deco=("classdeco", "xp", "band", "gold"))`）、実装の絵は `scripts/combat_hud_art.py`。

## 形

- ホットバーはバニラと同じ位置・大きさのまま炭色の板と鉄の選択枠に差し替え。技能はキー2〜6のスロットに
  32pxの技能原画を16pxで重ねる（アイテムと同じ密度）。CD中は暗転＋秒数、資源不足は青み、未解放は錠。
- その上に職業資源の20マス、さらに上に HP の板｜Lvの菱形｜MP の板。HP/MPの数字はゲージの中。
  HPの後ろに吸収（障壁）をバニラの金で、さらに直前の被ダメージの淡い帯。
- Lvの菱形：職業別の翼と冠（戦士＝鋼の刃・剣先、レンジャー＝枝と葉・枝角、メイジ＝氷の結晶・青銅に炎の宝石、
  アサシン＝黒鉄の鎌刃・鉤角、テンプラー＝金縁の鋼・十字、ヒーラー＝白金の羽根・光輪）、菱形を横切る銘板に
  金のLv数字、菱形の縁が経験値ゲージ（クラス色が上から時計回り、24段）。
- バフは板の左上に小さな札（アイコン＋秒数）。通知は action bar の文字行にバニラのフォントで。
- ボスバーは炭色の板＋赤い宝石＋名前（バニラのフォント）＋右に残り％＋220pxのゲージ（4分割の目盛り）。
- 数字はすべてマイクラ標準フォント（バニラの ascii.png を参照、白＋バニラの影）。

## 参考にした実物と藍の判定（抜粋）

- Wynncraft 2.0 / Rekindled World：数字は全部マイクラ標準フォント、HP/MP＋中央Lv＋帯＋ホットバーを一体化 → 配置の元。
- Monumenta の Njol's HUD：吸収をバニラの金で後ろに足す、バニラの部品の延長 → 色と数字の扱い。
- Minecraft Dungeons（公式UI・Java移植パック）：炭色の階段角の板・柔らかい縁 → 板の描き方。
- AION2・Lost Ark・黒い砂漠：中央の主役に両脇のゲージがつながる構成。
- NG：PSO2風、近未来風、高精細化、飾りの足しすぎ、独自の太字数字とMaruMinya、手描きの職業紋章（真ん中は妥協してLvに）。
  詳しい一覧は司令塔の共有ノート combat-hud-ok-ng.md。

## 2026-10-17 左右対称の修正

藍の指摘「真ん中の装飾、明らかに左右対称じゃない部分がある」。Lvの菱形の上の冠が、6職業のうち戦士・テンプラー・ヒーラーで
形が1pxずつ右にずれ、残りも左が明るく右が暗い塗りだった。冠は翼と同じく左半分を描いて中央の列で鏡写しにする作りに変えた
（`combat_hud_art.crown_pixels`、モックもこれを使う）。あわせて MP ゲージが HP より 1px 中央寄り・1px 長かったのを
HP と鏡写しの位置（x 25、幅 54）に直した。前後の比較は `emblem-symmetry-fix-8x.png`。
