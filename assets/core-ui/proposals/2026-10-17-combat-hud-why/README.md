# C6〜C8「今までで一番いいけど何かが違う」の正体を探す見本 — 2026-10-17

コンセプトは「近代MMO（AION2・Lost Ark・黒い砂漠）× Minecraft」。C8 を基準に、**1枚につき1か所だけ**変えた。
どれが一番「近代MMOに近づいた」と感じるかで、違和感の正体を決める。作り込みは方向が決まってから。

- `why-sheet.png`：画面全体（2倍）を4枚並べたもの
- `why-closeups.png`：下のHUD部分の拡大（4倍）を4枚並べたもの
- `why-<base|silhouette|material|gauge>-2x.png`：1枚ずつ
- 描画：`scripts/mock_combat_hud_why.py`（C8 の描画 `design_c6(crisp=True)` を元にしている）

全4枚共通で、C8 のあとに決まった規則だけは入れてある：数字はマイクラ標準フォント、日本語はバニラと同じ描き方
（独自の太字数字と MaruMinya はNGだったため）。判断待ちの D-07（職業色の枠飾り）・D-08（HP/MPの数字）・
D-09（色の割り当て）・D-15（戦闘キューの文字）には触れていない（数字の位置・色・通知の文言は C8 のまま）。

## 仮説

| | 近代MMOでは | C8 では | 見本で変えたこと |
|---|---|---|---|
| 1 箱が多い | 下中央のHUDが**ひとつの形**（両端がすぼまる・中央が盛り上がる）。ボス名・バフ・通知は板なしで浮いている | 同じ重さの四角い箱が6つ（ボス・通知・バフ×2・HP・MP・帯・ホットバー）。マイクラのインベントリ画面の部品を並べた見え方 | HP/MP・帯・ホットバーを1枚の石板にまとめ、上の両端を斜めに切る。ボス・バフ・通知の板を外す |
| 2 素材が冷たい | 地はほぼ黒で模様がなく、縁は**金・青銅の細い線**、中央の飾りだけ金属感が強い | 磨かれたブラックストーンの模様＋灰色の鉄。全体が中間の灰色で、枠と中身の明るさが近い | 配置はそのまま。地を無地のほぼ黒に、縁と中央のLv飾り・選択枠を金に |
| 3 ゲージが細い | HP/MPゲージが画面で**一番目立つ**（太く、光沢と明るい先端がある） | ゲージは4pxの線で、上の「HP 132/240」の文字のほうが目立つ | 配置と素材はそのまま。ゲージを7pxにし、上に光・下を濃く・先端を白く光らせる |

参考の近代MMOのスクリーンショットはrepoに入れていない（著作物のため）。比較は各ゲームの通常の戦闘HUDの
構成についての知識による。

## 経緯との関係

この後の E2（太いゲージの中に数字）・F1・J（実装済み）は、仮説3と「数字のフォント」を部分的に試した流れにあたる。
どれが当たりかで、J に何を足すか（形をまとめる／素材を変える／ゲージを主役にする）が決まる。

## J に当てはめた版（2026-10-17 追記）

藍「これもう少し作り込めないかな」を受けて、承認済みの J（実装済み）に上の3つを1つずつ当てた見本。
`jplus-sheet.png`（画面全体）・`jplus-closeups.png`（HUD部分）・`jplus-<j|shape|trim|gloss>-2x.png`。
描画は `scripts/mock_combat_hud_j_plus.py`（`design_j` の板・ゲージを描く関数を1つだけ差し替え）。

- 形をまとめる：HP/MP・帯・ホットバーを1枚の炭色の板に、上の両端を斜めに。バフとボスは板なし
- 金の縁取り：全部の板の内側に細い金の線、選択枠も金
- ゲージに光沢：上の光・下の影・明るい先端（太さは J と同じ 9px）。先端の白線が数字に重なる所は作り込みで直す
