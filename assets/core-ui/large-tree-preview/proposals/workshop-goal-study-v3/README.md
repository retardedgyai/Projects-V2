## 目標から組んだ4領域

- g26受け流し：小さな角。攻撃速度の入口から混合Notableへ届く。GUARDのない現在の戦士でも手数は使え、受け流し専用枝は入力不足のまま。
- g37貫通：上は貫通を先に拾い、下は物理を積んで回る。二つのNotableの先に任意のKey04を置き、Keyを通常育成の通過点にしない。
- g25会心：倍率へ短く届く腕と、確率を積んで回る長い腕。同じ半径・セルへの複製ではない。
- g48弱点：二つの混合Notableと異なる入口。WEAKPOINTのない現在の戦士は会心の道を使い、弱点専用枝を強制通過しない。帰路にも弱点側から合流する選択を置いた。

同じ48pt・同じ戦士support/plain/standard・所有済み吸収MODの条件で、会心と弱点の3Notableへ20pt（残28）、貫通の2Notableと静かな刃へ16pt（残32）。既存5配分はV2と同じ費用・ポイント・恩恵を保持する。

Key04の原効果は「会心が発生しなくなる／直接ヒット22%乗算増」。この試作で再現するのは会心・倍率の無効化と投資の選択で、22%の実戦乗算は未実装。会心に振った後にKey04を取ると、取得ポイント・接続を保持し、会心の恩恵だけが消える。解除すると戻り、保存・復元でも維持する。配分の適格性を持っている入力から判定し、Keyによる恩恵消失と分けた。

表示される会心+129%などは元の仮パッシブ値の合計で、実戦会心確率129%やDPSを表す値ではない。係数・上限・装備基礎値との合成は未検証。出血源を作らず、Key03は取得不可を維持する。

## 一枚へつなぐ全体設計

`full-tree-plan.json`は全47領域・5職業の入口・全15Keyの目的と入力・領域間の隣接意図を保持する。詳細17領域と、位置／目的のみ予約した30領域を区別。地域に属する元IDとその他の元IDを合わせて645点を重複なくカバーする。残り448点の詳細配置は未完。

西は装甲・生命から会心または貫通へ、北は仲間への障壁・MP運用・属性へ、東は会心・手数から範囲・弱点へ、南は資源と裂傷の境界へ配置する。レンジャーの入口近くにもg32会心を残し、西の会心圏への横断を強制しない。魔術のない職業も一般の物理・防御・資源へ通れるよう、属性や術式を必須の通過点にしない。

図の青灰文字は予約名称で、架空の細部ノードや未確認の配線を描いていない。47領域の隣接関係は一つにつながり、5職業とも共有領域への入口を持つ。予約された領域間の詳細線・全体の左右釣合い・全職業の最終取得費用は引き続き制作する範囲。
