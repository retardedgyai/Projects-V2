# V13制作時に実見した参照

- [PoE2実ゲームのパッシブ画面](https://www.youtube.com/watch?v=ylivrbkPgEY)：動画サービスが提供する静止フレーム hq2.jpg / hq3.jpg を実見。パッシブ画面と右側装備画面が並び、未取得の線は暗く、取得済み経路だけ金色、ノードの絵は金属枠の内側にある。動画の再生・正確な時刻は未確認。480×360の静止画なので精密なテクスチャ評価には用いない。大文字の見出しが覆うカスタムサムネイルはUI構成の参照に不採用。
- [GGG公式 Stormweaver図](https://www.pathofexile.com/forum/view-thread/3592012) / [元画像](https://web.poecdn.com/public/news/2024-12-04/Stormweaver.png)：3840×2160静止画を実見。暗い地に金属の大小枠、明るい経路、絵のあるノード、見出しと本文の分離を採用。これは公式発表用の図で、実ゲーム操作画面とは区別する。人物画・装飾画を複製せず、効果の技能付与もProjectSへ転用しない。
- [PoE2公式Steam掲載の実ゲーム Temple Console画面](https://store.steampowered.com/app/2694490/Path_of_Exile_2/) / [元画像](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/2694490/c0d1566648358ceff13c63c98addbe832a9e066d/ss_c0d1566648358ceff13c63c98addbe832a9e066d.1920x1080.jpg)：1920×1080静止画を実見。暗い鉄・石、真鍮の縁、選択箇所の明暗、画面中央の操作対象を優先する階層を確認。パッシブ/Atlas画面と誤認しない。
- 本人のPolish05工房：`assets/ui/polish05-import/reference/ProjectS_UI_Polish05_Workbench.html` を1440×920で実描画して実見（外部原URLなし）。炭色の面、落ち着いた真鍮色、細い継ぎ目、32pxのピクセル絵、選択結果の右パネル、金色の主操作を採用。承認済みのV12埋込日本語フォント・元spriteはそのまま保持。

PoE2公式WebツリーはJavaScriptが必要、wikiは取得結果がチャレンジページで、実画面の参照に数えない。第三者ゲーム画面は私的参照にのみ保持し、制作物やGitへ埋め込まない。
