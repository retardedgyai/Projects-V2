保存済みV7を保持した、実データ付きの次候補。789点・62領域・947接続。承認済みの中央60点とそれに触れる接続、字体、絵柄を維持した。元の645点の原データは変更せず埋め込み、表示用の修正と入力補正を別の候補データに記録している。既存点で位置を動かしたのは血の代価の終端1点だけ。防具混合・artifactシリーズ・任意の装備MODから能力源を増やさない。

## 修正と、選ぶと変わる体験

| 対象 | V7の問題 | V8の候補 |
| --- | --- | --- |
| 血の代価 | 20pt例で11点がMP・効率・再生の抑制により完全無効になる | MP環を保持し、HP・資源を含む一般経路へ終端を移動。新規経路30pt・完全無効0点。短縮とは扱わず、費用と有効な育成内容を比較する |
| 先に所有したMP投資 | Key導入後の保存・接続を壊す危険 | 任意に先に買った点は保持する。費用・接続を残して値を抑制し、Key払い戻しで復帰。自動払い戻しなし。17ptのMP例からKey追加は20pt |
| 術と守り `v7g12` | 共通入口2ptがMP専用。外部入口もMP領域の奥 | 一般経路から有料通路2点で接続。共通入口はHP2・装甲2、障壁枝はSHIELD入力。旧MP6は任意のMP効率枝へ移す。局所4ptの障壁経路にMP投資なし |
| noCrit後の貫通 `v7g04` | 貫通が会心だけの点に接続 | 物理が残る共通目標から任意の貫通へ。会心専用枝は任意。物理・会心の局所3pt比較は保持 |
| 範囲 `v7g10` | 「所有する範囲攻撃」と説明しつつDAMAGEだけで適用 | 実際に所有するAREAタグ・正の半径・AD/AP係数を持つ攻撃からAREA_ATTACKを派生。障壁・回復・GUARD・回避は除外。純範囲点は入力なしで不可、範囲＋物理の混合点は物理だけ有効 |
| 暗殺者の比較 | 53ptの例を48pt例と誤認する可能性 | 旧例は64pt予算の成長例だった。3目標の順序を変えて52pt。同編成で48/64/80ptの2案を比較し、未使用予算も表示。上限の採用は未決 |

新規取得の経路案は、目標Keyを選んだ後に残る恩恵を使って計算する。既得点の保存検証は所有する入力を使う。この区別によって、これから無効点を買わせず、過去に任意購入した点も削除しない。部分的に有効な混合点・職業を跨ぐ投資・任意の吸命終端を維持した。

## 予算上限別の未消費あり例と、同じ消費での比較

技能編成・追加MOD・通路HPを同一にした暗殺者の例。下表は「予算上限別の未消費あり例」であり、80pt例も64pt以内に収まる。80pt固有の解放や、ポイントを使い切った同消費比較を示す表ではない。値は追加パッシブで、最終DPSや最適解ではない。

| 比較予算（未採用） | 手数と範囲 / 使用・残り | 会心と手数 / 使用・残り |
| --- | --- | --- |
| 48pt | 43 / 5 | 46 / 2 |
| 64pt | 49 / 15 | 51 / 13 |
| 80pt | 55 / 25 | 60 / 20 |

同消費比較は別の2例を用意した。双方とも同じ48pt上限で43ptを使用し、残り5pt。手数・範囲側は `g41n3` と `g42n0`、会心側は `g17n0`・有効な会心10の `g17n1`・有効な攻撃速度2の `g10n2` を目標にする。無効点や意味のない点で費用を埋めていない。

| 追加パッシブ値 | 手数と範囲 / 43pt | 会心と攻撃速度 / 43pt |
| --- | --- | --- |
| 攻撃速度 | 25.95 | 7 |
| 技能の範囲 | 13 | 0 |
| 会心率 | 0 | 35 |
| 物理ダメージ | 6 | 0 |
| 資源運用 | 21 | 12 |

共通値はダメージ30・技の回転44・効率3・再生8・魔法防御5。弱点値は入力未実装なので加算しない。同じ費用で選ぶ育成内容の比較で、会心の期待値や最終DPSの優劣を証明しない。

生命の31pt例から12ptを防御へ再投資した43pt案も、旧43pt経路と比較した。追加値の差はHP＋34、装甲＋36、再生＋2、MP＋2、魔法防御−3、資源−22、効率−8。障壁14と受け流し45は回収できる。常に優れるとも、副防御をすべて失うとも扱わない。全ベクトルは `allocation-verification.json` に保存した。
