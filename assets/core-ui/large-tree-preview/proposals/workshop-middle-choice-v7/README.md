# ProjectS — 中間地域に育成の選択を加える V7

承認済み中央と初動を保護し、元の645点へ142点・15地域を追加した単一候補。計787点・62地域・945接続・5起点・15 Key。手持ちの力を育てる小目標と、専門投資を買わずに移動する有料経路を併置した。採用前の操作プレビューで、ゲーム統合は今回の範囲外。

## 保護と追加の理由

元の645点は、座標を含む全フィールドがV6の `f7cf411c275c0cfb3f4d19af0db19b7df9b3df61` と一致する。中央60点とそれらに接する全接続も一致する。元のグラフ、V6ファイル、フォント、絵柄付きスプライトは変更していない。全15 Keyは元の任意の行き止まり。防具series、装備制限、新技能、装備MODそのものは追加しない。

全地域を万能にせず、地域ごとに用途を限定した。HP/装甲/魔法防御、資源運用/回転、MP容量/消費効率などの配分差を作る。魔法、障壁、受け流し、吸命などは既存の手持ち入力がある枝だけ使える。吸命は終端側の任意投資に置き、取得しない場合にも移動を残す。

既存wireを分割して増やした通過点は2か所だけで、どちらも地域/移動の分岐を持つ。初期試作の分岐なしの追加通過点2つは削除した。新Roadは1点を払い、UIで選んだ通路恩恵を持つ。曲がり角だけでは購入点を増やさない。14経路の費用・用途は `middle-choice-authoring.json` に記録した。

## 既存10例の費用変化

同じ技能入力・目標・目標順で比較。表はUI誘導例の費用。大域最小の接続費用は別途 `allocation-verification.json` に計算してある。

| 例 | V6 | V7 | 差 |
| --- | ---: | ---: | ---: |
| 会心 | 47 | 45 | −2 |
| 無会心 | 43 | 41 | −2 |
| 生命・装甲 | 43 | 31 | −12 |
| 障壁 | 21 | 21 | 0 |
| MP | 17 | 17 | 0 |
| 血の代価 | 20 | 20 | 0 |
| 氷 | 25 | 25 | 0 |
| レンジャー | 42 | 42 | 0 |
| アサシン | 52 | 53 | ＋1 |
| 雷 | 26 | 26 | 0 |

生命・装甲の31点はHP/装甲に集中する新しい接続経路による。元の43点経路を、魔法防御・障壁・受け流し・資源運用も拾う比較例としてそのまま残した。短い経路ではこれらの途中効果を失う。V6誘導例43点とV6大域最小39点は区別する。V7の31点は旧最小より8点短い。

会心も新しい西側経路により2点短縮。45点では資源運用0・物理24・攻撃速度9、既存経路47点では資源運用45・物理34・攻撃速度12。共通会心目標を取りつつ、途中の価値へ追加投資するかを比較できる。HPなど他の差も `explicitLegacyComparisons` に全て記録した。アサシンの＋1点は、東の既存wireに追加した有料分岐点による。

## 避ける道と、払う価値

回復地域g33を全て除外した場合、レンジャー/アサシンの目標はV6では到達不能だった。V7では43点/53点で到達する。g33とMP効率地域g12を同時に除外しても47点/53点で、既存48/64点予算内。元の入力にない魔術や吸命を与えて通路を開く処理は加えていない。

吸収地域g13を丸ごと除外した会心/無会心は、V6の54/51点から46/42点へ。所有吸命MODなしの入力でも52/51点から46/42点となり、48点以内へ到達できる。元の専門経路は残し、途中で得る吸収・防御・資源などの効果は迂回側では取得しない。

同費用の局所例では、地域内3点のMP容量側がMP16/効率3、効率側がMP8/効率7。物理側は物理13/会心10、会心側は物理7/会心22。数値はプレビューのstat合計で、実戦DPSの測定値ではない。

「届き方の選択」を通って隣へ抜ける場合は、同じ2つのjunction間で中立経路が追加5点、専門地域を通る範囲/物理経路が7点。2点多く払えば範囲9/物理5または範囲5/物理11を得る。中立経路にはその専門効果がない。全地点を無料の短絡や万能投資に近づけず、不要な能力を買わない道と有用な投資を併置した。

## 実画像と検証

全体と通常ズーム0.20の西・北・東・東南・南西を、1920×1200画面の同じカメラで実ブラウザ撮影。背景を含むCanvasの実画素を使い、木を描き直していない。西の従来の空白帯に「受ける構え」「技能の余地」が入り、東南では攻め時・持ち直す方法・届き方を区別して見られる。外周の既存形と一部の長い接続は維持した。「技を回す」の入口729 worldは、新たな有用分岐を安全に挿入できないため残す。

| 確認 | 結果 |
| --- | --- |
| 元645点の全フィールド/座標、中央60点と接する全接続 | 完全一致 |
| 実8428線分の交差・重複・非接続点への近接 | 全て0、最小距離70.4768 world |
| 60入力プロフィール × 所有吸命有無 | 120条件で到達性PASS |

## 参照から採った設計判断

実PoE2の0.5.1 viewerとデータで、junctionから用途の異なる小投資へ入る例、同じ目標へ異なる途中効果で進む例、専門投資を回避できる有料通路を確認した。データ上のConservative Castingは同3点で回復40/効率15または回復20/効率31。北の障壁地域は専門側6点・属性側4点の局所接続を持つ。この「買う理由」と「買わない道」をProjectSの既存入力へ置き換えた。地域の密度や二入口の数を一律の基準にはしていない。

一次参照：[GGG公開tree exporter](https://github.com/grindinggear/poe2-skilltree-export)、[viewer実装](https://github.com/cvenzin/poe2-skilltree)、[0.5.1データ](https://cvenzin.github.io/poe2-skilltree/trees/0.5.1/data.json)、[実viewer](https://cvenzin.github.io/poe2-skilltree/)。取得データSHA256は `a59429f5fd675e55256fedf5c7ebdae9cce789c75855f8781f4a596d0c42ef21`。取得した0.5.1を研究対象とし、最新ライブ版との一致は主張しない。

## データと再現

`candidate-graph.json` がこの案の配置・接続・効果候補。`middle-choice-authoring.json` は用途と著作判断、`allocation-verification.json` は費用と入力/効果/迂回の検証、`geometry-verification.json` は実線分、`browser-verification.json` は画面/操作、`actual-comparison-captures.json` はカメラと比較画像の検証。`change-impact.json` に画像ハッシュと実見所見をまとめた。

repo根から、既存Python（NumPy/Pillow）とNodeを使う。追加installは行っていない。

```powershell
python scripts/build-skill-tree-middle-choice-v7.py
python scripts/publish-skill-tree-middle-choice-v7.py
python scripts/audit-skill-tree-middle-choice-v7.py
node scripts/verify-skill-tree-middle-choice-v7.cjs
node scripts/capture-skill-tree-middle-choice-v7.cjs
python scripts/compose-skill-tree-middle-choice-v7.py
```

ブラウザ検証/撮影は、専用プロファイルのheadless ChromeのCDP 18126が必要。無関係な既存ブラウザへ接続しない。生のQA PNGは再現可能なローカル証拠としてGit対象外、上記2比較PNGを候補と一緒に保存する。

保存コードは `middle-choice-v7` 専用のプレビュー範囲。元のV6ファイル/保存コードを維持し、V7へ黙って移行しない。習得ポイントのゲーム進行付与、権威的配分/リセット、戦闘効果、native画面、ゲーム永続化・packetはこの候補に未統合。実戦バランスと作者の操作感の最終判断は、プレビューの接続検証からは確定できない。
