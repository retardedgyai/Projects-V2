## 表記と条件の修正点

v7g02/04/07/13の登録上の入口2点は、どちらも同じ外部Roadへ接続する。これは**地域内で同じ目標へ異なる効果を積む選択**。入口2点だけを地域間の別経路とは呼ばない。g04には共通入口Roadへ外の2方向から来られる接続があるが、それも地域内の両腕が違う外部地点をつなぐこととは区別する。

v7g10は共通入口に加えて目標側から別の外部Roadへ抜ける接続を持つ。その地域を通る7点経路と、専門効果を取得しない5点経路を同じ外部2地点で比較できる。二入口を全地域の正解とする根拠にはしない。

「術と守りの投資」v7g12の共通入口はMP容量のみの2点で、両方に `MP_CONSUMER` が必要。魔法/障壁の入力を持っていても、ここでMPへの投資を拒むと枝の目標へ到達できない。MPを使わない仮想入力でも同様。これは現候補の専門地域条件で、全MP投資を回避できるという主張は成立しない。

MP入力を外すことと、MPに関係する全点を購入対象から除くことも異なる。後者は複合効果を持つ既存点も除き、もっと手前の接続まで失う場合がある。3条件の定義と結果をJSONに明示し、既存の60入力プロフィールは変更していない。g33/g12を除外したレンジャー/アサシンの到達検証は、その2地域と2ビルドについての結果だけである。

アサシン例53点は64点予算の例で、48点以内の例ではない。V6から既に64点予算を使用し、旧費用52・旧大域最小51、新大域最小52。比較するなら同じ予算で何を諦めるかを明示する必要がある。全例が48点以内と説明しない。

## 実画像で残る問題

[Northwest.png](Northwest.png) は中央北西→北、[OuterNorth.png](OuterNorth.png) は北外周。1920×1200画面、ズーム0.20でCanvasの実画素を撮影し、両方を実見した。カメラはJSONに記録した。

北西→北は長い斜め/並行通路が空間を占め、小地域が片側へ寄っている。北外周では資源循環→技の回転→雷属性を結ぶ通路が大きい空白面を横切る。長い通路が残ることをPoEらしさとして免責しない。既存のPoE2 viewer実画像は構造参照で、GGGの設計哲学そのものの証拠とは区別する。
