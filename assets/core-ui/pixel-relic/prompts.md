# Built-in image generation prompts

Mode: built-in `image_gen`, new images, not CLI/API. Two independent square
sprite-sheet outputs; no reference images and no external game artwork inserted.

## Shared art brief

Use case: stylized-concept. Asset type: production SPRITE ATLAS of original
Minecraft-friendly fantasy RPG inventory icons. Not UI mockup, not photoreal
painting. Transparent PNG background with real alpha. Strict uniform regular
4-column by 4-row GRID of exactly SIXTEEN sprites; every cell same size; sprites
centered inside their own cell, no overlap or touching. Square canvas. Each icon
is designed as clean hand-placed 32x32 pixel art enlarged by nearest-neighbor:
consistent square pixels, sharp hard-edged pixel clusters, limited palette 6-10
flat shades per icon, no smooth gradients/antialiasing, no painterly microdetail.
Minecraft/Wynncraft-like chunky block-world materials, shaded from upper left.
Readable silhouette at 32x32. Each icon occupies approximately 70 percent of its
cell and leaves transparent padding. No letters, no text, no numbers, no cell
borders, no frames, no floor, no drop shadows on background, no glow, no watermark.
Palette: charcoal ink outline, ivory stone, desaturated teal accent and worn copper;
material-specific browns, greens and iron grey. ALL icons a consistent polished
16-bit pixel art direction. EXACT row-major order:
