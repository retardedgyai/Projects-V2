# 見た目のOK/NG見本帳

見た目（UI・HUD・武器・ボス・置き物）を作るセッションは、作業の前にこのフォルダを読む。
基準は「藍がOKと言った実物」。規則の文章より、ここの画像が優先。

- `ok/` … 藍がOKした実物。これに寄せる。
- `ng/` … 藍がNGと言った実物。同じ失敗を繰り返さない。
- 画像は元のサイズのまま（拡大していない）。GIFはアニメ付き。

## 今の方針（2026-10-15〜16）

1. 方向性は「近未来MMO×マイクラ」。以前のUI規則（ピクセル枠・角丸禁止・M PLUS 2 禁止）は 2026-10-15 に一旦捨てた。藍「UI規則は一旦捨てていい。けど近未来MMO×マイクラは捨てたくない」。
2. ドットの大きさは1画面内で揃える。これだけは残す（部品ごとに倍率が違うと「荒い・雑」に見える）。
3. 見た目を作るときは、実装前に2〜3案を画像で並べて藍に選ばせる。エージェントの自己判定を品質の根拠にしない（自分の感覚で作ったUIは3回とも「ダサい」だった）。
4. 武器の基準＝鎌 v6（`ok/weapon-scythe-tokihami-v6.gif`）。ボス・HUD・UI の基準はまだ無い。OKが出たら `ok/` に追加して埋める。
5. 藍の言葉での指示（「タバコみたい」「AION2の巻物みたいに」）は、元のゲームの実物画像を検索して見てから描く。迷ったら規則を言葉で組むより、好きなリファレンスを1本選んで元のマス目に戻して1マスずつ数える（模写）ほうが効く。
