# Wave 2 Synthesis — Contract Inputs Before Red-Team

## Stable product spine

The two design waves now support one spine:

`arrive at compact port → talk to Coordinator → choose/express a contribution route → produce or purchase missing ordinary inputs → craft/install one repair component → learn charge/brace/stagger on one enemy family → enter one breakwater boss → obtain personal catalyst → craft/install one MOD → report completion`

The slice uses one generated world, one weapon, one enemy family, one boss, one gathered input, one enemy input, one crafted repair item, one currency, one catalyst, and one final MOD choice.

## Stable technical spine

- Server-only Minestom experiment package.
- Vanilla targeted attack and NPC/block interaction events.
- Fixed small layout rather than imported world.
- Pure world, combat, and loop lanes; serial wiring/integration.
- Personal quest/economic state, shared physical world, one encounter.
- Server-owned ledger/profile and item presentation tags.
- Atomic bounded state changes and exactly-once boss reward.
- Pack-declined readability via name, text, geometry, sound, particle, BossBar/ActionBar/Sidebar.

## Decisions still requiring attack

- Keep or delete right-click Brace if Vanilla event reliability is uncertain.
- One route choice with one contribution requirement versus a three-stamp writ.
- Static seeded NPC exchange versus shared stock and refill logic.
- One final MOD or a choice between two/three.
- Physical item rewards versus ledger-only resources.
- World-state repair object versus personal gate state.
- Solo-first only versus 1–4 player reward participation in the first completion milestone.
- How much reconnect reward reservation is necessary for the first slice.

Current Contract remains unfrozen until Red-Team resolves these.
