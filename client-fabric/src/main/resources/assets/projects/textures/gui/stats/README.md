# Stat Icon Set v1

Core stat icons are authored as 16x16 RGBA PNGs with transparent backgrounds.

| File | Stat | Concept |
| --- | --- | --- |
| `health.png` | HP | Heart |
| `mana.png` | Mana | Droplet |
| `attack_power.png` | Attack Power | Sword |
| `magic_power.png` | Magic Power | Four-point spark |
| `attack_speed.png` | Attack Speed | Sword with motion marks |
| `defense.png` | Defense | Shield |
| `level.png` | Level | Chevron rank mark |
| `xp.png` | XP | Progress spark |

All icons share a one-pixel charcoal outline, restrained two-tone color, and no baked background, frame, shadow, glow, text, or numeric value. Use nearest-neighbor sampling for sizes other than the native 16x16 canvas.

`stat_icons_preview.png` is a review sheet, not a runtime asset. It displays every icon at native 16px and 8x nearest-neighbor scale on both a light surface and a dark transparent-glass-like surface.
