# shelves/ — 分野ごとの手本棚

手本の動画・画像は `~/ProjectS/refs/` に置いたまま、ここでは場所を指すだけ。repo には入れない。

## 行の形

[docs/development/harbor-visual-reference.md](../../docs/development/harbor-visual-reference.md) と同じ4つを1行にする。

| 手本（画像か動画の場所） | 何が良いか | どこに持ってくるか | 持ってこない物 |
|---|---|---|---|

- **手本**：`~/ProjectS/refs/...` の場所か URL。動画なら時刻も書く。
- **何が良いか**：**藍の言葉がある物だけ書く。** ない物は空欄にして「藍が書く」と印を付ける。AI の読み取りや作り話で埋めない。
- **どこに持ってくるか**：どの技・画面・物のどの部分に寄せるか。
- **持ってこない物**：その手本から借りてはいけない部分（別の武器の表現、ボスの技、影MODのにじみなど）。
- 1分野3〜5件まで。「候補」はそれより多くてよいが、藍の言葉が付くまで手本にはしない。
