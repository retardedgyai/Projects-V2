# 桜牙獣（ボス）

- **何か**：2体目の Blockbench ボス。ジンオウガ型の骨格、花びらの甲殻、光が肩から尾へ流れるシェーダー、桜の形のエフェクト、技12＋怒り＋協力ギミック＋最後の大技。
- **どこにあるか**：
  - モデルとアニメ：`scripts/build_boss_sakura_fang.py` → `assets/bosses/sakura_fang.bbmodel`
  - 文書：[docs/development/sakura-fang-boss.md](../../docs/development/sakura-fang-boss.md)
  - エフェクト：`SakuraPetalFx`（花びら＋光の帯）、`SakuraStrikeFx`（桜紋・花びらの輪・弧・列・開く花・壁）、`scripts/shaders/item.fsh` の印78・79
  - 色付きの光：`mob/SakuraLight.kt`、`scripts/shaders/post/sakura_light.fsh`
  - main に入っている（PR #169 桜牙獣、PR #183 色付き点光源）。branch `play/gyai/boss-sakura` は merge 済み
  - 見本ページ：https://claude.ai/artifact/Q3ZwzHeYw4XcZsEnsigaLS （v1〜v16）。途中の画像は共有ノート `side-session-notes/.../boss-sakura/`（`sakura_fang_look_v5.png`、`sakura_fang_glow_small.gif`）
- **藍の言葉**：「完璧、かっこいい」（2026-10-19、モデル＋シェーダーの光）。その後「遠吠えと見得はこれでOK」「全体的にOK」（技12）、「花輪の合図でOK」「桜紋の陣はこれでOK」。
- **何が決め手だったか**：
  - 骨格：藍が「ジンオウガ・イナガミの骨格で」と具体的な実物を指し、公式レンダーから比率だけ読んだ（なぞっていない）。
  - 派手さ：全体の彩度を上げた版は「こういうことじゃない」。決め手は**光と部品の作り込み**（花びらの甲殻に光る縁、脇腹と尾の光る筋、光が肩→尾へ流れる）。
  - エフェクト：色だけ桜色にした版は NG。**形を桜（五弁の花紋・花びらの輪・花びらの弧）で作る**ことで通った。
  - 花びら：平たい桃色の粒は「紙切れみたい」。発光と長い光の帯（案 B「花の奔流」）で「華」になった。
  - 動き：「動いて止まるだけ」は NG。止まる時間をなくす重ね動き、大技の締めに見得、大技ごとに専用の動き。
- **再現できると分かっている制約**：
  - モデルは Blockbench（bbmodel）、55骨まで実機で動いた。花びらの甲殻は1枚1骨で開閉。
  - シェーダーは共有の `core/item` 1本（黒翳竜・戦士と同じファイル）に印で分岐。印は alpha 200..215（自己発光と流れ）と tint 青78・79。
  - 花びらは表示用エンティティ1枚＝花びら＋光の帯、上限360、3tickごと送信。パック無しの人には桜の葉の粒。
  - 色付きの光は後処理で最大8灯、影なし。実機で床と柱が桃色に照らされるのを確認済み（2026-10-20）。
- **まだ確かめていないこと**：花びら360体同時の実機の重さ。本編の入口と報酬。
