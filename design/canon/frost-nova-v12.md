# 霜の波紋 第12版（メイジ）

- **何か**：メイジの霜の波紋。走る輪→氷の柱が3周でせり上がる→割れる。凍った敵の体から氷が生える。
- **どこにあるか**：
  - 絵：`scripts/build_mage_frost.py`（PR #189、branch `play/gyai/mage-rework`。**まだ main にない**）
  - 描画：`server-minestom/.../coreloop/CoreMageFrost.kt`（同じ PR）
  - 見本：https://claude.ai/artifact/4C3q1PWvZQhzfeTNFsxJCJ （元は `~/ProjectS/refs/mage-vfx/preview/src_frost.js`、撮影 `s8_frost.png`）
- **藍の言葉**：「氷は一旦これでOK」（2026-10-28、第12版。体から氷が生える凍結を含む）。
  その前の第9版は「何か違う」→房にして尖らせた。
- **何が決め手だったか**：火炎弾と同じ見本ページ・同じ作りで、氷だけを wolf awwent の Goosezilla の作り（白い太縁＋紫の斑点の四角柱を積んで細くする）に寄せたこと。
  「一旦」なので、火炎弾ほど強い OK ではない。詰めるときは第12版を土台にし、作りを替えない。
- **再現できると分かっている制約**：
  - 1ブロック16ドット。柱は段ごとに白い縁一周＋丸い紫の斑点2つ（手本にない模様を足さない）。
  - 表示用エンティティで柱・霜の板・輪を出す。柱は1tickに1段ずつ育つ。
  - 消えるときは割れる（薄くしない）。氷の破片と雪の結晶が飛ぶ。
  - 地面に氷の床は残さない（火と同じ理由）。
- **まだ確かめていないこと**：実機での見え方。
