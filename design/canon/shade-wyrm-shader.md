# 黒翳竜のシェーダー部品と色付きの光

- **何か**：技の見た目をパーティクルでなくシェーダーで描く部品（斬撃・輪・光線・煙・幕、発光・揺らぐ鱗粉・燃える先端・溶ける尾）と、怒りで闘技場が紫になる光、画面の光のにじみ。
- **どこにあるか**：
  - シェーダー：`scripts/shaders/item.fsh`（印：tint 青77＝黒翳竜、緑＝種類1..6。7..9 は戦士の熱斬 `war_slash` の物）、`scripts/build_boss_vfx.py` がパックへ
  - サーバー：`mob/ShadeWyrmShaderFx.kt`（技ごとに表示用エンティティを置き、毎tick進み具合を色で渡す）、`ShadeWyrmLights.kt`
  - にじみ：`scripts/shaders/post/shade_glow_*.fsh`、持ち主は `mob/PlayerPostEffects`（PR #189 でプレイヤーごとに）
  - 色付きの光（桜から始まった部品）：`scripts/shaders/post/sakura_light.fsh`、`mob/SakuraLight.kt`
  - 文書：[docs/development/shade-wyrm-boss.md](../../docs/development/shade-wyrm-boss.md)「紫の光」と改訂履歴。main にある
  - 画像：共有ノート `side-session-notes/.../shade-wyrm-abilities.png`・`.gif`
- **藍の言葉**：「ださい。シェーダーで一回試したい、バニラでできるところまで」（最初の粒の版へ）。実機（2026-10-17）「シェーダーは動いた」＋指摘「翼が飛び出てる／首が顔に重なる／範囲もう少し広く／薙ぎをもっと派手に」。
  怒りの光は藍「怒ったら竜から波動が広がって周りが紫に」。
- **何が決め手だったか**：粒を撒く版が「ださい」で、形を描けるシェーダーに替えたこと。桜牙獣がこの部品を桜色（印79）で借りて「完璧、かっこいい」が出たので、部品として信用できる。
  ただし桜では「色だけ桜色」は NG で、形を桜にした。部品は借りてよいが、形はコンセプトごとに作る。
- **再現できると分かっている制約**：
  - バニラ 26.3 の `core/item` シェーダー差し替え1本で、印の付いたアイテムだけ描く。他はバニラのまま。パック無しの人には見えない（粒に落とす）。
  - 表示用エンティティ1枚＝1部品。進み具合は色で渡す（データ画像 R形・G流れ・B横）。
  - 後処理（`PostEffectsPacket`）は一覧を丸ごと置き換えるので、持ち主を1つにする（`PlayerPostEffects`）。にじみを技のたびに点けたり消したりすると画面全体が一瞬で変わる（`ng.md`「Valorant でフラッシュ」）。
  - 色付きの光は深度から位置を戻して足す後処理、最大8灯、影なし、手も少し照らされる。
  - 闘技場全体の色（紫）は次元型＋時計のタイムラインで、場所ごとには変えられない。
- **まだ確かめていないこと**：シェーダー版の黒翳竜の技の最終形への藍の OK（2026-10-17 の指摘後の直しは実機未確認）。
