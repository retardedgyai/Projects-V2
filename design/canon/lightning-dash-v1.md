# 雷走り 1版目（見た目は OK、走る技でなく撃つ技にする）

- **何か**：稲妻になって見ている先へ8ブロック走り、通り道の敵を感電させる移動の技の見た目。メイジの「雷走り」として作った。藍の言葉は**メイジのまま、遠くへ撃つ（レンジドの）雷の技にする**という意味（体ごと走る技はメイジっぽくない）。職を変える話ではない。2版目で、同じ見た目のままプレイヤーは止まり、杖から雷が地面を走る形にした。
  経緯を知らないエージェントが `design/` の文書だけを読んで1回で作った物（ハーネスの2回目の試し。1回目は竜巻 1版目）。

- **藍の言葉**：「ああいいじゃん、メイジっぽくはないからレンジ系のスキルにしよう　見た目は良い　やっぱりDungeonsは最高や」（2026-11-03）。
- **何が決め手だったか**：Dungeons の Electrified の流れ（走り出しの光 → 地面を這うつながったギザギザ → 細かく割れる → 角ばった煙）と、通った道に残る Tempo Theft の白いギザギザを、落雷 6版目の 16 ドットの描き方と色（水色＋白）で描いたこと。
  メイジっぽくないのは、杖から撃つのでなく体ごと走る技だから。藍「メイジとしてレンジドの雷のスキルをつくろうって話だよ」。
- **作り（再現できると分かっている制約）**：
  - 流れ（発生2tick）：t0〜1 印（杖の先に小さなギザギザ、行き先まで地面に水色の点線、8ブロック先に小さなドットの輪。t1 で画面を一瞬暗く）→ t2 白い1コマ（画面がうっすら水色、1/16 ドットのつながった階段の雷が白で4本走る：体の高さに2本、地面に2本）→ t3〜5 本体 → t5〜 ほどける。
  - 本体：視点が 0 → 2.5 → 6 → 8 ブロックと3tickで進む。雷の先頭は9ブロックまで行き過ぎる（白1本と水色・薄い水色）。横を白と薄い水色の短いドットの筋が流れる。斜め後ろから見ると走っている間は体が消えている。
  - 当たった敵：道から敵の胸へ階段の雷が2tick伸び、短いドットの線が飛ぶ。2tick白、そのあと2秒水色（落雷 6版目と同じ感電、7×5ドットのギザギザ）。道から1.5ブロックより外の敵は何も起きない。
  - ほどける：着いた先の2〜4ブロック前で雷の先が短い切れ端に割れて消える。小さなギザギザが地面を跳ね、草と石のブロックが前へ跳ねて一度弾み沈む。水色 → 灰青の角ばった煙。通った道の白いギザギザは12tickで欠けて消える。焦げは出発点と敵の足元だけ、2秒。
- **まだ確かめていないこと**：2版目（撃つ形）への藍の判定。技の中身（雷走りはメイジの逃げる手段の1つ。撃つ技にすると逃げる手段が突風だけになる。`docs/development/mage-rework.md`）。ゲームの中での見え方。音。
