# 戦士の技の組み立て（獣・8つの技・狂乱・縦振りの軌跡）

- **何か**：戦士＝「獣」を溜めて吐き出す破壊者（ロストアークのデストロイヤー寄り、キャラクターの軸はベルセルクのガッツ）。獣（最大3）、技8つ（轟進・地割り・跳び叩き・狂乱・天落とし・大地崩し・斬り上げ・引き摺り）、奥義3つ。藍と1つずつ決めた。
- **どこにあるか**：PR #184（merge 済み、2026-10-23）。技の表 `CoreSkillCatalog.kt`、動き `CoreWarriorRefChoreography`、演出の表 `combat-art/skill-scenes.psv`。相談の記録は共有ノート `warrior-design.md`、候補のページ https://claude.ai/artifact/WYoTKW8RThc2Gub61MD1RM 。コンセプトの調べ直し（2026-10-27）は https://claude.ai/artifact/2wgaao4sYkKRpw9phKXmq8 。
- **藍の言葉**：
  - 狂乱（踏み込み5連、最後に大振り下ろし）：気に入った範囲技の1つ（2026-10-22）。1周目は「狂乱あんまり角度の違いとかを感じないな　もっと派手さとかがほしい　斬撃を纏ってる感じゃないけど　暴れ回ってる感」（2026-10-22）。2重の軌跡に直した計算プレビューに「狂乱はこれでいい。次へ」（2026-10-23）。OK が出たプレビュー：[img/frenzy-2026-10-23.gif](img/frenzy-2026-10-23.gif)・[img/frenzy-2026-10-23-last.png](img/frenzy-2026-10-23-last.png)、確認ページ https://claude.ai/artifact/7MKKz4HmEBj8sGckxEhrYm 。
  - 縦に振る技の軌跡：「剣が進む縦の面（正面に沿う）に置き、体の前に出す」で藍OK（2026-10-23、commit `036b5662`）。肩を中心に体を貫く置き方は「人から平行」、体の前に正面向きで立てる置き方は「横」。
  - 地割りの獣の使い方（0〜3で長く深く）：藍OK（2026-10-23）。
  - 引き摺り：「剣の位置とアニメーションが気になるが悪くない」。
  - 気づき：「CC技を積んでもCCを連打できない（強いCCは獣を使う技にあり、獣は最大3つ）のがこの構成の良い所」。
- **何が決め手だったか**：コンセプト（何者になる遊びか）を先に藍と決め、技は「溜める技」「使う技」「奥義」の順に藍が選んだ。技ごとの差は体の動き（踏み込む・跳ぶ・引きずる）と当たりのリズム、結果の出る場所で付けた。
- **再現できると分かっている制約**：
  - 技は通常攻撃でできること（斬撃1回など）にしない。移動技はテレポートにせず軌道を描く（跳び叩き）。守りだけの技は持たない。
  - 狂乱は振りごとに面の違う軌跡を2重で太く、だんだん大きく、0.25秒ごと（commit `55fa146a`）。
  - 演出の順は「原因→結果」：大剣の黒い軌跡→刃が届いた所の破裂→地面（commit `24825c55`）。結果だけ置くと「剣をふってるんじゃなくて…えぐれてる…意味がわからない」。
- **正典ではない物（同じ戦士でも）**：当たり炎の絵（`ng.md`）。2026-10-27 の溜める技3つ（刻み打ち・百刃・暴れ歩き）は「斬撃の作りがひどすぎる」で破棄。2026-10-28 の体当たり・押し払い・切っ先薙ぎの世界側の見た目は「ぶつ切り」で外した。
- **まだ確かめていないこと**：実機での手触り（PR #184 の時点で未確認。OK は計算プレビュー `preview_warrior_cast.py` に対して）。体の動き（人形モーション）。奥義の最終決定。
