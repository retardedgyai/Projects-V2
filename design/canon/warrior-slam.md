# 地割りの見た目（戦士）

- **何か**：戦士の「地割り」の見た目。光と呼び出しを使わず、重さだけで見せる。大剣の振りに暗い風圧の帯、叩いた所から前へ細くなる「えぐれた溝」が4tickで伸び、両側で土の板がめくれ上がり、塊が跳ね、低い土煙。めくれる板と跳ぶ塊は、自分で描いた絵ではなく**その場の地面のブロックそのもの**（草地なら草、石畳なら石、砂なら砂。サーバーが足元のブロックを読む。commit `f89beb18`）。
- **どこにあるか**：[docs/development/class-cd-rework.md](../../docs/development/class-cd-rework.md) 3.13（2026-10-20、決定）。絵とモデル `scripts/build_warrior_ref_vfx.py`、動き `CoreWarriorRefChoreography`。確かめ方は `python3 scripts/preview_warrior_cast.py --ids slam --grass`。main にある。正典の見本（地面のブロック版、獣2、PR #184 の時点の計算プレビュー）：[img/slam-2026-10-23-blocks.gif](img/slam-2026-10-23-blocks.gif)・[img/slam-2026-10-23-blocks-hit.png](img/slam-2026-10-23-blocks-hit.png)。記録として、最初に OK が出た版（2026-10-20、自分で描いた草付きの板）：[img/slam-2026-10-20.gif](img/slam-2026-10-20.gif)・[img/slam-2026-10-20-high.png](img/slam-2026-10-20-high.png)、確認ページ https://claude.ai/artifact/C48ZJLr4SAuuPqU4gcyHJX （1つ前の版が全部並んでいる）。
- **藍の言葉**：「ベルセルクのガッツみたいな雰囲気」「地割りはこれでいい」（2026-10-20、計算プレビューに対して）。その後、実機を短く触って「とりあえず地割れはいい感じだった、スタン+モブが上にはねあがるみたいな感じにしようかな？」（2026-10-20）。OK の後に足した「その場の地面のブロックがめくれる」版について「新しい方でいいよ」（2026-10-30）。
- **何が決め手だったか**：光・閃光・呼び出し物を全部やめて、重さ（溝・めくれる土・跳ねる塊）だけにしたこと。途中で試してやめた物：閃光（銃の表現）、斬撃の帯、Outer Gods の花びら・巨神の指（「気持ち悪い」）、ブラウムの岩の列、石の岩。
- **再現できると分かっている制約**：
  - 表示用エンティティの板とモデル。板はカメラを向く設定（`CoreCombatMeshPart.billboard`）。
  - 大きさ・間隔・角度・形はばらばらにし、叩いた所ほど大きい（整いすぎは「AI SLOP 感」の元）。
  - めくれる板と塊の絵は、その場の地面のブロックを使う（絵を描き足さない）。
  - 獣0〜3で溝が長く深くなる（`warrior-skills.md`）。
- **まだ確かめていないこと**：実機の録画はない（2026-10-20 の実機は視点が動かない不具合で短く終わった）。地面のブロック版と打ち上げは、計算プレビューでしか見ていない。
