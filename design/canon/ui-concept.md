# UI の決まり

- **何か**：「Minecraft の素材 × 2026 年の MMO の UI」。飾りより文字と余白、平らな面、強調色は1つ、区切りは細い線、ドット絵は整数倍。
- **どこにあるか**：[docs/assets/ui-design-concept.md](../../docs/assets/ui-design-concept.md)（main にある）。
  実装例は Forge（`docs/development/forge-v3-ui.md`）と開拓大陸の地図（`frontier-atlas-v3.md`）。
- **藍の言葉**：2026-10-10、開拓大陸の地図画面の作り直しで合意。言葉そのものは文書に残っていない（**未確認**）。
  2026-10-28 スキルツリーで「Forge と地図を元に見た目を作り直したい、2つに一貫性がない、Forge が好きだが色とりどりで柔らかい雰囲気は残したい」「線などはなめらかでよい、ドットにする部分となめらかにする部分を設計として決めよう」。
- **何が決め手だったか**：Minecraft らしさを飾りでなく素材（ドット絵のアイコン・等倍のブロック）で出し、MMO らしさを情報の層で出す、という分け方。
  2026-10-28 の決まりの案：ドット＝「もの」（札・アイコン・紋章・ピン）、なめらか＝「説明・つながり・状態」（線・光・背景・文字・パネル）。
- **再現できると分かっている制約**：
  - 半透明の絵は使わない（奥の物を消す）。霞や影は絵に焼き込んで不透明で出す。
  - 文字は用意した大きさのページだけ。本文 M PLUS 2（Medium 以上）、数字 DotGothic16、13px 未満は使わない。
  - 作り方：HTML で見本 → ヘッドレス Chrome で動かない部分を絵にする → 位置を測る → ゲームでは文字と動く部品だけ描く。
- **まだ確かめていないこと**：スキルツリー画面（PR #190）がこの決まりに乗った形で藍の OK を得るか。
