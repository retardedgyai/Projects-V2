# 戦士の当たり炎（手描きの平塗り）

- **何か**：戦士の技の共通の命中の炎、4コマ（閃光→炎→冷める→ちぎれて消える）。技ごとに一目で分かる物を手で描く方針の最初の絵。
- **どこにあるか**：`scripts/warrior_vfx_art.py` の `hit_flame`（main にある）。一覧は `python3 scripts/warrior_vfx_art.py` が `.tools/apage/warrior-art.png` に出す。
- **藍の言葉**：絵を描き直す指示は「技ごとに一目で分かる物を手で描くところから直して」（2026-10-20）。
  この絵への OK の言葉そのものは記録に見つからなかった（**未確認**）。PR #191 の `fx-style-kit.md` は「藍の OK が出た作風」の一つに数えている。
- **何が決め手だったか**：手で点を置く平塗り（縁・深い赤・赤・クリーム・白い芯の5色、ノイズも乱数もなし）。黒翳竜・桜牙獣のシェーダー部品、火炎弾 第21版と作風が一致していた。
- **再現できると分かっている制約**：
  - 32×40 ドットの板。色は5段の平塗り、グラデーションもアンチエイリアスもなし。
  - 消え方は「芯が消えて舌がちぎれる」。薄くしない。
  - PR #191 の作風の型では iron の帯にそのまま収まる。
- **まだ確かめていないこと**：藍の OK の言葉。戦士の技の世界側の見た目は 2026-10-28 に「ぶつ切り」で外されたので、この炎だけが残っている物として扱う（`ng.md`）。
