# 木・地形・道と坂・岩・小物の決まり（2026-11-03）

藍（11/03、オープンワールドの試みを見て）「ここめっちゃ気になるな」（館の丘へ上る坂）。「配置されてる木とかのクオリティが低すぎて酷いことにもなってる　小物とかも全部ちゃんときれいにしよう、多分らーなろっその言及がない部分が酷いことになってる」。

読んだ動画は16本。らーなろっその4本（巨大樹、200mの滝と地形、道の講座、装飾の講座）と、なりです・soujju・DiddiHD・Broken Orbit・Calven・BlueNerd・たにしらいす・そろんご・SEVEN の解説。各回の記録は `~/ProjectS/refs/build/learn2/<id>/notes.md` で、寄りの切り出しは同じフォルダの `z-*.jpg`。

## 木

1. **丸い玉から始めない。** 先に芯（幹）と骨（枝）を作り、枝だけで木に見える所まで仕上げてから葉を付ける。（なりです・soujju・Calven）
2. **幹はまっすぐ積まない。** 1〜2段ごとに1マス横へずらし、段差は同じ木の階段・ハーフで埋める。形は「根元が太い → 中ほどが細い → 分かれ目で少し太い」。（Calven）
3. **大木の幹は、細い筋のらせんで作る。** 1〜2マス幅の筋を3〜5本、らせん状に立てて骨組みにし、そこに肉を付ける。外側はトウヒの原木、中はダークオークの板。原木の向きは縦・横・奥を混ぜて、切り口をまだらに出す。（らーなろっそ 巨大樹）
4. **枝は分かれるたびに細くする。** 幅5 → 2と2、2 → 1と1。先は原木 → 階段 → ハーフ → トラップドア、または柵と柵のゲートで終える。枝は1マス太さのジグザグの折れ線で、先を2〜4本に分ける。少し上向きにして、完全な水平にはしない。奥行きの方向にもずらし、同じ平面に並べない。（Broken Orbit・soujju・らーなろっそ）
5. **根は幹と同じ材料の階段・ハーフで這わせる。** 2〜3方向（大木は5〜6本）に、長さ1〜3。大木は根元を幹の外へ3〜6マス広げ、地面では横向きの原木が草の上を這う。（らーなろっそ・Calven）
6. **葉は玉にも箱にもしない。** 枝先の上に、厚さ2〜3の平たい板（レンズ形）を高さを変えて何段も乗せる。下面はほぼ平ら。板の内側に空気の穴を残し、一番上の段は葉数個の点で終える。（らーなろっそ・Calven・soujju）
7. **葉は2〜4種類の濃淡で塗る。** 下面と内側は暗い葉、中はオークの葉、上は明るい葉（ツツジ）。暗い葉と明るい葉の数はおよそ1対2。別の色を1割ほど足す。（Calven・らーなろっそ）
8. **トウヒは垂れた腕の層を重ねる。** 1層は8方向の腕で、外へ1つ出るたびに1つ下がる45度で垂らす。9層ほど重ね、上の層ほど腕を短くする（下は4〜5、上は1〜2）。層の間に影の隙間を残し、頂点は葉の細い柱にする。（DiddiHD）
9. **小さい木は細い幹（柵1本）に、葉40〜50個。** 葉の大きい段と幹の見える段を交互にする。（Calven）
10. **森の並べ方。** 同じ大木を並べたあとに、小さい木を混ぜて大きさを際立たせる。下草は密に生やす。幹を傾けた木は、葉の重心も同じ向きにする。（らーなろっそ・なりです）

## 地形

11. **段は1マスのまま、真上から見た縁の線をなめらかな等高線にする。** 縁をまっすぐ並べるのは7マスまで。1・2・3・5・7と長さを変えて刻み、同じ形のくり返しは土を足すか抜いて消す。（BlueNerd・soujju）
12. **上の段と下の段で、縁の曲がり方や折れ目をそろえない。** そろうと縦の筋に見える。段の奥行きは1〜8マスでばらつかせ、平らな所は広く取る。斜面は下の段から作る。（BlueNerd）
13. **崖は、丸い頭の縦の柱を束ねた形にする。** 上の縁の輪郭を決めたら、すぐ下に石の柱を地面まで縦に並べる。角は1マス奥へ引っ込め、高さもばらつかせる。角には土を1〜3マス垂らす。足元には石の階段とハーフ、出っ張りの下には逆さの階段を付ける。（soujju・らーなろっそ）
14. **岩山は、大まかな形 → 均す → 石に置き換える、の順で作る。** 草を残すのは平らな所と細い段だけ。（らーなろっそ）
15. **道を通して切った段は、土の断面を見せない。** 石・安山岩・石レンガの土留めで覆い、上の端はブロックとハーフを混ぜて半段ずつ上げ下げする。同じ高さは2つまでしか並べない。（BlueNerd）
16. **材料の切り替わりは、線で区切らずぼかす。** 帯から点へ散らす。水際の1列はポドゾルか粗い土で、奥ほどまばらにし、外側に苔を少し。（BlueNerd・soujju）
17. **水辺と滝。** 水辺は「草 → 土1〜2段 → 石が1マスずつ水へ下がる段々」。滝は滝壺を何段も水路でつなぎ、流れの中に岩を1つ残す。（らーなろっそ）
18. **岩は1個の石を芯にする。** 周りに石の階段・ハーフ・ボタンを付ける。石の塊を散らすだけにしない。（soujju）

## 坂と道

19. **坂を階段の帯にしない。** 「平ら3〜8マス → 高さ1の段 → 平ら」をくり返し、段の位置は等高線に合わせて不規則にする。（そろんご）
20. **段はハーフで半段ずつ上げる。** 段の線は道を真横に切らず、曲がりに沿って1マスずつずれる斜めのギザギザにする。同じ段の中で材料と高さを混ぜ、欠けも残す。（BlueNerd・そろんご）
21. **坂でも縁は途切れさせない。** 道と一緒に段々に上げ、側面の線を見せる。（らーなろっそ・BlueNerd）
22. **道の幅と曲がり。** 村の散歩道は中身3〜4、町は5。枠を付けるなら外に1マス。まっすぐは7マスまでで、1・2・3・5・7とずらして曲げる。（らーなろっそ・そろんご・BlueNerd）
23. **道の材料。** 同じ系統の色を3〜5種混ぜる（主の色が7〜8割、近い色が2〜3割）。汚れ・苔・草は、人が通らない縁から入れる。道の外にも道の材料を1〜2マス飛ばして散らす。（そろんご・BlueNerd）
24. **道の脇。** 茂みと花を左右非対称に置き、背の高い街灯や、使っている跡（樽・コンポスター・小さな畑）を添える。（そろんご）

## 小物

25. **小物は必ず何かの縁に付ける。** 枠の上・柱の脇・窓の前・入口の脇・木の根元など。地面の真ん中にぽつんと置かない。（らーなろっそ・SEVEN・そろんご）
26. **本物の部位1つに、形の似た薄いブロックを1つずつ当てる。** フルブロックは芯（胴・樽・原木）にだけ使う。吊り物は、天井側に金具役のブロック（砥石・避雷針）を1つ挟んでから下げる。とがった物は下から太さを落としていく（塀 → 柵 → 鉄格子 → 避雷針）。（らーなろっそ）
27. **状態や使い方まで作る。** 倒れた手押し車とこぼれた干し草のように。色は主の材料1つと差し色1〜2つに絞り、芯は地面に1段埋める。（SEVEN・そろんご）
