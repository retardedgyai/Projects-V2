# 外の景色のインスタンスダンジョン（11/06、Runeforge「緑の城塞」から）

藍（11/06）「この感じのクオリティで…最初のインスタンスダンジョンとして出したい」。手本は `~/.minecraft/saves/play.runeforge.fun_minecraft_dgn_verified_verdant_citadel`（`towns/mc_view.py` で見る）。番号は harbor.md の続き。

106. **区域は器。** 縁は高い崖か丘で上に森がかぶさり、中は開けて段になり、底で戦う。器と器は細い切り通しでつなぎ、そこに門を置く（ゲームではそこを閉じる）。
107. **段の縁は石で縁取る。** 段の切り替わりの1列を石レンガ・苔の石レンガ・丸石・安山岩のまだらにすると、上から見て灰色の輪が渦に見える。
108. **斜面の段の縁は苔ブロック。** 草ブロックの横の面は土の絵なので、1段ずつの斜面が茶色の縞の壁に見える。手本は地面の2割が苔（ほかに黄緑のテラコッタ・緑の羊毛）で、横の面も緑。
109. **白い石の遺跡を、開けた所の縁に目印として散らす。** 磨いた閃緑岩の柱2本と弧、片方は折れて石が落ちている（poi.white_arch）。
110. **戦う床には木を置かない。** 器の中は木の冠もかぶせない。ボスの床は苔と草を主に静かにして、模様は参道と縁の帯だけ。周りの大きな木は縁のすぐ外に置き、冠を床の縁へかぶせる。
