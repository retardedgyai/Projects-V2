# 港町建築：ユーザー指定の品質基準

2026-09-07。以下の3投稿はユーザーが指定した建築品質のリファレンス。
投稿内の画像をブラウザーで実見した。画像や配布建築データの取り込みは行っていない。
街の用途・配置・海沿いの世界観は従来の港町画像を維持し、下記は造形の品質基準として使う。

## 実見した特徴と適用先

- [amane734](https://x.com/_amane734/status/2096516253716214155)：大小の切妻、屋根窓、
  高い煙突を非対称に組み合わせた輪郭。白壁を木骨・奥まった窓・窓の縁取りで分節し、
  上階の張り出しと石の下階に明確な厚みがある。倉庫・商館・宿の屋根と正面構成の基準。
- [Gutty / Fletcher's Foundry](https://x.com/Gutty_Live/status/2095844337687101512)：
  赤から橙へ変化する屋根、主屋と高い塔・羽根の明確な主従、草地から石の基壇への接続。
  投稿本文でも樹脂の塊を使った屋根の色の移行に言及している。鍛冶工房・造船所の識別性と
  素材配置の基準。港町全体を風車建築に置き換える意味ではない。
- [GraySun8151 / The Verdant Bastion（Shera_nomとの制作）](https://x.com/GraySun8151/status/2095871325696864646)：
  緑の主屋根と塔屋、曲線的に回り込むバルコニー、深い軒、暖色の窓、建築と一体の植生。
  高低差を階段と基壇でつなぎ、大小の形を重ねている。学院・高台・街路側の立体構成の基準。

## 現状との差と次の一括改修

比較対象は実ゲーム画像 `assets/harbor-architecture/overview-r34.png`。
現状にも木骨・屋根窓・バルコニーはあるが、単色の大きな屋根面、似た住宅の輪郭、
長く平らな桟橋面が支配的。細部の支持材や葉の1ブロック調整だけではこの差は埋まらない。

1. 主役の集会所、脇役の学院・工房、低い市場という大小の関係を保ち、主要な住宅の
   主屋根・小屋根・張り出しの組み合わせを建物ごとに作り分ける。
2. 壁を窓・柱・軒・バルコニーの複数の奥行きで構成する。既存動線へ柱や装飾を突出させない。
3. 屋根や石の色は面のまとまり、上部と下部、縁などの意味を持たせて変える。
   ブロックを無差別にランダム置換してノイズを増やさない。
4. 植生と地形は基壇・路地・建物のつなぎ目を構成し、屋根の輪郭や入口を覆わない。

## 検証と作業量の制約

- 小修正ごとのビルド・再起動・撮影は禁止。残作業を一覧化し、街全体に効く変更をまとめて実装する。
- 一括変更後にテストと代表的なプレイヤー目線・全景をまとめて確認する。
  再修正は動線の破綻・欠損・大きな造形上の欠陥に絞る。細部の好みで同じ場所を反復しない。
- テスト成功を造形品質の達成と同一視しない。一方、撮影枚数やブロック数を成果の代わりにしない。
- 参考画像の照明・背景・撮影効果と建築の形を区別し、Vanilla通常表示でも成立する形を優先する。
- ゲーム機能・通路・mainは維持。撮影用ウィンドウはサブモニターのみ。人間の手動テスト操作は奪わない。
