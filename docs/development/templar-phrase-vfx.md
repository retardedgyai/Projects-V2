# テンプラーの槌・防護・封鎖線の演出

2026-09-08 / `play/gyai/class-combat-rework`。全技の品質目標はまだ未達。

## 8技の役割

| 技 | 主動作 | 余韻・境界 |
|---|---|---|
| 裁きの槌 | 持ち手を支点に頭上から振り下ろす立体槌 | 5本の枝分かれする地割れと放物線を描く石片 |
| 破魔槌 | 歯の付いた重い槌。同じ支点で強い振り下ろし | 実命中した敵だけに装甲の破片。空振りで装甲破壊を出さない |
| 守護の構え | 中央に視界の隙間を残した左右の盾を閉じる | 実際の50tickに追従し、最後の6tickで外へ開いて崩れる |
| 援護突進 | サーバー移動後の前方へ盾を押し出す | 独立した石片。槍の刺突・転移門は使わない |
| 報復 | 四分割の低い衝撃波を5tickで外へ広げる | 6個の石片が別々の弧を描く。追加の命中判定はない |
| 封鎖線 | 実範囲の境界に4本の低い柱を立てる | 実PULSEごとの8tickの境界点灯。柱は初回だけ生成 |
| 護りの誓い | 前左右と背後の3枚の盾 | 上昇する小さな光のルーン。広い不透明な輪は置かない |
| 不落の聖域 | 正面中央を空けた6つの聖堂状アーチ | 内側の光が浮上。大きな地上円や頭上の屋根で視界を塞がない |

吸引2技は既存の両端固定された動く鎖を維持する。
槌・盾・柱・アーチ・石片はMinecraftの立体モデルであり、PNGやドット絵と呼び替えない。
新規の画像生成・外部画像取り込み・UI素材の差し替えは行っていない。

## 発動と判定の関係

`CorePlayerCombat` の PREPARE → 実際の PULSE / CONTACT を使用する。
槌のPREPARE最終姿勢とPULSE開始姿勢は、持ち手・槌頭とも同じ位置。
PULSEの槌は振り下ろしをやり直さず、12tickの跳ね返りと分解を行う。
地割れや衝撃波の広がりは命中後の余韻であり、遅延ダメージではない。

封鎖線は最初のPULSEの柱が32tick残る。8tickごとの4回のPULSEは境界だけを点灯し、
後続のPREPAREでは柱を追加しない。
護りの誓い32tick・不落の聖域40tickは発動演出であり、味方へ付いた障壁の残量や
持続時間を示す表示ではない。演出の壁に衝突判定・新しい保護領域はない。

音は槌の金属音と石の破砕、盾受け、鎖、鐘へ分離。
防護技に汎用の魔法爆発を重ねない。音の開始は既存フェーズと同時で別タイマーなし。

## 実装の入口

`CoreSkillChoreography.parts` → `CoreTemplarChoreography.parts` →
`CoreSkillChoreography.pose` → `CoreCombatMeshes`。
最初に見るファイルは `CoreTemplarChoreography.kt`。
槌の支点・守護の盾の開閉は同ファイルの `pose`、形は
`scripts/build_core_combat_models.py` の `build_templar_phrases`、音は `CoreSkillAudio.kt`。

通常の1演出は最大11表示、主表示は最大8。本人48・シーン384の上限は変更しない。
広い衝撃波は半径に合わせてセル数を増やし、半径を広げても帯の厚さを約0.25mに保つ。
最初の投影で大きな金色の輪が槌や盾を隠したため、槌は地割れ、防護は小さなルーンへ
変更した。輪を残したのは報復と封鎖線だけ。
