# 桜牙獣（sakura fang）— 2体目のBlockbenchボス

制作手順は [boss-model-pipeline.md](boss-model-pipeline.md)。モデルとアニメは `python scripts/build_boss_sakura_fang.py` が `assets/bosses/sakura_fang.bbmodel` に書く。

## 姿

- ジンオウガ型の骨格（低く構える、巨大な前腕、短い後脚、背へ反り上がる太い尾）。骨格の比率は公式レンダーから読んだだけで、形・名前・技は独自。
- 顔になるモチーフは「桜の花びらの甲殻」。背から尾の外側のふちへ、二重の花びらが1列に重なる。ふだんは閉じ、怒ると左右に開く（`shell_*` 骨）。
- たてがみの毛先と角の先が桃色。前腕と肩は重ねた甲殻に光る縁、脇腹と尾に光る筋。

- 技の合間：連携が終わると2.2〜3.8秒（怒り後1.4〜2.6秒）は技を出さず動き回る（`QuestEncounterCombat.SAKURA_REST`）。近すぎると飛び退き、中距離では回り込み・横跳び・威嚇（`growl`）・身震い（`shake`）・地を掻く（`scrape`）から同じものを続けずに選び、遠いと低く忍び寄る（`stalk`）。大技の待ち時間は長め（6〜14秒）。休みの間に出すのは小技（`SAKURA_LIGHT`）だけで、飛び退きの後は踏み込み爪、横跳びの後は突き上げか体当たり、回り込みの後は3回に2回小技へつながる（休みが終わったら大技が先）。飛び退きの後（怒り後）は散華、横跳びの後は突き上げにつながる。

- カウンター：大技（桜爪・止め・宙返り・花嵐・突進・遠吠え・花冠落とし・飛びかかり）の決めの0.6〜0.15秒前、角が青く光る。その間に正面から当てると技が止まり、3.5秒崩れる（動けない・被ダメ+30%、`countered` クリップ）。
- 部位破壊：正面から最大HPの12%で枝角が折れる（先が消え、突き上げを使わなくなる）。背後から10%で尾の花びらが散る（尾の先の花びら甲殻が消え、散華を使わなくなる）。どちらも数秒怯む（`flinch`）。素材の報酬はまだ無い（保存形式に関わるので未決）。
- 桜紋の陣（協力ギミック、怒り後）：怒りの10秒後、以後40秒ごと。座って遠吠えし、闘技場に人数分（1〜5）の桜紋が咲く。6秒後、全部の紋に誰かが立っていれば陣が逆流して4.5秒崩れる（被ダメ+30%）。空いた紋1つにつき全員に魔法ダメージ、紋に立っていない人はさらに1つ分。
- 千本桜（最後の大技、HP25%で1回）：それまでHPは25%より下がらない（飛ばせない）。闘技場の真ん中へ跳び、足を広げて低く構え体を揺すって力をため込み（だんだん大きく速く）、6.4秒で四つ足のまま天へ吠え、8秒で跳んで両前脚で叩きつける。その間、床いっぱいに桜紋が咲いて花びらが渦を巻いて集まる。終わりに、見えている全員へ大ダメージ（魔法）。柱（散り桜の庭は3ブロック幅）の陰に隠れれば無事。撃ったあと5秒崩れる。
- HP 560、弱点 炎、移動 0.14（怒り後×1.2）。体は不可視のRavager（音もravager）。
- 怒り（HP50%で1回）：5秒。ジンオウガのように座って天へ遠吠えし、2.5秒で花びらが肩→尾へ波のように開いて花吹雪が弾ける。以後は開いたまま。大技の締めは「見得」。
- 花吹雪：パックありの人には `SakuraPetalFx`（花びら＋光の帯の表示エンティティ、`scripts/shaders/item.fsh` の印78）、全員に桜の葉の粒（`QuestEncounterCombat.sakuraBurst`）。花びらと光る筋は印 alpha 200..215 で自己発光し、光が肩→尾へ流れる。
