# 刻印射撃・閃光歩の演出

2026-09-08 / `play/gyai/class-combat-rework`。全エフェクトの品質目標は未達。

## 変更

- 雷の刻印：手元の集電、射線に沿う分岐雷、確定命中時の刻印と短い放電。
  雷は4形状を切り替え、その後4段階で途切れる。長距離でも線を単純に引き伸ばさず分岐を増やす。
- 影の針：立体の細い針と専用16コマのピクセル残光。手元側から影の筋が裂けて消える。
  確定命中時だけ印と二つの縦裂けが現れる。矢の羽根・星の爆発・煙は流用しない。
- 閃光歩：4本の立体放電が出発時は身体へ閉じ、到着時は外へ開く。
  追加の破片2つは副表示。正面を塞ぐ門の画像や斬撃は使わない。

射撃22tick、転移24tick、命中18tick。見せるために射撃を遅い弾へ変更していない。
短い針の本体は7tickで消え、残光が後を引く。音は投射・着弾・転移に分けた。
ダメージ、当たり判定、移動、資源、CDは変更していない。命中印はCONTACTのみ。

## 素材

影の針は組み込みimage_genの生成＋1回の修正を使用。
初稿の滑らかな灰色の発光を不採用にし、輪郭のあるドット連番を選んだ。
原画と完全なプロンプトは `assets/combat-vfx/needle-rift-pixel-v1.md`。
最終パックは96×64、実質48×32グリッド、3明度、不透明／透明の2値、補間なしの整数拡大。
短い交差面を射線へ並べ、フレームをずらして消散させる。単一画像の全長引き伸ばしではない。

雷・針本体はMinecraftの立体モデル。ピクセルPNGと混同しない。
既存の分岐雷で消散後半ほど立体部品が増えていた条件も修正し、段階的に減るようにした。
目線投影で雷の折れ曲がりが四角い板に見えたため、折点間の箱埋めをやめて細い段差状の線へ修正。
白い芯を青い箱の内部へ完全に隠さず、上下へ露出させる。消散中も同じ枝形状を保ち、
途中の部品を消しても残りの枝を別経路へつなぎ直さない。
UI・日本語フォント・スキルアイコン・クライアント・共有Frameworkは変更していない。

## 処理と調査の入口

`CorePlayerCombat` → `CoreSkillChoreography.parts` → `CorePrecisionChoreography.parts`
→ `CoreSkillChoreography.pose` → `CoreCombatMeshes`。
描画の向きと時間は `CorePrecisionChoreography.kt`、素材は
`scripts/build_core_combat_models.py` の `build_precision_casts`、音は `CoreSkillAudio.kt`。
射線の最終長はサーバーの遮蔽結果を使う。表示数は最大6、既存の予算を増やさない。

## 検証

最終変更を含む全サーバーテスト756件（失敗・エラー・スキップ0）と
`:server-minestom:distZip` 成功、2分40秒。専用テスト9件を含む。

専用テストは、短距離・真上・斜め下への全フレームの射線範囲、
雷の密度と単調消散、16コマのドット・余白・明度、CONTACT限定の印、
命中裂けの全方向回転、転移の出発／到着、短い予備動作、実ポーズ出力を検査する。
折れ曲がりの部品幅・高さも制限し、大きい板へ戻らないよう検査する。

`.tools/precision-cast-review.gif` と `.tools/precision-cast-eye.gif` は
実モデル・実ポーズの6シーン／4シーンの投影。Minecraft画面ではない。
実機の視認性、連打時の重なり、多人数時の負荷・音量、最終feelは未確認。
