# ProjectS V2 — Astra コアループ手動テスト案内

対象は `play/gyai/astra-core-loop` のソロ向け T1〜T4 試作です。Vanilla Minecraft 26.2 で、
港 → 遠征 → 戦闘・任意の採取 → ボス → 帰還 → 精製・制作 → 次Tier、を確かめます。
この文書は実装から作った確認手順であり、起動成功・手動テスト合格の記録ではありません。
ゲーム内の操作と面白さの最終判断は人間のCreatorが行います。

旧ProjectS資料からの採用点・見送り点と読了一覧は
[資料監査と設計意図](astra-core-loop-source-audit.md)を参照してください。
短い港の施設動線、戦闘と採取から制作につながる素材、サーバー確定の報酬を採用しています。
昔の大型都市・市場・全職業・クライアント専用エディターを全部復活させる実装ではありません。

## 起動とセーブの前提

- `main` は変更せず、試作用worktreeを使います。通常のサーバー入口は新しい港とコアループです。
- 旧combat labへ戻す場合だけ、サーバーJVMに `-Dprojects.legacyCombat=true` を渡します。
  Gradleプロセスだけに付けても子JVMへ渡るとは限らないため、サーバー側のJVM設定を確認してください。
- 接続先は通常 `127.0.0.1:25565`。Fabric導入や専用クライアントUIは必須ではありません。
- `PROJECTS_CORE_READY` はサーバー待受の記録です。Minecraftの可視ウィンドウ・タスクバー表示、
  プレイヤー接続ログ、港への転送を確認するまでは「遊べる状態」と扱いません。
- 起動準備後にAgentがキャラクターを動かしたり、ゲーム内テストを代行したりはしません。

ビルドは `:server-minestom:test :server-minestom:installDist`。WindowsではJava 25の
`JAVA_HOME`（必要な環境では既存の `JAVA_TOOL_OPTIONS` パッチも）を設定したうえで
`scripts/start-core-loop.ps1` を実行すると、サーバーだけを非表示で起動して待受完了とログ場所を返します。
使用中のポートを自動で奪ったり、別サーバーを強制終了したりはしません。

Gradleの `:server-minestom:run` をこのworktreeで実行した場合の保存先：

| データ | 保存先（worktreeからの相対パス） |
|---|---|
| 素材・装備Tier・所持地図・解放Tier・報酬確定状態 | `server-minestom/run/config/projects/core-loop/<UUID>.account` |
| 採取職の経験値・取得済み心得 | `server-minestom/run/config/projects/gathering-mastery/` |

今回のアカウント保存は旧コアループのデータを移行せず、別ディレクトリを使います。
採取熟練度は既存の専用保存を継続します。このworktreeの `server-minestom/run` で起動すれば他worktreeの
実行ディレクトリとは分離されますが、別の作業ディレクトリから直接Javaを起動すると保存先も変わります。
既存セーブを削除して試験しないでください。完全な初回確認は別プレイヤー名などで区別します。

アイテムの所有数はサーバーの台帳が正本です。倉庫から取り出す必要はなく、満杯のインベントリでも
素材報酬を受け取る設計です。ホットバーやメニューのアイコンは表示・操作用で、自由に並べた全アイテムの
位置を再接続後まで保存する仕組みではありません。

## 港の施設

初回は海沿いの港 `(0.5, 41, 7.5)` に到着します。正面が地図台です。
日本語の施設名を目印に、表の作業ブロックを近くから右クリックしてください。

| 施設 | 主なブロック座標 | できること |
|---|---|---|
| 地図台 | `(0, 41, -15)` | 地図の受取・選択、石板MOD、遠征出発 |
| 工房 | `(-16, 41, -6)` | 素材の精製、武器・防具制作、消耗品制作 |
| 素材倉庫 | `(-15, 41, 10)` | Tier別の所持数確認。取り出さず制作に使用 |
| 補給所 | `(16, 41, 9)` | 戦利品券を同Tier素材へ交換、採取道具を選択 |
| 採取の心得 | `(16, 41, -9)` | 採取職の経験値・ポイント確認と心得取得 |

ホットバー9番の「冒険の手帳」からも案内を開けます。遠征中は探索状況・倉庫・道具箱・帰還へつながり、
港で行う制作・地図操作を遠征中に実行する入口ではありません。道に段差・頭上の引っ掛かりがないか、
施設の用途がブロックの見た目から分かるかも確認してください。

## 操作早見表

以下はMinecraft標準のキー割当での表記です。番号は画面左から1〜9番です。

| 操作 | 内容 |
|---|---|
| 1番の大剣で左クリック | 通常攻撃。サーバーが前方の範囲を判定 |
| 大剣で右クリック、または2番を右クリック | 踏み込み斬り：マナ15、再使用4秒 |
| 3番を右クリック | 地砕き：マナ25、再使用7秒 |
| 4番を右クリック | 旋風斬り：マナ35、再使用11秒 |
| F | 移動入力方向へ回避。入力がなければ向いている方向。通常のオフハンド交換は使いません |
| 5番を右クリック | 回復薬：最大HPの45%回復、再使用10秒。遠征中に使用 |
| 6番を右クリック | 帰還の羅針盤：状況を開き、港への帰還を確認 |
| 7番の適切な道具で対象を右クリック長押し | 採取。離す・離れる・道具を変えると中断 |
| 8番の地図を右クリック | 手元に用意した地図で出発。地図台から直接出発も可能 |
| 9番を右クリック | 冒険の手帳 |
| E | インベントリ。道具の持ち替え、石板を地図へ重ねる操作 |
| インベントリの砥石を手に持ち右クリック | 一時的な攻撃力強化。所持数・効果はアイコン説明を確認 |
| Esc | 開いたメニューを閉じる |

スキルアイコンで技を使うと大剣へ持ち替わります。HP・マナ・各技の残り秒数は画面下部に表示します。
経験値バーはマナ、レベル欄の数字は解放済みの最大地図Tierで、キャラクター経験値レベルではありません。
通常のブロック破壊・設置はできません。手帳を見失った場合は `/projects`、帰還操作に困った場合は
`/hub` が補助入口です。通常確認ではまずアイテムと施設の導線を使ってください。

## 最初の1周

1. 港で手帳と5施設を開き、日本語が読めること、文字化け・名前の重なりがないことを確認します。
   新規アカウントはT1武器・防具、T1地図、回復薬3個から始まります。
2. 地図台でT1地図を選び「この地図で出発」。準備表示が出たら、地形と転送の完了を待ちます。
   地図は出発時に1枚消費します。未解放Tierには出発できません。
3. 道を進んで戦闘します。人型の敵の予兆を見て、移動・F回避・技・回復を試してください。
   ボス直行でも構いません。寄り道や通常敵の全滅、採取はクリア条件ではありません。
4. 採取も試す場合は道具箱で対象に合う道具を用意します。木・鉱石・石・獣皮・植物繊維の
   ラベル、対象上の進行表示、長押し中の音・動作、完了後の対象消失を確認します。
   右クリックを1回だけ押して離した際に、勝手に採り切れないことも確認してください。
5. 道の先のボスを倒します。討伐表示、討伐証・戦利品券・次Tier地図・石板・回復薬の加算、
   次Tier解放を手帳／倉庫で確認します。討伐後に探索を続けても構いません。
6. 羅針盤 → 港へ帰還 → 確認。獲得素材を倉庫で確認し、補給所・工房へ向かいます。
   戻った遠征マップへ再入場する機能はありません。

## 制作してT4まで進む

素材は地図Tierごとに別勘定です。工房・補給所・倉庫の上段のT1〜T4タブを確認してください。
精製・消耗品制作は左クリックで1回分、右クリックで5回分を選び、確認画面から確定します。
補給所の交換は確認画面を挟まず実行されます。右クリックは5回分の交換です。

- 原素材2個 → 同Tierの加工品1個。木材→板材、鉱石→インゴット、石材→加工石材、
  獣皮→なめし革、植物繊維→布です。
- T1→T2武器にはT1インゴット4・T1板材2・T1討伐証1、防具にはT1なめし革4・T1布2・T1討伐証1を使います。
  T2→T3、T3→T4も、現在の装備Tierの素材で同じ導線です。完成した装備は自動で反映されます。
- 採取をしなくても、同Tierの戦利品券1枚を原素材4個に交換できます。
  T1ボス報酬だけで、武器用の鉱石8・木材4と防具用の獣皮8・植物繊維4を交換し、
  両装備をT2へ進める素材を揃えられます。採取は素材獲得の別ルートです。
- 布・加工石材などは回復薬・採取の石板・砥石にも使います。現在の必要素材・完成個数は
  制作確認画面を正として確認してください。消耗品の所持数は素材Tierをまたいだ共通の在庫です。
- 装備更新 → 次Tier地図へ出発 → ボス → 港で更新、をT4まで繰り返します。
  T1地図は何度でも無料。解放済みT2〜T4地図の追加受取には前Tierの戦利品券を使います。
  失敗してもT1からやり直せます。所持地図には32枚の上限があります。

## 石板MODを実地で確認する

1. ボス報酬または工房で「採取の石板」を入手します。
2. 地図台で地図を選び、石板付与ボタンを押すか、「地図を手元に用意」で8番へ出します。
   後者はメニューを閉じ、Eのインベントリで石板アイコンをつかんで地図に重ねます。
   オフハンド右クリックやF交換で付ける仕様ではありません。
3. 石板在庫が1減り、地図のMOD行が増えることを確認します。最大3個で、付与内容はランダムです。
   同じキーのMODを無制限に積む仕組みではありません。
4. その地図へ実際に出発し、表示された対象と効果を確認します。採取量・品質・密集地域のMODがあります。
   密集地域では狙った素材のまとまりを探し、通常地域との差、採取対象同士の干渉も見てください。
5. 帰還して倉庫の増分を確認します。MODは生成条件に渡されますが、確率的な配置の効果を
   1枚だけの見た目で断定しないでください。密集地域の出やすさは複数の遠征で比較する項目です。

## 追加チェック

- [ ] 途中帰還：採取または通常敵報酬を得て、ボス前に帰還。得た分は残り、ボス報酬・次Tier解放は発生しない。
- [ ] 死亡：敵の攻撃で倒され、港へ帰還。確定した素材は残り、その遠征地図は返却されない。
- [ ] 再接続：港で落ちて戻り、素材・装備・地図・解放Tierを確認。遠征中の切断後は港へ戻り、同じ遠征を再開しない。
- [ ] 採取：5系統を試す。長押し解除・距離・道具違い・対象消失後の再操作で不正に報酬が増えない。
- [ ] 戦闘：予兆と実際の被弾範囲、回避方向、MP不足、再使用待ち、回復薬不足が理解できる。
- [ ] 制作：不足時は制作されず、確認を戻るだけでは消費しない。連打で二重消費・二重報酬が起こらない。
- [ ] インベントリ：Shiftクリック・数字キー・ドラッグでメニューの飾りや倉庫素材を持ち出せない。
- [ ] 石板：同じ地図への連打・付与上限・石板不足が正しく扱われ、表示したMODの地図へ出発できる。
- [ ] T4：T4素材を採取・精製して消耗品に使える。T4討伐でT5が解放されず、T4周回を継続できる。
- [ ] 日本語UI：施設名、装備、スキル、制作費用、報酬、エラーが読め、次にすることが分かる。

通常帰還・死亡・切断では使った地図は戻りません。地形生成や転送に失敗して遠征を開始できなかった
場合だけ返却する設計です。保存エラーが出た場合は操作を続けて結果を推測せず、表示とサーバーログを残してください。

## 今回まだ完成扱いにしないもの

- プレイヤー間取引、市場、パーティ共有遠征、役割分担の本格的な経済。
- 旧資料の全クラス、装備の大量ランダムMOD、キャラクターレベル全体、長期の成長ツリー。
- 多数の異なるボス・ダンジョン、T4を超えるエンドゲーム、長期運営の素材消費設計。
- 成長速度、敵の強さ、ドロップ量、制作費、採取対戦闘の効率の最終バランス。

今回は「自分で1周して成果を次の周回に使える」接続を確認する試作です。
T1〜T4の数値と所要時間は仮置きで、縦のプログレッション仕様全体が確定したという意味ではありません。
