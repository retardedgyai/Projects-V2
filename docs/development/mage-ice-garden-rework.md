## 職全体の軸と、今回の範囲

メイジの目標は「物質と場所を扱い、残すか解放するかを選ぶ」。全技を同時に改修せず、
毎回下の役割へ戻って判断する。庭一技の完成を職全体の完成とは扱わない。

| 技 | 現行で試せる役割 | 全体案での方向・今回実装しないこと |
|---|---|---|
| 火炎弾 | 遠隔の一体へ即時射線、術式を得る | 火種・敵に残す熱 |
| 霜の波紋 | 近くへ迫った敵への範囲減速 | 進路を予測する氷牙。工房形状は本編未接続 |
| 雷の刻印 | 遠い優先敵への印 | 自分の物質を使う見える接続線 |
| 閃光歩 | 配置を残して自分が移動 | 共通Fも使え、必須枠にはしない |
| **氷の庭** | **追跡敵の進路・交戦位置を作る独立した床域** | **今回の実装対象。再操作解放は次の解式設計に属する** |
| 流星雨 | 術式60を使う地点攻撃 | 予測して一度落とす重い落火 |
| 術式起爆 | 術式40を使う本人中心の範囲攻撃 | 選んだ自分の熱・氷を一つ解く遠隔解式 |
| 魔力障壁 | 攻撃と同じMPを防御へ回す | 受けた作用点が読める障壁 |
| 天火 | 長い隙に使う高コスト地点攻撃 | 重い一拍と短い残熱 |
| 絶対零界 | 広い抑制・氷奥義 | 抑制を維持するか砕くか。既存承認演出は保持 |

機動射撃（火・雷・歩・障壁）は庭なしで成立する方向。領域制御（庭・進路氷・落火・火）は
敵が追う位置を作る方向。火のみ／氷のみの蓄積と解放も全体案の評価対象だが、未実装の解式を
今回の完成条件にはしない。属性交互の固定rotationを要求しない。
レンジャーの列射撃・実罠、テンプラーの集敵・防御、星織りの節点・接続へ役割を侵食しない。
庭は敵を吸わず、攻撃・詠唱を止めず、味方を回復せず、ボスを凍結しない。
装備の混在は既存のまま。巨大パッシブを取得しなくても置き技が成立する。

## 一周の体験

既存操作で庭を選び、追跡敵の進路の床へ右クリック → 0.3秒の床の予兆 → 一度展開して本人は自由 →
横へ歩く／Fで敵を庭へ誘う → 減速中に火炎弾、資源があれば流星雨を重ねる → 最後の1秒は結晶が縮み、
終端の亀裂が開く。遠隔敵が庭へ来ないなら庭を押さずに射撃する。敵が外れたら流星雨を温存できる。

現行数値で確認する資源の例は、庭命中15 → 属性変更した火炎弾30で45 → 次の火炎弾15で60 → 流星雨60。
これは連携を確認する一例で、毎戦闘の正解手順ではない。全体案の生成20／落火消費40は未採用。
再発動で高火力を得る固定コンボを今作らない。新キー、別の技能、取得画面は追加しない。

## 仮値と比較の根拠

| 項目 | 現行main | 今回の仮値・意図 |
|---|---|---|
| コスト・再使用・初動 | MP20・9秒・0.3秒 | 同じ。初動後にpendingを解放 |
| 実体 | 0.4秒ごとの4波、1.2秒で攻撃終了 | 展開後6秒の独立域。設定済みduration120を実寿命に使用 |
| 範囲 | 円R4.5、約63.6平方m／絵のreach3 | 1.25m角×21枚の段付き八角形、平地32.8平方m。見える板と判定が同じ |
| ダメージ | 1回2+0.45AP、4波 | 同式、1体最大4打、1秒間隔。素の総量は増やさず、維持・遅着に価値 |
| 術式 | 最初の命中で15、属性変更+15 | 同じ。庭のcast contextに獲得済フラグを保持し、他技と分離 |
| 減速 | 40%／氷大成60%、命中後3秒 | 在域40%／氷大成50%、4tick間隔で350ms更新。退出後最大0.35秒 |
| ボス | 通常減速を半減 | 庭だけは実効10%。割込み・root・凍結なし |
| 重ね | pendingに占有 | 本人の庭は同時1つ。訓練のCD補充でも置き直せない |

「広い備え」等の既存radius補正は床板の間隔・判定幅へ同じ倍率で適用し、コスト補正も保持する。
基本の庭は足元全周novaより小さく、進路へ先置きする価値を選ぶ。21表示体・最大128対象分の
命中履歴・1体4打で状態とダメージを制限する。死んだ敵のIDの履歴も寿命内は保持し、再入場でリセットしない。
同一Instanceの表示総数384、術者48の既存上限を保持。観客は最大21枚の静的な庭＋既存8個の
一過性表示。床板は位相が変わる時だけ更新し、通常保持中に変形packetを繰り返し送らない。
複数メイジは各1庭・各自の命中予算を持つ。減速は既存の強い方を採用し、足し合わせない。

## 見た目・操作の完成条件

- 予兆は支持床の角と作用点。展開後は低い色面の氷板と外周の短い結晶で足元を読む。
- 板は一度だけ育ち、保持中に同じ開閉を繰り返さない。敵の初回命中だけ局所の氷片と割れる音。
- 最後の1秒は結晶を縮め、消滅時は境界を割る。終わりの破砕に追加damageはない。
- 華やか／控えめ／最小でも実体境界を残す。RPなしには同じ支持床の点で最小限の範囲を伝える。
- 壁・穴・段差へ広がらず、置けない床はMP/CDを消費せず理由を返す。
- Fは予兆中なら未展開を取消し、展開後なら庭を残す。別技の取消でも残す。
- 帰還・死亡・切断・Instance移動・職変更・術者24m超の離脱で状態と表示を掃除する。

既存Minecraft26.2クライアントから、独立worktreeのローカルサーバーへ接続しRPを受け入れる。

## 修理の入口

主処理: 入力受付／支持床採取 → pendingで初動 → PlantedGardenへ移管 → 在域チェック →
独立cast contextによるhit・一度だけ術式獲得 → 終了／掃除。
挙動は `CorePlayerCombat.tickGarden` と `CoreIceGarden`、見た目は `CoreIceGardenChoreography`、
保持中の消失なら `CoreCombatMeshes.cancel(preserveGarden)`、音は `CoreSkillAudio`。
数値・説明は `CoreSkillCatalog`。この資料とテスト結果・30秒比較を一緒にレビューする。
