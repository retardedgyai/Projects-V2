# ランダム加工・寄り道・専用ボスのプレイテスト

対象: `play/gyai/astra-core-loop`。Vanilla 26.2 + Minestom + 配布リソースパックのみ。
クライアント実装、protocol、地形生成方式、既存マップアセットは変更しない。

## 今回加えたもの

- 通常オーブ9種: 変成、増強、改変、錬金、混沌、富豪、高揚、洗浄、神聖。
- 専用オーブ3種: 裂け目（元素付きレア再鋳造）、儀式（各値を2回抽選して大きい方）、試練（上位25%の値でMOD追加）。
- レアリティは装備Tierと分離。ノーマル0、マジック2、レア6MOD。接頭／接尾の上限と重複禁止。
- 裂け目: 3地点・3波を追い、完走で専用オーブ3＋欠片3。通常戦利品は各敵からも出る。
- 儀式: 3波。1波後は報酬1、2波後は3、完走6。祭壇を右クリックで続行、しゃがみ右クリックで確定。
  死亡・戦域離脱・時間切れ・帰還で未確定の専用報酬は失う。既に拾った普通の戦利品は失わない。
- 境界の試練: 対応欠片3個を消費して独立したフィールドへ。地図自体は消費しない。
  - 裂け目の欠片 → 灰燼の王／灰燼の溶炉。追尾火印と後半の十字攻撃。
  - 儀式の欠片 → 氷獄の巨兵／氷獄の円庭。内側／外側の範囲を見て避ける。
  - 試練の欠片 → 嵐の司祭／天雷の祭壇。HP66%・33%で護衛を倒して障壁を解除。
  - 討伐報酬: 対応オーブ2、高揚1、討伐証2、戦利品券12。可視ボスドロップの通常オーブ3は別途回収。
  - 試練の欠片は通常マップのボスが1個落とす。3回の討伐から入場できる。
- 所持品だけの保管庫。素材は選択Tier、通貨と欠片はTier共通。21枠ずつページ送り。
- HPとマナは元の心臓／満腹度位置に置換。32pxスキルアイコンはその上。
  使用可能=明るい金枠、CD=暗い扇形+中央秒数、マナ不足=青色+MP表示。
- 6MODのツールチップはコンパクト表示。ロール範囲・品質・Rank・アイテムレベルは常時表示。

## 遊びの導線

港の手帳 → 遠征 → 敵／隠し物資からオーブ → 港の刻印工房 → 装備を選び加工。
オーブが持っているのは「加工方法」だけで、確定前にはMODや結果の数値は分からない。
Eのインベントリでオーブを装備へ重ねても同じ確認画面へ進む。

地図の裂け目・儀式 → 専用オーブ／欠片 → 港の手帳「境界の試練」→ 専用ボス → 専用加工。
地図内イベントは安全な道沿いに配置し、表示エンティティに衝突はない。道のブロックは変更しない。
通常ボスへの直行、採取だけの周回、イベントを無視して帰還する遊び方も維持する。

## 既存データ

旧刻印石は所持品を保持し、工房の「旧刻印石を交換」に隔離。勝手に交換しない。
本人が確定した石だけ、改変×石Tier＋錬金1へ交換する。
既存装備のMOD値とIDは維持。旧構成が新しい接頭／接尾制限を超えていても効果は失わない。
全再抽選すると新制限へ移行。v1/v2元ファイルは初回成功更新前に完全一致バックアップを保存。

通貨のItemStackは表示用。移動した投影もrefreshで回収して再構築するため、
最後の1個を使った後に手元・カーソル・オフハンドへ偽の残数を残さない。
支払いと抽選結果は同じ原子保存。帰還は報酬queueをdrainしてから終了する。

## 確認項目

1. パック適用後、元のハートと食料だけが消え、HP/MPが同じ段へ来る。防具・経験値・酸素は残る。
2. 2〜4番のスキルを使うと上の大きいアイコン内に残り秒数、終了時に明るく戻る。
3. オーブを拾った時点で具体的なMODは書かれない。工房で確定すると装備へ抽選される。
4. 混沌はレアのみ、高揚は空きのあるレアのみ、洗浄は既存MOD消去など、加工条件が守られる。
5. 保管庫で持っていない素材／通貨／欠片は並ばない。最後の1個を使えば表示が消える。
6. 裂け目3地点と儀式の途中確定／続行／完走。報酬数と欠片が保存・再接続後も一致。
7. 欠片3個を消費して3種類の専用ボスへ入り、討伐・死亡・途中帰還・切断のいずれでも港へ戻れる。
8. ゲーム操作と難易度・気持ちよさの最終判定はCreatorが行う。Agentは勝手にゲーム内操作しない。

## 画像・実装上の限界

PixelLabの既存APIスクリプトと設定は見つかったが、設定先のキー本体が存在せず、今回新原画は生成していない。
既存3原画の透過余白を除いて拡大し、新しい状態フレームを組み立てた。
PixelLabキーの保存パスが分かれば原画3枚だけ差し替えられる。キーの内容はチャット／gitへ出さない。

ボスやイベントは少人数向けの具体的な試作で、PoEやMonumentaそのものの完全再現ではない。
MOD数値・通貨出現率・波の制限時間・欠片報酬数は手動テストで調整する。
自動テストの画面寸法検証は実Minecraftの視認性確認と区別する。
