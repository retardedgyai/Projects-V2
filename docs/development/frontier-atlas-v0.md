# 開拓図 v0（地図アイテムをやめ、世界地図から直接選ぶ）

状態：設計案（Playground）。保存形式が変わるため、本編へ入れる前に Production Issue 化と Sol Review が必要。

## 目的

今の遠征は「所持している地図アイテムの一覧から1枚選ぶ」だけで、どこへ行くかに意味がない。
島ごとに地形は違っても、プレイヤーが比べるのは Lv と MOD だけになっている。

開拓図では、港を中心にした世界地図の上で行き先を直接選ぶ。
踏破するたびに霧が晴れて世界が広がり、地域ごとに採れるもの・出る敵・記録が残る。
進み具合は**プレイヤー個人**のもの。

## 今の仕組み（コード上の事実）

| 項目 | 現在 | 場所 |
|---|---|---|
| 地図の入手 | T1 は無料、T2 以上は1つ下の Tier の戦利品券1枚。Lv は `floor..min(ceiling, 冒険Lv+2)` | `CoreAccountService` `ClaimMap` |
| 所持上限 | 32枚 | `CoreLoopCatalog.MAX_MAPS` |
| 採取MOD | 採取の石板1枚で1個、最大3個、同じキーは不可。地図に付き、出発で地図ごと消費 | `ApplyTablet` |
| ボス報酬 | 討伐証2・戦利品券12・石板1・ポーション2・試練の欠片1、**次の地図（Lv+2）**。Tier 上限 Lv で討伐すると次の Tier が解放 | `BossReward` |
| 採取地図 | 採取実績で Tier 解放。素材を払ってボスなしの地図を作る | `SurveyMap`、`survey.*` |
| 地形 | seed から 6 種（VERDANT / HIGHLANDS / SALTMARSH / CLIFFLANDS / SAKURA_GROVE / INFERNAL）を抽選 | `questmap/QuestMapPlan.kt` |

## 新しい仕組み

### 世界地図の形

- 中心に開拓港。外側へ向かって **4 つの輪 = T1〜T4**。
- 輪を **6 つの扇（地形）** に分ける。扇の地形は Tier をまたいで固定で、外側ほど「その土地の奥地」になる。
- 6 扇 × 4 輪 = **24 地域**。1 地域 = (Tier, 地形)。

| 地形（仮名） | 特産（密集地域が出やすい採取） |
|---|---|
| 緑野 | 伐採・植物採取 |
| 高地 | 採石・採鉱 |
| 塩沼 | 皮剥ぎ・植物採取 |
| 断崖 | 採石 |
| 桜の森 | 植物採取・伐採 |
| 獄炎の地 | 採鉱 |

特産は「その地域を選ぶ理由」。素材集めの行き先が地図上で決まる。

### 霧と解放

- 開始時：T1 の 2 地域（緑野・断崖）だけ見えている。
- 地域のボスを初めて倒すと、**同じ輪の両隣**の霧が晴れる。
- Tier 上限 Lv（10 / 20 / 30）でボスを倒すと、**その扇の一つ外側**の地域が見える（今の「次の Tier 解放」と同じ条件）。
  外側の輪の残りは、そこから両隣へ広げていく。
- 一度見えた地域はいつでも何度でも行ける（周回用）。

### 出発の手順

1. 地域を選ぶ。
2. 敵 Lv を選ぶ。範囲は今と同じ `floor(T)..min(ceiling(T), 冒険Lv+2)`。
3. 石板を最大 3 枚はめる（任意）。
4. 討伐遠征か採取遠征（ボスなし、採取実績で解放・素材を払う）を選ぶ。
5. 出発。費用は今と同じで、T1 は無料、T2 以上は 1 つ下の Tier の戦利品券 1 枚。

中身（地形の起伏・ルート・寄り道）は**毎回新しい seed** で生成する。
地域が決めるのは地形の種類と特産の偏りだけで、毎回違う島になる。

### 石板

- 地域ごとに 3 枠。同じキーは不可（今と同じ）。
- 出発すると、はめた石板は**その遠征で消費**される（今「地図ごと消費」しているのと同じ重さ）。
- 出発前なら外して手元に戻せる。

### ボス報酬の変更

- 「次の地図」はなくなる（地図アイテムがないため）。他の報酬はそのまま。
- 代わりに、**その地域の初回踏破報酬**を一度だけ渡す（案：石板 2・冒険経験）。24 地域を回る動機にする。
- 地域ごとに記録を持つ：踏破回数、最高踏破 Lv。

## 保存データの変更

アカウントに次を足す。

```text
atlas.revealed : Set<RegionId>        // 見えている地域
atlas.cleared  : Map<RegionId, { clears: Int, bestLevel: Int }>
atlas.slotted  : Map<RegionId, List<CoreMapModifier>>   // はめている石板（最大3）
RegionId = (tier 1..4, style)
```

- `maps: List<CoreOwnedMap>` と `MAX_MAPS` は役目を終える。
- `CoreActiveRun.map` は「地域 + Lv + seed + MOD」を持つ形へ置き換える（`CoreOwnedMap` の中身とほぼ同じなので、型の名前替えで済む見込み）。
- `unlockedMapTier` は残し、霧の解放と整合させる。

### 移行（既存アカウント）

- `unlockedMapTier` が N なら、T1〜TN の地域を全部見える状態にする（今まで遊んだ人が損をしない）。
- 持っている地図は換金する：T2 以上は 1 つ下の Tier の戦利品券 1 枚ずつ。T1 は返金なし（無料のため）。
- 地図に付いていた MOD は、1 個につき石板 1 枚で返す。
- 遠征中のアカウントは、帰還してから移行する（今の `activeRun` を壊さない）。

## 画面

- 地図台を開くと、世界地図を上から見る。
  理想は、港の地図台の部屋に**本物のブロックで 24 地域のジオラマ**を建て、カメラを上空へ移すこと（光・水・溶岩の揺れはクライアントの描画に任せる）。
- 地域を選ぶと右に詳細が出る：
  - 地形と特産
  - Lv の選択
  - 石板の 3 枠
  - 費用
  - 初回踏破報酬
  - 記録
  - 出発
- 霧の地域は輪郭だけ見えて、選べない（次に開く条件を表示）。

## 実装の順番（案）

1. `questmap` の生成に「地形の種類」と「特産の偏り」を外から渡せるようにする（今は seed から抽選）。
2. 開拓図の状態を `CoreAccount` に追加し、保存・読込・移行を書く（テスト付き）。
3. `ClaimMap` / `ApplyTablet` / `StartRun` / `BossReward` / `SurveyMap` を地域ベースへ置き換える。
4. 地図台の画面を、まずチェスト画面で地域一覧として作る（遊べる状態にする）。
5. ジオラマとカメラ表示は、そのあと別作業で入れる。
