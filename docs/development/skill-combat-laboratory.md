# ランダムマップのスキル試験場

## 使い方

1. 港で `/skilltest`。個人用のランダムマップを新しく生成して移動する。地図アイテムの消費なし。
2. 手帳 **[9]** を右クリック、または `/skilltest` / `/projects` で設定を開く。
3. 上段で職業を選択 → 次段で変更する枠を選択 → その下のスキルをクリック。奥義は別の2候補から選ぶ。
4. 「閉じて試す」。スキルはいつもどおりホットバー **[2～6]** の右クリック。通常攻撃・回避も本編と同じ。
5. 帰還ボタン、または `/hub` で終了。マップ・テスト用の戦闘状態は破棄し、本編の職業・装備に戻す。

全7職業（星織り師を含む）、通常8候補＋奥義2候補の計70スキルを解放。テスト用Lv40・基準T1装備・MODなし。職業変更時は使用可能な武器を自動設定し、試験中の職業別スキル選択は保持する。

## 操作と試験条件

| 操作 | 内容 |
| --- | --- |
| 制限なし（初期値） | HP・マナ・固有ゲージ・CDを毎tick補充。敵からのダメージなし |
| 通常条件 | 実際のコスト・固有資源・CDで使用。通常条件への切替時は戦闘状態を初期化 |
| 全補充／ホットバー[7] | HP・マナ・固有ゲージ・CDを補充。発動中の多段攻撃はキャンセルしない |
| 初期化・ゲージゼロ | 通常条件へ切替、ゲージ0から開始。Starweaver等の蓄積を確認するための操作 |
| 敵を再配置 | 現在の正面付近へHP20倍の敵3体。元の敵・毒・予約攻撃を消去 |
| 敵の反撃 | 初期はなし。ありにすると本編の敵AIを動かす。通常条件との併用で戦闘確認 |

制限なしでも、発動中の技を同時に無限発動できる仕様にはしない。予備動作・多段の間隔・硬直は本編のまま。
敵を倒しても素材・経験値・通貨・進行報酬は付与しない。再配置ボタンで何度でも試せる。通常条件で死亡した場合は試験場の開始地点へ戻る。
再配置先が狭い場合は道など広い場所へ移動して再試行する。

## 保存データとの分離

`CoreCombatLab` は本編の `CoreAccountService` / `CoreRewardQueue` を参照しない。
`CoreLabLoadout` が表示用アカウントを一時的に組み立て、専用の `CorePlayerCombat` が試験場内の攻撃だけを処理する。本編アカウントそのものは差し替えない。
試験場ではアイテム移動・ドロップ・本編の消費アイテム処理を遮断。試験場のポーションは補充操作であり、倉庫の所持数を減らさない。
帰還後の表示は保存済みの本編アカウントから再構築する。再接続でも試験用Lv・装備・職業は残らない。

## 主な処理の流れ・変更ファイル

- `CoreLoopServer.kt`：`/skilltest` 登録。入力・HUDを試験中だけ専用actorへ振り分け、帰還・切断を接続。
- **`CoreCombatLab.kt`（最重要）**：生成 → 移動 → 敵と一時装備 → 設定メニュー → 帰還／破棄。生成取消と移動中の帰還を処理。
- `CorePlayerCombat.kt`：`refillTraining` を追加。補充では発動中の技や演出を止めない。
- `CoreSkillTooltip.kt`：フッター差替えを許可し、試験場では現在の設定先を表示。本編の既定表示は変更なし。
- `CoreCombatLabTest.kt` / `CoreCombatLabLifecycleTest.kt`：全職業・全候補、データ分離、実マップの入場と帰還、生成前取消。
- `CorePlayerCombatTest.kt`：補充中も三連撃の判定時刻・回数を保持、全職業の資源補充。

## 確認時に理解しておくこと

1. 前回変更したのはVFXと判定・音の同期。職業やMODの戦闘設計を作り直したわけではない。今回もスキル性能は据え置き。
2. 制限なしは演出を見るための条件。スタックを貯める楽しさや通常のスキル回しは「通常条件／ゲージゼロ」で確認する。
3. テストはサーバー内の自動テスト用Playerを使用し、ユーザーのMinecraftは操作しない。見た目・操作感の合否はManual Smoke待ち。

困った場合は、入退場・敵・設定なら `CoreCombatLab`、入力やHUDなら `CoreLoopGame.actor`、技の形・タイミングなら `CoreSkillEffect` と `CorePlayerCombat.executeSkill` を最初に確認する。
ログは `CORE_SKILL_LAB_ENTERED` / `CORE_SKILL_LAB_RETURNED` / `CORE_SKILL_LAB_*_FAILED`。
Playgroundのみ。本編採用にはProduction Issue・Sol Review・Manual Smokeが必要。
