## 経路で変わる体験

戦士の同じNotable「軽やかな連撃」へ進む2経路は、どちらも3pt。

| 経路 | 途中を含む旧仮値の合計 |
| --- | --- |
| 威力側 | 物理+12%、攻撃速度+5%、自分の資源+4% |
| 耐久側 | HP+8%、攻撃速度+5%、自分の資源+4% |

5起点すべてで同費用の2経路に異なる恩恵があり、成分ごとの比較で片方がもう片方を一方的に上回らない。横断して別のNotableへ向かう道、合流後に進む道も残す。起点は二つの即時選択から始まり、内部は10点13辺・4周回となる。すべて既存の能力を持つ点を再接続しており、空の通行料ノードは追加していない。

全47クラスタにKey以外の出入口が2点以上ある。全Keyを除去しても、各起点から他起点そのものを無料経由せず主要地域全体に到達できる。Keyは末端の任意投資であり通行の必須条件にはしない。線の交差16箇所には切れ目を描く。交差位置は隣接関係にならない。

構造の参照は [PoE 1公式ツリー](https://www.pathofexile.com/passive-skill-tree) と [公式エクスポート](https://github.com/grindinggear/skilltree-export)。親側の調査は JSON 3.29.1、rev `8bd138b32ea2631455cac5935bfab089f826094f` の分岐・合流、同目標への違う恩恵、複数入口の環状クラスタを確認したもの。本資料が全公式グラフを独自再取得したという意味ではない。公開画面とJSONのパッチ一致は保証しない。PoE 2の名称・数値・職構成は根拠にしない。

## 比較予算

Small / Notable / 能力を選ぶ経路点は1pt、起点0pt、Key3pt。個別の最短到達費用を5起点×15候補で計算した。

| 予算 | 到達できるNotableの個数（起点による幅） | Key候補 |
| --- | --- | --- |
| 44pt（旧値の比較） | 54–77 / 77 | 7–15 / 15 |
| 48pt | 63–77 / 77 | 10–15 / 15 |
| 64pt（画面の初期値） | 77 / 77 | 15 / 15 |
| 80pt | 77 / 77 | 15 / 15 |

**64ptを当面の比較基準として提案する。** 最遠のKeyは取得3pt込み57ptで、どの起点からも届いて7ptの余地がある。48ptの地域制限、80ptの広い寄り道と比較できる。個別到達は全部同時取得を意味しない。レベルごとの獲得点、上限、返還コスト、保存移行はこの案では決めない。

KeyなしのNotable投資例と同予算の近傍Key巡回例を全5起点・4予算で操作できる。64ptの巡回例ではKey3–5個。これは最適化の結果でも最大取得個数でもない。途中の能力を見比べる資料であり、新効果の戦闘係数が未採用なので、Key巡回が最適にならないという実戦バランスは未検証。

## 15個の比較候補

| 候補 | 変化・交換条件の方向（すべて未採用） |

| 守りの循環 | HP吸収を障壁へ変える代わりにHPを減らす |

| 深い裂傷 | 直撃を減らし、出血を強める |

## 現行データの入力確認

`CoreLargeTreeReferenceExport.kt` が現在の技能カタログを読み取り、5職×3セットの技能、タグ、資源消費/獲得、AD/AP、効果、半径、状態と職別18点の名前・説明を `current-catalog.json` に出力した。プレイヤーの保存データは読み書きしない。既存の120入力比較プロフィールを追記して凍結した参照であり、プレイヤーの実装備を取得した画面ではない。

- 現行状態は NONE / SLOW / MARK / EXPOSE / POISON。毒・牽制を出血と見なさない。出血を強める候補は出血供給がなければ警告する。
- 他職の武器・職別技能・AP・専用資源は取得だけで供給された扱いにしない。現行の装備/技能判定と共通大盤面の新ルールは別欄に表示する。
- Mageの半径0の自分用障壁を味方への障壁と見なさない。Tankの半径を持つ味方用障壁は入力として区別する。治癒供給は自動追加しない。
- 火属性というだけで燃焼、雷属性というだけで連鎖が供給されたことにしない。現在のMOD/技能入力が必要。
- HP吸収MODの有無を任意の比較条件で選べる。技能効果・新Keyの実装済みとは表示しない。
- 回避喪失と回避返還、会心喪失、自然回復喪失も警告する。取得済みでも入力不足の点を一覧で確認できる。

育成の役割は経路で拾う能力と条件付きの戦い方の選択。防具の全職自由混合とartifact別series、任意の装備MOD変性/専用MODという魔術加工の方向を維持し、魔術加工を必須条件にしない。

余波と既存WAR_AFTERSHOCK、重ね撃ちとMage Echo/矢の多段、HP消費と吸収/障壁の循環、DoTの再発動、失った回避・会心への依存などは、本番効果へ採用する前の未解決事項。仮値の合算を実DPSと呼ばない。
