## 3技

- 受け流し：二本の線の交差から、一振りの立体大剣へ。握り位置を固定して胸前へ起こす。
  実防御時間30tickだけ本人に追従し、最初の12tickは刃に沿って光が走る。
  光は成功判定ではなく、既存の受け流し猶予時間を示す構えの表示。
- 雄叫び：口元の吸い込みから、前後それぞれ3つの声の波。4tickずつ遅れて外へ動き、輪郭が崩れる。
  中央の空いた厚みのある輪郭で、斬撃画像を流用しない。3回の攻撃や障壁付与ではない。
- 不屈の旗：横棒・留め具・金の穂先・燕尾の赤布・白い剣章の立体旗。
  予備動作で布を開きながら打ち立て、設置地点に固定して3秒間揺れる。
  四方へ金色の吹き流しが一度だけ散る。石片は設置の瞬間だけ。

## 素材と時間

新規の画像生成・外部ゲーム画像の取り込みなし。すべてMinecraftの立体モデル。
「ピクセルのPNGを描いた」とは区別する。既存UI・日本語フォント・スキルアイコンは変更しない。

大剣は厚い両刃・中央の溝・鍔・握りを持ち、モデル中心ではなく握りを軸に回す。
旗の布は閉じた状態から4段階で開き、その後8姿勢を2tickごとに繰り返す。
最後の10tickで8段階に消える。旗竿と横棒は風でずれず、上端を留めた布だけが変形する。
布・金属・木の色はVanillaのブロックテクスチャを使用する。

受け流しの表示30tick、旗の表示60tick。前者は既存の防御30tick、後者は自身の防御姿勢60tickに対応。
味方の障壁100/160tickやその残量を表す常設UIではない。旗を回復床や新しい設置スキルにしない。
防御判定、猶予時間、障壁量、範囲、資源消費、クールダウン、ダメージは変更していない。

音は、受け流しの金属の構え／雄叫び／旗の打ち込み・布・角笛に分ける。
被弾して防御したときの既存のブロック音は維持し、構えただけで成功音を鳴らさない。

## 処理と調査の入口

`CorePlayerCombat` の PREPARE/PULSE → `CoreSkillChoreography.parts`
→ `CoreWarriorSupportChoreography.parts/pose` → `CoreCombatMeshes`。
描画の問題は `CoreWarriorSupportChoreography.kt` から確認する。
`war_standard` は足元をroot、`war_parry_blade/glint` は握りをrootに使う専用pose。
汎用の中心回転へ流すと接続が外れる。

モデルは `scripts/build_core_combat_models.py` の `build_warrior_support`、音は `CoreSkillAudio.kt`。
最大9表示・主表示5。本人48／シーン384の既存上限は変えない。
旗・吹き流し・声の波は設置後に本人へ追従しない。受け流しと予備動作だけ追従する。

投影で確認した、声の波が途中で止まって重なる問題を修正。各波は同じ速度で最後まで外へ進む。
旗の周りの矢印状の紋もUI記号に見えたため不採用とし、布の形の吹き流しへ置き換えた。
