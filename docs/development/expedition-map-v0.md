# 遠征マップ（開拓大陸の地図画面）v0：置いただけの情報を本物にする

状態：Playground（`play/gyai/expedition-map`）。保存形式 v12 を含む。

見た目（地図の絵・マーカー・右パネルの板）は [frontier-atlas-v3.md](frontier-atlas-v3.md) のまま。
中身を、ゾーンごとの実データとプレイヤーの記録につないだ。

## ゾーンのデータ

`coreloop/CoreFrontierZones.kt` に、絵のマーカーと同じ id で 30 か所（港 + 遠征地 29）を定義する。
絵の位置は今まで通り `polish05/atlas-map.json`。表と絵の Tier・地形が一致することはテストで確かめる。

| 項目 | 中身 | 効くところ |
|---|---|---|
| 名前 | 今まで画面に出ていた名前をそのまま固定 | 画面、出発メッセージ |
| Tier | 絵の Tier | 地図の Tier、敵 Lv の範囲、費用、解放 |
| 地形 | 絵の地形（6 種） | 遠征の地形（seed の剰余で選ぶ既存の仕組み） |
| 特産 | 採取 5 種のうち 1 つ | 基本採取点 8 か所のうち 4 か所が特産、残り 4 種が 1 か所ずつ |
| ボス | 道のボス 3 種（執行官・守護者・預言者）のどれか | 遠征の最後に出るボスを固定。ボスバーの名前も |

各 Tier に 3 種のボスが全部いて、T2 以上は各 Tier に 5 種の特産が全部ある。

## 出発

- パネルの「遠征に出る」は `ClaimMap(tier, seed, zone)` → 既存の出発。地図にゾーン id が付く。
- 未解放 Tier のゾーンは出発できない（以前は解放済み Tier に黙って下げて出発していた）。
- 費用（T2 以上は 1 つ下の戦利品券 1 枚）が足りないときもボタンが止まる。サーバー側でも同じ判定をする。

## 踏破記録（保存形式 v12）

- 地図ゾーン付きの遠征でボスを倒すと、そのゾーンの「踏破回数」と「最高 敵 Lv」を記録する。初回は「初踏破！」と出る。
- 保存行：`map-zone <mapId> <zoneId>`、`zone-record <zoneId> <回数> <最高Lv>`。
- v11 以前のセーブはそのまま読める（記録なし・地図はゾーンなし）。初回の書き込み前に `*.account.v11.bak` を残す。

## 消したもの（仕組みが無いもの）

ギルド領地・持ち主・領地戦の時刻、ワールドボス / フィールドボスと出現タイマー、上部の出現通知、
荒野（PvP）マーカー 5 か所、地形ごとの架空の「敵の傾向」、素材の架空の個数（×24 等）。

## まだ無いもの（決めていない）

- 霧（見える範囲が踏破で広がる）。採取の道の人もボス討伐なしに地図を広げられるべきか、で方針が分かれる。
- 初回踏破報酬。
- ボス討伐報酬の「次の地図」は地図画面から使えないまま溜まり、32 枚で ClaimMap が止まる（既存の問題）。
