# ヒーラーの攻撃祈祷・灯火・光の歩み

2026-09-08 / `play/gyai/class-combat-rework`。全エフェクトの品質目標は未達。

## 6技の構成

| 技 | 構成 |
|---|---|
| 裁きの光 | 手元の光片が集まり、射線に沿う光が羽根状に裂ける。実命中では光片が外へ散る |
| 導きの印 | 同系統の光線。実命中した敵だけで4片が内側に寄って印を示す |
| 断罪の柱 | 地面から中央と左右の3本の光が上昇し、裂けて消える。2回の実PULSEに対応 |
| 灯火 | 開いた窓のある立体祈灯と独立した炎。三度の実PULSEで下へ照射する |
| 最後の審判 | 予備動作で上から剣が落ち、実PULSEの開始位置へ到達。着地光へ切り替わる。4波で位置も変化 |
| 光の歩み | 出発点では羽根が下へ閉じ、到着点では外へ開いて上がる。平面の門を置かない |

灯火・断罪・最後の審判はカタログ上は攻撃であり、味方を回復する演出として扱わない。
救いの輪・祈りの盾・清めの風・救済の既存の花弁・翼は維持した。

## 素材

`assets/combat-vfx/purifying-light-pixel-v1.png` を内蔵 image_gen で新規生成し、
背景のぼかしを除いた版を採用。完全な生成・修正プロンプトと使用範囲は同名の `.md`。
32×64の配布テクスチャは2×2画素の塊、背景透明・他は3階調で不透明。
光柱は下端固定の交差面、光線は短い区間を重ね、長射程で一枚の絵を引き伸ばさない。
最初の4tickで立ち上がり、その後は羽根状に分裂して消える16コマを使用。

祈灯・審判の剣・導きの光片は新しいMinecraft立体モデル。移動の羽根は既存の
`feather_plume` を使い、出発／到着で開閉・上下移動を変える。
外部ゲーム画像の取り込み、既存UI・日本語フォント・スキルアイコン・クライアントコードの変更はない。

## 発動・寿命・上限

`CorePlayerCombat` の PREPARE / PULSE / CONTACT → `CoreSkillChoreography.parts`
→ `CoreHealerChoreography.parts` → `CoreSkillChoreography.pose` → `CoreCombatMeshes`。
最初に見るファイルは `CoreHealerChoreography.kt`。形は `build_healer_prayers`、音は `CoreSkillAudio.kt`。
ダメージ・命中・回復・障壁・移動距離・クールダウンは変更していない。

- 光線は即時の射撃判定を維持し、18m等の長射程でも端のUVとモデル頂点を射線内に収める。
- 審判の剣はPREPARE終点とPULSE始点が一致する。PULSE後の剣は6tickで光へ切り替わる。
- 祈灯の本体と炎は初回だけ生成し36tick残る。後続PREPAREで本体を複製しない。
  下向きの照射は実PULSEごとに16tick。炎は8tick周期で揺らぎ、最後の12tickで消散する。
- 導きの印は確定命中位置での短い命中演出。移動する敵へ追従する状態異常タイマーではない。
- 光の歩みの主表示は4枚、総数6枚。1tickの短い予備動作でも負の寿命を作らない。
- 1演出は最大6表示。本人48・シーン384の既存上限を変更しない。
