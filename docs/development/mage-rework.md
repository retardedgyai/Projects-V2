# メイジの作り直し

相談のページ：https://claude.ai/artifact/PpG325i91uFiJXZkzsR6xx（戦士の型のまとめ、方向の比較、技と奥義の案）。

## 決まったこと（2026-10-27）

- 今の技は残す前提にしない。見た目から中身まで作り直す（藍「全部作り直しても良いかもな」）。
- もう少し複雑に、もっとメイジらしく。ただし**技は全部ワンボタン**（印を2つ押して呪文を組む案は、LoL の Hwei に近く難しすぎるのでやめた）。
- メイジらしさは押し方ではなく「起きること」で出す：
  - **地面に残った魔法が勝手に混ざる**：砕け（凍った敵＋火）、伝導（氷＋雷）、過負荷（火＋雷）、巻き込み（風＋火・氷・雷）。
  - **陣と紋**：技を撃つとその元素の紋が足元の陣に1つ刻まれる（最大3、自動）。大詠唱で全部使い、一番多い紋で中身が変わる。紋は大詠唱以外の技の条件にしない（戦士の獣と同じ）。
- **元素は火・氷・雷・風**（藍「分かりやすく」）。風は元素を運ぶ万能の役（藍「風が万能でおもしろそう」）。
- 技（案どおりで進める）：火炎弾・流星（火）／霜の波紋・氷槍の列（氷）／雷走り・落雷（雷）／突風・竜巻（風）／大詠唱。
- **奥義は2つ**、遊び方が一気に変わるもの：
  - **反響**：10秒、撃った技が2秒後に同じ場所でもう一度唱えられる（紋の数だけ、最大3回）。繰り返しは6割の威力、普通の技だけ（大詠唱・移動技は繰り返さない）、薄い青紫の影で描く。
  - **元素の極み**：10秒、陣に一番多い紋の元素を極める。体は変わらない（硬く・速くならない、飛ばない）。火＝全技に火・燃えた敵へ大ダメージ／氷＝砕いても凍結が残る／雷＝跳ねる回数が倍・伝導が氷の床全体へ／風＝範囲と飛ぶ距離1.5倍。
- **大ダメージ・体は弱い**を守る（藍）。技にも奥義にも守りや自己回復を足さない。逃げる手段は雷走りと突風だけ。
- 凍結は雑魚だけ。ボスは凍らず、そのぶん崩しが多く入る。
- 色：火＝橙、氷＝水色、雷＝黄、風＝薄い緑。アイコンの地は職の色の青紫。
- 通常攻撃は見える魔弾（案「ア」、`CoreMageBolt`）。
