# メイジの作り直し

相談のページ：https://claude.ai/artifact/PpG325i91uFiJXZkzsR6xx（戦士の型のまとめ、方向の比較、技と奥義の案）。

## 決まったこと（2026-10-27）

- 今の技は残す前提にしない。見た目から中身まで作り直す（藍「全部作り直しても良いかもな」）。
- もう少し複雑に、もっとメイジらしく。ただし**技は全部ワンボタン**（印を2つ押して呪文を組む案は、LoL の Hwei に近く難しすぎるのでやめた）。
- メイジらしさは押し方ではなく「起きること」で出す：
  - **敵に残った元素が勝手に混ざる**：砕け（凍った敵＋火）、伝導（凍った敵＋雷）、過負荷（燃えた敵＋雷）、巻き込み（風＋燃えた敵・凍った敵）。※初めは「地面に残った魔法」だったが、2026-10-28 に藍が「敵だけに状態をつける」に変えた（下の追記）。
  - **陣と紋**：技を撃つとその元素の紋が足元の陣に1つ刻まれる（最大3、自動）。大詠唱で全部使い、一番多い紋で中身が変わる。紋は大詠唱以外の技の条件にしない（戦士の獣と同じ）。
- **元素は火・氷・雷・風**（藍「分かりやすく」）。風は元素を運ぶ万能の役（藍「風が万能でおもしろそう」）。
- 技（案どおりで進める）：火炎弾・流星（火）／霜の波紋・氷槍の列（氷）／雷走り・落雷（雷）／突風・竜巻（風）／大詠唱。
- **奥義は2つ**、遊び方が一気に変わるもの：
  - **反響**：10秒、撃った技が2秒後に同じ場所でもう一度唱えられる（紋の数だけ、最大3回）。繰り返しは6割の威力、普通の技だけ（大詠唱・移動技は繰り返さない）、薄い青紫の影で描く。
  - **元素の極み**：10秒、陣に一番多い紋の元素を極める。体は変わらない（硬く・速くならない、飛ばない）。火＝全技に火・燃えた敵へ大ダメージ／氷＝砕いても凍結が残る／雷＝跳ねる回数が倍・伝導が凍った敵のまわり3ブロックへも／風＝範囲と飛ぶ距離1.5倍。
- **大ダメージ・体は弱い**を守る（藍）。技にも奥義にも守りや自己回復を足さない。逃げる手段は雷走りと突風だけ。
- 凍結は雑魚だけ。ボスは凍らず、そのぶん崩しが多く入る。
- 色：火＝橙、氷＝水色、雷＝黄、風＝薄い緑。アイコンの地は職の色の青紫。
- 通常攻撃は見える魔弾（案「ア」、`CoreMageBolt`）。

## 外す今の技

閃光歩（→雷走り）、氷の庭、術式起爆、魔力障壁、雷の刻印、天火の大術式・絶対零界（→大詠唱の火・氷の形に入れる）。保存データは `CoreSkillCatalog.migrate` で置き換える。

## 作り（2026-10-27、1回目）

- 決まり：`CoreMageRules.kt`（`MageElement`、陣 `CoreMageSigils`、床と敵の状態 `CoreMageField`、大詠唱 `CoreMageRules.grand`）。混ざり方：砕け（凍った敵＋火、×2・ボスは冷えて×1.5）、伝導（氷の上の敵へ雷）、過負荷（燃えた敵・火の床に雷で爆発と吹き飛ばし）、巻き込み（突風・竜巻が床の元素を拾って運ぶ）。凍結は雑魚だけスタン2秒。
- 大詠唱は**杖の右クリック**（ホットバーに空きがないため。`CoreLoopServer` の `weapon` 入力をメイジだけ `skill(CoreMageRules.GRAND)` に）。陣の紋は資源の欄に0〜3で出し、ヒントに「陣 火氷」のように並べる。
- 技の表（`CoreSkillCatalog`）：今の絵の番号をそのまま借りる。外した氷の庭は番号5に `retired` で残すので、メイジだけ候補が9つ（`CoreSkillCatalog.ultimateStart`）。竜巻だけ新しい絵の名前 `mage_gale`（仮の絵）。
- 奥義：反響（撃った技を2秒後に同じ場所で6割の威力で繰り返す）、元素の極み（火＝全部の技に火、氷＝砕いても凍ったまま、雷＝跳ねる回数2倍・伝導が氷の床全部、風＝範囲と射程1.5倍）。
- 見た目はまだ全部仮（今の絵の流用と、床・凍結はバニラの粒）。技ごとの一人称の見本を藍に見せてから作る。
- まだ：竜巻の吸い寄せ（今は当たるだけ）、技の説明欄の資源の行、技能ツリーのメイジ大成（連鎖術式・対位法・氷の賢者は古いまま）。

### 共有の土台に触れたところ
- `CoreClassBuild`：技の番号の上限を 0..7 から 0..8 に（メイジの9つ目）。保存の列と版は変えていない。古い保存で氷の庭を付けていた人は `migrate` で別の技に置き換わる（試験あり）。
- `CoreSkillCatalog.ultimateStart`、`CoreCombatLab`・`CoreLoopMenus` の「奥義は8番から」の決め打ちを置き換えた。
- 技の絵の並び（`scripts/build_core_hud_assets.py` の SKILLS、`class_for_skill`）に `mage_gale` を足した。
- `CorePlayerCombat`：`readyAt` を6つに（6つ目が大詠唱）。メイジの処理は末尾の「Mage」の塊にまとめ、ほかは数行のつなぎだけ。

## 床をなくして、状態は敵だけに（2026-10-28）

藍：「なんで魔法使ったら地面に属性がのこるの？」→ 理由（ワンボタンのままメイジらしさを出すため）を伝えた上で「敵だけに状態をつけるでいいよ」。

- 火の床・氷の床はなくした（火炎弾、流星、霜の波紋、氷槍の列、大詠唱の火と氷）。地面には何も残らない。
- **燃焼**：火が当たった敵は4秒燃え、1秒ごとにダメージ（前は火の床の上にいる間だった）。
- **凍結**：今までどおり。雑魚は2秒凍って動けない、ボスは3秒冷えるだけ。
- **砕け**：凍った敵に火。今までどおり（×2、ボスは×1.5）。
- **伝導**：凍った敵に雷が当たると、凍っている敵みんなへ走る。元素の極み（雷）では、凍った敵のまわり3ブロックの敵にも走る（前は「氷の床全体」）。
- **過負荷**：燃えている敵に雷で爆発と吹き飛ばし。
- **巻き込み**：突風・竜巻が吹いた敵の中に、燃えた敵か凍った敵がいれば、その火か氷（多い方、同じなら火）を当たった敵みんなに広げる。元の状態は消えない。原神の「拡散」に近い。
- 決まり：`CoreMageField`（`land` に位置はもう要らない、`carry` は敵の一覧から）。技の説明も直した。
