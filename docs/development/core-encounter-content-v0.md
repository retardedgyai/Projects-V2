対象は Vanilla Minecraft 26.2 + Minestom。`client-fabric` と `protocol` は変更しない。

HPと攻撃力は T1〜T4 で `1.65^(Tier-1)` 倍。通常遭遇はマップseedと遭遇番号から混成を決定し、ボスもseedから3種を選ぶ。同じseed・配置なら同じ構成。接触ダメージやVanilla AIによる無予兆攻撃は追加しない。

## 攻撃の流れ

技選択 → 薄い赤い範囲を表示して短時間だけ追尾 → 位置・方向を固定して赤を強調 → 一度だけダメージ判定 → 赤い短い発動表示 → 硬直 → 次の技。

- 扇・前方長方形・円・ドーナツの判定は `MobAttackShape` に集約。輪郭は同じ形から計算する。
- 面は Vanilla の Text Display 背景を水平に置いた ARGB 半透明の赤。表示文字は空白のみで、独自文字・絵文字・フォント画像・クライアント描画処理を必要としない。
- 面の内部は0.5ブロックの走査線をまとめた四角形で近似する。階段状の地形では高さごとに分割する。非常に細かい地形だけ走査線を最大2ブロックまで粗くするため、曲線端には近似誤差がある。正確な境界は赤い輪郭が示す。
- 面は攻撃範囲の上下2.2ブロックにある地表だけへ投影する。壁を挟んだダメージは視線チェックで除外する。
- 1技64表示、1マップ6技同時・最大384表示。枠が満杯なら新しい技の開始を待たせる。面を置けない地形では技を中止し、見えない範囲攻撃を発生させない。
- 追尾中は180msごとに既存表示を更新。方向固定後に遅れて追尾しない。発動後180msで面を消す。
- 敵の死亡・帰還・プレイヤーの論理死亡／退場・マップ破棄で予兆を取り除く。遅延タスクを残さない。

## 戦利品・属性の接続

`QuestEncounterCombat` はHPを死亡状態にしてから `latestDefeat` を更新し、既存の `(killer, boss)` コールバックを呼ぶ。コールバック側で `sourceId = mob:<UUID>`、通常／精鋭／ボス、敵種、Tier、死亡位置を読み取れる。戦利品の抽選・物理ドロップ・回収・永続付与はコアループ側の責務で、このモジュール内では二重に付与しない。

- `weaknessOf(UUID)` は `fire` / `ice` / `lightning`。名前にも「弱点:炎／氷／雷」を表示する。
- `applySlow(UUID, fraction, durationMillis)` は最大65%まで移動速度を下げる。ボスには半分の減速、帰還で解除、時間経過で元の速度に戻る。
- `applyDamage` は通常のサーバー確定打撃。8ブロック以内・同一instance・生存・視線を再確認する。
- `applyEffectDamage` はサーバーで最初の命中を確定済みの炎上／連鎖専用。24ブロック以内・同一instance・生存を再確認し、盾で炎上を軽減したり壁の裏に移動すると炎上が消えたりしない。パケットから直接呼ばない。

## 最初に見る場所

- 敵の数値、装備、技構成: `QuestMobContent.kt`
- 追跡、盾、減速、撃破通知、終了処理: `QuestEncounterCombat.kt`
- 技の追尾・固定・発動・キャンセル: `MobAbilityManager.kt`
- 面の色、向き、タイル数、地面投影: `MobGroundTelegraph.kt`

画面上の透明度・色・敵の強さの最終判定はCreatorの手動テストで行う。自動テストは形状境界、表示メタデータ、表示上限、ロック、命中一度、死後の掃除、盾の前後判定、減速解除、撃破contextの一度性を確認する。
