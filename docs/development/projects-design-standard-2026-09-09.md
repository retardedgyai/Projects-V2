# ProjectSのデザイン基準・ユーザー承認

## 固定するもの

ユーザーが実機で承認した大剣v02の作画を、今後の武器の第一基準にする。
元原稿: `assets/class-armaments/texture-first/sources/greatsword-material-v02.png`
SHA-256: `5962fb645e63ec851d64fcfff32d281291edea1cf87d59a5a443899aa305f3e3`

- 色面が整理されたピクセル絵。細かいノイズや滑らかな写実材質を足さない。
- テクスチャが形を決める薄い刃。鍔・宝石などには役割に応じた別の厚み。
- 色は武器の題材に合わせる。全武器を赤くする、蛇行した刃を流用することではない。
- 刃から出る赤い小片のアニメーションも重要。ただし他武器に同じ炎を色替えして貼らない。
- 防具制作中止の指示は引き続き有効。

## 今回実際に見た追加参考

指定されたXリストはログイン済みブラウザーで閲覧できた。
リストそのものは非公開なので、内容の転載や外部メディアのダウンロードはしない。
参照した公開作品のURLと観察だけを以下に残す。全投稿を網羅したとはしない。

### 武器: [Meluch / Ghostly](https://x.com/Meluch0_o/status/2097196877733065210)

回転GIFの正面寄りと真横寄りを確認。白い縁と青緑の段階的な色面を持つ細長い刃、
暗い紫の鍔、淡い柄、離れた小片が見える。横からの刃は薄い。
色や細い直剣の形そのものではなく、面の塗り分けと奥行きの配分を参考にする。
疎な観察のため、小片の正確な周期・元のテクスチャ解像度・メッシュ構造は未測定。

### モブ: [Blasmer / more slimes](https://x.com/wBlasmer/status/2096652133936333135)

灰茶の耳付きの個体と、青い体に灰色の結晶を載せた個体の展示画像を確認。
目・口・耳や結晶の大きい特徴が少数の色面で読める。細かい飾りを全身に散らさない。
参考は静止画なので、この投稿から歩行/攻撃アニメーションが確認できたとは扱わない。

### 建築

  小さな窓、部分的な蔓と赤い花の塊。大形→中形→細部の強弱を先に設計する。

## 今回の具体的な修正

### 大剣の持ち位置

以前は `handheld` の表示用translationに近い値を、そのまま握り位置の目標にしていた。
また、柄領域の全画素の中央値には柄尻の大きな装飾が影響していた。
v02の装飾のない柄上部(10.5,63.5 texel)を明示的な基準に変更。
バニラ26.2のiron_swordの柄付近(3.5,3.5,8 model units)をhandheldで変換した位置に合わせる。
斜めに描かれたバニラ剣と縦の原稿の45度差も補正。左右・一/三人称の全25姿勢へ適用。
絵、UV、モデル形状、GUI配置、赤い刃のアニメーションは不変。
これはバニラ基準との計算検証であり、実機の手・カメラの最終判定は別。

### Mage Zero

以前は各命中波で8tickの開閉/消失を再開し、5回短い動画を再生しているように見えた。
初回に一つの48tick演出を開始し、展開8tick→成長しながら加速旋回→最後12tickで崩壊。
後続4回は主役の渦を作り直さない。床1・帯4・結晶4の最大9表示体のまま。
NOVAのダメージは各命中時のプレイヤー中心なので、主役の演出もプレイヤーに追従する。
5回のダメージ判定・係数・範囲・コスト・クールダウンは変更しない。
既存のキャンセル/インスタンス移動による掃除と、観客ごとの表示上限を維持する。

確認用の出力は `.tools/material-grip-next` と `.tools/frost-domain-continuous.gif`。
稼働中パック、インストール済みサーバー、ゲーム入力には触れていない。
破損時は `approved_hand_display` / `CoreFrostChoreography` とそれぞれのテストを見る。
