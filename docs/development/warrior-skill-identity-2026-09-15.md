# Warrior：技を見分けられる専用素材

前回の「全体PASS」は、同じ素材の流用が技の区別を壊しているというCreatorの実機評価で撤回する。
今回の対象は全10技能の演出。威力、判定、入力、クラス、UI、他職業は変更しない。
稼働中のゲーム/配信パックへは書き込まず、起動依頼時に反映する。

- `approved-dash-v3-restore-2026-09-09.md`：承認済み輪郭、部分ごとの誕生/消散、固定transform。
- `projects-design-standard-2026-09-09.md`：少数のピクセル色面、局所的な紅、テクスチャ主体。
- `warrior-design-rework-2026-09-11.md`：動画観察と旧実装。PASS表は現行の品質保証ではない。
- Dragon Warrior https://www.youtube.com/watch?v=WR6NQB7NmgY
- MatE Hollow Monarch https://x.com/MatE312001/status/2052458279125610949

今回は保存済みのブラウザー確認フレーム（Dragon Warrior 30/30.15/30.3、
Hollow Monarch 0.4/0.8/3.2/3.4/3.8）も読み直す。
動画の制作方式を推測して断定せず、主役・大小の破片・遅れてほどける尾の関係を参照。
新しいビットマップ一枚を回すのでなく、既存の承認済みnative pixel contour生成系を拡張する。

## 演出契約

| 技能 | 保持する主役 | 新規素材と用途 |
|---|---|---|
| 踏み込み斬り | 承認済みの一閃 | 低い踏み出しの砂塵。突き用のjetを貼らない |
| 叩きつけ | 縦の剣筋 | 割れて開く地面、角張った石片、着弾で広がる低い砂塵 |
| 薙ぎ払い | 専用の長い横断輪郭を新設 | 横へ追従する風圧の帆と低い巻き上げ。牽制の拡大を禁止 |
| 受け流し | 承認済み大剣の構え | 刃縁の短い集中光、実成功時だけ金属の交差閃光 |
| 牽制斬り | 小さい斜め切断 | 細く途切れる切断糸。広い薙ぎ払いのfanを禁止 |
| 返し刃 | 逆方向の剣筋 | 折り返して裂ける鉤状の尾。奥義中段と分離 |
| 雄叫び | 開いた声の波 | 胸から押し出す圧縮面。剣の溜め光を流用しない |
| 破城突き | 細い前方向の芯 | 尖った貫通鞘と左右へ剥がれる薄片。踏み込みと分離 |
| 天断 | 上昇→返し→断撃 | 浮く破片→横に分断される面→縦の断裂と地表衝撃を段別に新設 |
| 不屈の旗 | 承認済みの旗・布・実範囲線 | 旗竿の足元だけ打ち込み留め具状の衝撃。攻撃火花は出さない |

共通化するのは画風、ink、生成器、同じ物理的役割の小片だけ。
白い斬撃以外に石灰・青灰の面を用い、紅は小面積。Vanilla煙/critや発光リングの量産はしない。
静止画の違いだけで合格にせず、実runtimeモデル列の始動/発動/余韻を比較する。
ゲーム内の見え方・音・手触りはCreatorの手動テスト。自動テストを目標水準の証明にしない。

## 実装・引き渡し

- `scripts/warrior_identity_contours.py`：20用途の新規native輪郭。20frame×body/accent、
  800モデル＋800item定義。新しいPNG原稿ではなく、承認済みinkから生成する実形状。
- `build_warrior_skill_contours.py`：薙ぎ払い専用の長い横断軌跡を追加（49モデル＋49item）。
  牽制斬りの拡大をやめた。使用しないemberも同生成契約で出力するが、薙ぎ払いには表示しない。
- `CoreWarriorFlourish`：用途・位置・傾き・寿命・描画優先度を技ごとに割り当てる。
  攻撃同士の主役素材の共用はなし。奥義の各段も独立。砂塵に空のaccent表示体を出さない。
- `CoreWarriorCompanions`：通常技能へ一律に出していた白いwind針を廃止。
  小さい接触火花/石片など物理的役割が一致する部品のみ共通。AAの既存粒子は保持。
- `CoreWarriorSupportChoreography`：受け流し成功は専用の金属衝突body/accent。
  構えただけでは成功光を出さない。旗の布と実radius輪郭は保持。
- `CoreSkillAudio`：踏み出しの砂利、重い横払い、叩きつけの砕石、受け流し成功の金属音を追加。
  同期元は既存PREPARE/PULSE/CONTACT。勝手な追加ダメージや音量設定上書きはなし。
- 主役bodyを非secondaryにし、控えめ設定と近距離観戦でも技の識別を保持。
  赤いaccentや小片は既存のFULL本人向け。表示上限は本人48/scene384/観戦8のまま。

処理：既存の攻撃/防御イベント → Warriorのparts/pose → ItemDisplay → RPのnativeモデル。
最重要の入口は `CoreWarriorFlourish.kt`。形が違えば `warrior_identity_contours.py`、
向き/位置/寿命はFlourish、紫黒ならRPのindex/参照/配信ハッシュから調べる。
共通Particle Framework・クラス基盤・client-fabric/protocolは変更しない。

## 追加改修：もっと明確な差別化と派手さ

Creatorの追加指示を受け、前節（12a64e1a）の小片中心の絵を変更。
大きな形を加えた `hero()` と、`CoreWarriorFlourish` の配置/厚みが今回の主な変更入口。

- 叩きつけ：高さの異なる5本の割れた衝撃を、地面から立ち上げる。地割れ自体も太くした。
- 薙ぎ払い：幅広い一つの扇状の剣圧に、不均等な切れ目を作る。牽制は短い斜線のまま強調。
- 返し刃：折り返し部分の厚い鉤状の面。薙ぎ払いと同じ扇を逆向きに貼らない。
- 破城突き：尖った槍先状の面＋縦横に交差する貫通部。奥行き用の一面だけFULL設定で追加。
  同じ技の同じ貫通形を二方向から見せる用途であり、別技能への流用/時間方向の回転ではない。
- 雄叫び：胸から放射状に広がる厚い5つの圧力片。声のecho/実radius線は保持。
- 天断：大きな上昇する叉状の面→横へ引き裂く面→下降する断裂。最後の地表の裂け目も強調。
- 受け流し：刃縁の構え光と成功時の金属閃光を太く。旗は布を変えず足元の打ち込みを強調。
- 踏み込み：承認済みの一閃を変えず、踏み出しの砂塵だけ広げる。AA/武器は不変。

固定の表示体を1tickごとに別のnative輪郭へ更新する既存方式を保持。
同じ絵を高速回転/反復して派手に見せない。色は鋼白・青灰＋局所的な紅。
音/判定/威力/クールダウン/入力・継続時間・共通描画基盤・client/protocolは変更なし。
