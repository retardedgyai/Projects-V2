## 強化

- 基礎成功率：+1〜5は100%。+6〜10は95/87.5/80/72.5/65%、+11〜15は55/50/45/40/35%、+16〜20は30/26/22/18/14%、+21〜25は10/8.5/7/5.5/4%、+26〜30は3/2.5/2/1.5/1%。
- V2熟練：0〜10ポイント加算。触媒：15ポイント加算。成功率は最大100%。
- V2成功保証：次の強化が+6〜10なら4失敗、+11〜20なら6失敗、+21〜30なら9失敗で、次の有料挑戦が確定成功。
- 現在の強化値Lが15未満なら破損なし。それ以降の「失敗した場合の破損率」は `min(50, 5 + (L - 15) × 3)%`。
- 全挑戦あたりの破損確率は `(1 - 成功確率) × 失敗時破損確率`。成功した装備は破損しない。
- 例：熟練/触媒なしの+15→16は成功30%、失敗時破損5%、1挑戦あたり破損3.5%。+29→30は1% / 47% / 46.53%。
- 強化値とMODは失敗でも破損でも維持。破損失敗も成功保証へ蓄積する。
- +30は上限。破損中は強化・MOD加工・旧互換Tier昇格を拒否する。
- 強化材料は既存V2を維持。装備の基礎Tierではなく、目標強化値に応じてT1(+1〜8)、T2(+9〜16)、T3(+17〜24)、T4(+25〜30)を消費する。
- 強化乱数policy revisionは3。サーバー内のrequest ID/保存revision/seedに対し決定的で、同じ操作の再送や保存再試行で再抽選・二重消費しない。

## 破損と修理

- 武器破損：通常攻撃と武器スキルを拒否。攻撃力0、強化速度補正なし、武器由来MOD無効。
- 防具破損：Tier基礎HP・強化HP・Tier軽減・防具由来MODが無効。裸の基礎HP100は残る。健全な他部位のMODは有効。
- 回避・採取・帰還は使える。装備は消失しない。予備装備への持ち替えも可能。
- 装備庫で修理材料を選び、確認してから1個消費する。材料側のMODも消えることを明示する。
- 修理では対象のbrokenをfalseにするだけ。個体UUID・製作者UUID・Tier・レアリティ・MOD個体/種類/数値・強化値・失敗蓄積・旧MOD構成フラグ・取引制限を維持。
- 修理そのものの銀貨/追加素材費は付けない。職人の完成品1個が直接消費される。
- 出品中の装備は材料にできない。自分が作った物に限定せず、他プレイヤー製の装備でも修理できる。
- 破損品の売買は許可。商品名・能力欄・購入確認に破損を明示し、売買/装備変更で勝手に修復しない。

## UI動線

既存の丸い日本語、配色、工房配置を維持。説明に必要な文字だけ既存フォントへ追加する。新しいクライアント処理はない。

1. 工房の強化で成功率・失敗時破損率を表示。
2. 破損確率があると確認画面へ進む。成功率、条件付き破損率、1挑戦あたり破損確率、消費素材を別々に表示。
3. 破損した場合は修理画面へ。工房にも「要修理」と「修理へ」を表示。
4. 所持している適合材料を選択 → 対象と材料のTooltipを確認 → 修理。
5. 不足なら同Tier/同系統の制作、または適合品だけを絞った市場へ。市場購入後は修理へ戻る。
6. 材料を制作した場合は装備庫へ入る。装備庫上段の修理から材料を選ぶ。自動消費はしない。

## 保存と検証方針

- 専用core-loop schema6：武器/防具/保管装備にbroken真偽値を保存。
- schema5の旧整備度は0〜100の範囲を検証してから廃止。0だった装備も健全として移行し、既存プレイヤーへ突然破損を課さない。
- v1〜v4も健全として移行。MOD・強化値・通貨・個体・取引履歴などは従来どおり保持。
- 通常の読み込みはファイルを変更しない。初回保存前に旧形式を完全一致の `.vN.bak` として保全。
- 旧v5の未完了market.pendingも読み、双方を復旧してから次の操作を許可する。
- v6を旧v5バイナリで読むことはできない。ダウングレードは本体・バックアップ・取引記録を保全して判断する。新旧サーバーで同じ保存を同時に開かない。
- 実プレイヤーの保存・稼働中サーバー・Minecraft操作はこの実装作業で変更していない。次の起動依頼で更新版へ切り替える。

## 経済としての限界

この方式は「愛用武器を捨てずに、修理のために職人の完成品を買う」需要を作る。
大量製造すれば必ず売れる、全Tierで永久に需要が続くという保証にはならない。

参考の解析計算：熟練を最初から最大10で固定し、+15から+30まで到達するまで毎回壊れたら修理する場合、通常強化では平均約16.75個、毎回触媒を使うと平均約8.63個の同Tier装備を消費する。
各段階で成功確率p、失敗上限K、条件付き破損率bとすると期待材料数は `b × Σ(j=1..K) (1-p)^j`。15段階分の和。天井・修理で失敗蓄積を保持する実装を前提とした理論値で、実プレイヤーの測定結果ではない。

+30到達者が同じ1本を使い続けて強化しなければ、この修理需要は止まる。
長期運営では別ビルド/用途の装備更新、新規参加者の装備需要などと合わせて評価する。需要を増やすためだけの遠征消耗・強化降格・全ロストは勝手に足さない。
