# 職業リワーク（CD管理）

Creator：「ここからクラスリワークしていきたい。基本はCD管理」。2026-10-15の `play/gyai/class-rework`（主力技を固有資源で回し、CDは連打防止だけ）は逆向きなので使わず、手触りルールだけを移した。

## 1. 全職の方針

- 技を撃てるかは**CDだけ**で決める。マナは使いすぎの上限。
- 固有資源は**普通の技の条件にしない**。奥義の条件と、技を強くする使い道だけ。
- CDを役割で分ける：つなぎ技 4〜6秒 / 大技 10〜16秒 / 状況技 16〜30秒 / 奥義 60秒＋資源。全部同じ長さにしない（D05「CD順押し」の原因）。
- 大技は「いつ当てるか」で強くなる（戦士は通常3段目の直後）。
- 候補は 5〜6技＋奥義。枠（4＋1）とHUDはそのまま。
- 進める順：戦士 → アサシン → レンジャー → メイジ → テンプラー → ヒーラー。1職ずつ「技の中身とCD」→ 実機 → 見た目（VFX・アイコン2〜3案）。

## 2. 共通の手触り（`CoreCombatFeel`）

先行入力6tick、通常→技の接続（命中から職ごとのtick）、技の後隙（最後の命中から職ごとに3〜7tick）、Fで全職の後隙を中断、テンプラーだけ構えたまま殴れる。値は `CoreCombatFeel.profile`。

## 3. 戦士（実装済み・たたき台）

| 位置 | 技 | 分類 | CD | マナ | 中身 |
|---|---|---|---:|---:|---|
| 0 | 踏み込み斬り | つなぎ | 5秒 | 8 | 離れた敵へ寄って斬る。闘気+15 |
| 1 | 叩きつけ | 大技 | 12秒 | 12 | 狭い正面へ重撃・防御崩し。**通常3段目の命中から0.6秒以内なら発生0.15秒・威力+30%** |
| 2 | 薙ぎ払い | 大技 | 10秒 | 10 | 前方180度を一度に薙ぐ |
| 3 | 踏ん張り | 状況 | 20秒 | 8 | 2秒構えて被害軽減（最初0.6秒80%・以降55%）、受けた攻撃で闘気。反撃なし |
| 4 | 剣風 | 状況 | 16秒 | 8 | 前方7mの細い斬撃。闘気+15 |
| 8 | 天断 | 奥義 | 60秒 | 20 | 闘気80で3連撃 |

- **闘気**：通常攻撃（命中ごと+12）・踏み込み斬り・剣風・踏ん張りで溜まる。叩きつけ・薙ぎ払いは闘気が30以上あれば**自動で30使って威力+30%**（足りなくても撃てる）。奥義は80必要。
- **剣聖**（大成）：通常3段目が当たるたび、叩きつけ・薙ぎ払いの残りCDが1.5秒縮む。狂戦士・旗手は従来どおり。
- 外した技：返し刃・雄叫び・破城突き・不屈の旗（受け流し→反撃の組と数合わせ。D06）。受け流しは踏ん張りへ、牽制斬りは剣風へ作り替え。
- 剣風の見た目は旧牽制斬りの斬撃を仮に流用。見た目は内容が決まってから2〜3案を出す。

## 4. 保存データ

外した技は `CoreSkillCatalog` に `retired = true` で番号・アイコン・絵の並びを残す。技選び・試験場・`SelectSkill` では選べない。読み込み時（`CoreAccountCodec.decode`）に `CoreSkillCatalog.migrate` が外した技を「その構成にまだない最初の選べる技」へ置き換える。保存の列と版（v11）は変えていない。成長樹「広い備え」の対象は戦士だけ位置4（剣風）。
