# Starweaver：星の流れ・星衣・空間の折り畳み

2026-09-08 / `play/gyai/class-combat-rework`。全技の最終品質目標は未達。

## 今回の7技

| 技 | 構成 |
|---|---|
| 星糸 | 左右の手元で星を集め、交差する星雲の流れを射線に沿って出す。手前から裂けて消える |
| 星の針 | 細い流れと短時間の結晶針。実命中でだけ印と既存の星の破裂を出す |
| 星砕き | 太い圧縮流と大きい結晶。既存の大きい破裂は実命中限定 |
| 星環 | 六方向の立ち上がる星雲が5tickで外へ広がり、その場で裂ける。中央に円盤を残さない |
| 星渡り | 出発側は四本が内へ閉じ、到着側は四本が外へほどける。平面の星形ゲートを使わない |
| 星衣 | 肩の外側へ開く左右二辺ずつの星座、下へほどける二本の光の帯 |
| 星座の守り | 高低差のある左右三辺ずつの星座、前後四本の光の帯。正面に壁を置かない |

星降る夜・星雲・天球崩壊の既存の落下／雲／実着地の破裂は維持。
星環は演出カタログの3.1ではなく実スキルの半径を使う。ダメージの範囲・時刻は変えない。

## 素材と表示

- 新規画像生成なし。既存の `nebula-stream-pixel-v1.png` 由来の64×64・16コマを再利用。
  射線への割り当ては短い区間を重ねる新しいモデルで、1枚を24mへ引き伸ばさない。
- 射線は1.5mごとの区間、交差面、UVの90度回転と端の切り詰め。最大16区間でも1表示。
  立ち上がりは最初の4tick、その後の時間は分裂・消散に使う。
- 結晶針と星座の接続線はMinecraftの立体モデル。これらをビットマップのピクセル絵と呼ばない。
- 星座の各辺は両端の星と線を一体のモデルにする。開く・回る時に両端を再計算し、
  位置・向き・長さを合わせる。8段階で接続線が途切れて消える。
- 星環・転移・光の衣は同じ星雲素材でも、向き・位置・動き・立ち上がりを分ける。
  星環を細い平面の輪、星衣を小さな点だけにした最初の投影は不採用。
  星環は傾いた交差面を使い、波を横から見た際に一本の線になる問題も修正する。
- 音は射撃・命中・星環・転移・防御を分離。守りに爆発音を付けない。

## 処理と制約

`CorePlayerCombat` の PREPARE/PULSE/CONTACT → `CoreSkillChoreography`
→ `CoreStarweaverChoreography.parts/pose` → `CoreCombatMeshes`。
CONTACTは既存の命中限定 `stellarBurst` を通し、外れた射線の先端には破裂を足さない。

一番重要なファイル、動きがおかしいときの起点は `CoreStarweaverChoreography.kt`。
形は `build_core_combat_models.py` の `build_star_weaving`、音は `CoreSkillAudio.kt`。
星座は `constellation_edge` の `offset` と `chainAnchor` を両端に使う専用poseを通る。
通常の鎖の固定アンカー動作へ流してはいけない。

最大10表示・主表示8。既存の本人48／シーン384上限は維持。
防御の主表示は左右の星座と前側の光の帯。後ろの帯は他者・低詳細で省略可能。
防御は発動演出だけが本人に追従する。味方の障壁残量や有効時間を示す新しいタイマーではない。
ダメージ・印・障壁量・星の消費・回復・移動・クールダウン・クライアントは変更しない。
既存UI・フォント・スキルアイコンも変更しない。
