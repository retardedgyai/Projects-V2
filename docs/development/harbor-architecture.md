# 港町建築リワーク

Creator contract: 到着桟橋 → 市場 → 高台の集会所を、提供された港町画像の構図を読み替えて作る。
Minecraft Vanillaのブロック建築。機能・経済・職業・UI・保存形式には手を入れない。
作業branch: play/gyai/harbor-architecture。

## 合格を判断する証拠

- 実際に生成した街をVanillaクライアントで表示した複数のプレイヤー目線の画像。
- 桟橋: 船体と荷揚げ場を前景に、軒の連なり越しに赤い大屋根が見える。
- 市場: 柱・梁・軒・石基壇がつながり、巨大な無装飾壁や宙に切れた鎖がない。
- 集会所: 地形から建物が立ち上がり、入口・階段・バルコニーが実際につながる。
- 同じ意匠規則を工房・倉庫・学舎・外周街区・船に展開する。単なる同型反復にはしない。
- 既存5施設のinteraction block、接近可能性、桟橋、上階への階段と頭上空間を自動検査。
- 画像を見て問題を修正する。テスト成功や俯瞰の簡易レンダーだけでは見た目合格にしない。
- Hypixel/Wynncraft相当は目標であり、コード行数や装飾数で達成を宣言しない。

## 設計

既存施設はy40の使いやすい短い回遊路に残す。背後の大集会所はy52の石造テラスに載る。
暖かな砂岩・石、暗い木組み、白い塗壁、酸化前の銅/レンガの赤屋根を主材にする。
大屋根・中規模の商館・小さな庇の3段階。窓を一段奥へ引き、張り出す軒とバルコニーで陰影を作る。
先に基壇・道路・建物、その後に用途が読める付属物を配置する。

## レビュー環境

人間Creatorのセッションは操作しない。保存機能のない独立した建築プレビューサーバーに、
レビュー専用アカウントを所定のカメラ位置で接続して撮影する。ゲームのmanual smokeとは区別する。
テスト用画像は実景と明記し、概念画像や立方体の簡易描画とは混同しない。
