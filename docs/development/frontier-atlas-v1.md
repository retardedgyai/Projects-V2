# 開拓図 v1：海域と果ての海域（いつまでも遊べる世界地図）

状態：設計案。v0（[frontier-atlas-v0.md](frontier-atlas-v0.md)）の「24 地域の輪」を置き換える。
見た目の見本：デザインキャンバスの「開拓図 v2：海域」。

## 一言で

世界は「海域」という群島のページでできている。
1 つの海域には 7〜8 の浮島があり、霧を晴らしながら島から島へ渡っていく。
海域の主を倒すと次の海域への航路が開く。
第四海域の先には**果ての海域**が深度ごとに生成され続け、終わりがない。

## 構造

| 層 | 中身 | 今の仕組みとの対応 |
|---|---|---|
| 海域 | 群島 1 つ。第一〜第四海域は手作りの固定配置、果ての海域は seed から生成 | Tier（T1〜T4）、深度（旧深殿の ascension 0〜20 を引き継ぐ） |
| 島 | 地形 1 種類 + 目印の建物 + 島の種類 | 地図 1 枚（seed から地形・ルートを生成）。島は**場所**、中身は毎回新しい |
| 航路 | 島どうしのつながり。踏破すると隣の霧が晴れる | 新規（個人ごとに保存） |

### 島の種類

- **遠征**：普通の島。道の先にボス、寄り道あり（今の遠征そのもの）。
- **採取**：ボスなし、特産の密集地域が多い（今の採取地図）。
- **異変**：期間ごとに入れ替わる。裂け目・儀式・試練の専用報酬が出る（今の寄り道と境界の試練を島に昇格）。
- **海域の主**：その海域のボス島。倒すと次の海域が開く。
- **前哨**：港の代わりの出発点。踏破した海域では、そこから直接出発できる。

### 霧と進み方（個人）

- 海域に入ると、前哨と、それにつながる島だけが見える。
- 島を踏破すると、航路でつながった島の霧が晴れる。
- 海域の主の島は、航路を何本かたどらないと見えない位置に置く。探索している感覚を出すため。
- 一度晴れた霧は戻らない。

## いつまでも遊べる仕組み

1. **果ての海域（深度 1〜∞）**
   - 第四海域の主を倒すと開く。深度を 1 つ上げるたびに新しい群島が seed から生成される（島の数・配置・地形・目印・異変がすべて変わる）。
   - 敵は Lv40 のまま、深度に応じて体力と攻撃が伸びる（旧深殿の `dungeonHealthPerAscension` / `dungeonDamagePerAscension` と同じ考え方）。
   - 報酬は、戦利品券の量・オーブの出やすさ・MOD の上限ロールが深度で伸びる。
   - 記録：自分の最深到達、週ごとの最深到達。
2. **海域の異変（週替わり）**
   - 毎週、各海域の 1〜2 島に異変が付く。例：「熾火の火口：裂け目」「沈み葦の集落：儀式」。
   - 専用オーブと欠片は異変からしか出ないので、クリア済みの海域にも戻る理由が残る。
3. **石板で島を書き換える**
   - 3 枠（v0 と同じ）。採取の石板に加えて、**戦闘の石板**を新設する案（敵を強くする代わりに報酬を増やす）。
   - 海域の主と果ての海域にも使える。
4. **前哨を育てる**
   - 踏破した海域の前哨に素材を納めると、施設が増える。例：灯台＝霧の範囲が 1 つ広がって見える、倉庫＝島で拾った素材を持ち帰れる量が増える。
   - 港の外にも「自分の拠点」が増えていく感覚を出すため。

## 保存するもの（個人）

```text
atlas.sea            : 今いる海域（1..4、果ては 5+深度）
atlas.cleared        : Set<IslandId>       // 踏破済みの島
atlas.revealed       : Set<IslandId>       // 霧が晴れた島
atlas.slotted        : Map<IslandId, List<Tablet>>
atlas.deepest        : Int                 // 果ての海域の最深
atlas.outposts       : Map<SeaId, OutpostLevel>
IslandId = (sea, index)   // 果ての海域は (5+深度, index)、配置は seed(深度) から再現できる
```

既存アカウントの移行：`unlockedMapTier = N` なら第一〜第 N 海域の前哨と遠征島を「霧が晴れた」状態で始める。
持っている地図と MOD の扱いは v0 と同じ（戦利品券・石板で返す）。

## 画面（見本どおり）

- 夜空に浮かぶ群島を、斜め上から見た絵にする。ブロック 1 つ 1 つに縁取りを入れる。
- 地図は横に長く、左右に動かせる。
- 島の上には ProjectS の装備スロットと同じ形の目印を置く。状態は縁の色で示す（踏破＝緑、未踏破＝白、主＝赤、選択中＝金）。
- 上には海域名の帯と、海域の切り替え（一〜四・∞）。
- 右には島の詳細（倉庫・強化画面と同じ作り）を出す：種類、敵Lv、伝承の一文、特産、見どころ、敵Lv の選択、石板 3 枠、報酬、初回踏破報酬、記録、費用、出発。
- ゲーム内では、島の絵をあらかじめ画像にしてリソースパックに入れ、強化画面と同じ「カメラの前の表示物」で描く。
  果ての海域は島の絵の組み合わせ（地形 × 目印 × 色違い）で、生成した配置に並べる。
