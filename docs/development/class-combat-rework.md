## 遊ぶまでの導線

手帳 → **成長と職業** → **技選び / 成長樹 / 能力値**。

1. 職業を選択。必要な系統の初期武器を補助配布（帰属付き・取引不可）。既存武器は装備庫へ保持。
2. 技選び：上段で枠、下段で技を選ぶ。同じ技を二重に選ぶと既存枠と入替。奥義は専用枠。
3. 成長樹：上から接続して習得。習得済みを押すと、その下の子ノードも返還。
4. 港で無料変更。遠征・ダンジョン中の変更はサーバーで拒否。職業を戻すとその職業の構成を復元。
5. 工房の武器型ページで新武器も製造。採取→精製→製造→装備→オーブ加工→遠征の既存動線を維持。

技能枠の解放はLv1 / 4 / 8 / 12、奥義Lv16。旧アカウントのlegacyアクセスは維持。
技能ポイントは初期2、Lv8ごとに1追加、最大6。Lv8で最初の大成へ届く。

### 入力

- 左クリック：通常攻撃。全職AD係数。メイジ・星織り・ヒーラーの通常魔弾もADを参照。
- 武器の右クリック：第1技能。ホットバー2〜5で通常技能、6で奥義を選び右クリック。
- F：回避。詠唱・連続技の中断が可能。ただし支払った資源・マナ・CDは返らない。
- ホットバー7：回復薬、8：地図、9：手帳。旧帰還コンパスは手帳内の帰還導線へ統合。

HUDのMP不足と固有資源不足（RP）は別表示。未解放には鍵、CDには残秒数。
障壁は青い盾と残量、固有資源は中央の金色ゲージ。パックなしでも日本語の代替表示。

防御・会心・印・蓄積・大成の条件付き倍率は別計算と明示。

## 今回追加したMOD

挙動MODのroll値をvとする。職業が一致すると発動。武器・防具の既存接頭/接尾枠と抽選処理を使う。

| ID（projects:以下） | 効果 |
|---|---|
| sanctuary | 障壁量増加。技能ツリーの障壁量と同じ計算を表示にも適用 |
| aftershock | 戦士の前方/回転/踏込技の半径+8v%、威力85%。roll合計12まで、最終半径10.5mまで |
| spell-echo | メイジの消費技に1回追加。各回は65+v%（v上限20）の係数へ |
| returning-arrow | レンジャーの直線技能に1回追加。各回は60+v%（v上限20）の係数へ |
| venom-mark | アサシンの印付与で3秒の毒。各秒AD×(10+2v)%、対応ダメージ補正を適用 |
| gravity-well | テンプラーの吸引半径+10v%（v上限10）、威力80%。引寄距離も増加 |
| preventive-prayer | ヒーラーの回復の25+3v%を障壁へ変換。最大80%。審判者とは高い方を採用 |
| orbit | 星織りの三蓄積解放に1回追加。各回65+v%（v上限20）。回復/移動/障壁には追加攻撃しない |

追加回数は大成と併用可、最大8回。倍率は順番に乗算する。
範囲が広がる、追撃が増える、回復が減るなどの交換条件を持ち、単なる全職の火力上昇にしない。

## 安全性と戦闘ルール

- 命中はサーバーの射線・範囲で判定。クライアント指定の敵IDを信用しない。
- 設置技は詠唱開始時の可視の敵/地面へ固定。途中で照準を振って範囲を運べない。
- 素材/報酬/装備加工は既存の永続台帳を利用。攻撃演出から報酬は作らない。
- 固有資源の通常獲得は1impactにつき1回。範囲で大量命中しても瞬時に満タンにならない。
- 印は術者ごと、6秒。消費技の最初の有効命中が1回だけ消費。
- 障壁は最大HP75%まで。足算せず強いものを採用。弱い障壁で強い障壁の期限を伸ばせない。
- 支援は同instanceかつ同encounterの近距離、遮蔽物なしの仲間と自分へ。死者を復活させない。
- 挑発は2秒、味方の攻撃で解除されない。ボスは吸引で移動せず短い阻害、再阻害耐性6秒。
- 吸引・移動は壁を横断しない。地上からの移動は床のない先で止まる。封印ボスの無敵を吸引で破らない。
- 炎上と毒は別の非再帰DoT。死亡/帰還/instance変更で予約技能・演出・状態を破棄。
- 全体の粒子予算と距離減衰は既存Frameworkを利用。大剣以外の技能を大剣の演出へ使い回さない。

## 保守・変更箇所

主な流れ：入力タグ → `CorePlayerCombat.skill` → 選択カタログ/ツリー/MODから定義確定 → 支払・発生待ち → 命中/支援 → `QuestEncounterCombat`の最終防御/死亡 → 既存報酬台帳。

最重要ファイルは `CoreSkillCatalog.kt`（70技能の値・係数・動き・tooltip）。

- `CoreClassBuild.kt`：選択/入替、前提、排他、返還、大成の内容。
- `CoreClassState.kt`：固有資源、印、集中、防御、星。
- `CorePlayerCombat.kt`：実戦の消費・予約・入力キャンセル・各技能の効果。動かなければ最初にここを見る。
- `CoreCombatMath.kt`：AD/AP/AR/MR、共通の障壁倍率。数値表示と実戦が違う場合の最初の確認先。
- `CoreAccountService.kt` / `CoreAccountRepository.kt`：港の構成変更とv9、旧版バックアップ。保存失敗時は再抽選/初期化せずログを確認。
- `CoreLoopMenus.kt` / `CoreSkillTooltip.kt` / `ui/CoreHudLayout.kt`：日本語導線、技能詳細、5枠HUD。
- `scripts/build_core_class_icons.py` / `build_core_weapon_assets.py`：オリジナル画像/モデルの再生成元。
- `CoreClassEffect.kt`：既存Particle Frameworkを使う職業別演出consumer。

数値の調整先はカタログ/ツリー/クラス係数へまとめている。無関係なnetworkやclientを触る必要はない。
