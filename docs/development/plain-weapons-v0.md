# 地味版の武器（T1）v0

2026-10-17。藍が承認した「地味版」の武器9本のうち、職業6種をゲームの T1 の見た目に入れ、残り3本は素材だけ入れた。

## 何が本物か

- 職業6種の T1 の見た目は、地味版のドット絵になった。手に持っても、GUI でも、置いても同じ絵（アニメなし。藍「初期武器にアニメは要らない」）。
  - ウォーリアー＝大剣、アサシン＝短剣、テンプラー＝ランス、メイジ＝杖、ヒーラー＝聖典、ハンター＝弓。
  - 星織り師（星環杖）の T1 は今まで通り。
- テンプラーの武器の名前は「誓いの戦槌」から「誓いの騎槍」に変えた。購入注文の系統名も「戦槌」→「騎槍」。
- 斧・大鎌・盾は、絵・モデル・アイテム定義（`projects:weapons/plain_axe` など）だけある。どの装備からも使っていない。

## 何が変わっていないか

- 内部の武器の種類は `MACE`（系統 `mace`）のまま。セーブ、性能、スキル、スキル演出（裁きの槌の槌頭など）は槌のまま。
- T2〜T4 は今までの3Dモデル（テンプラーは槌の見た目）。名前だけ「騎槍」なので、T2 以降は名前と見た目が合っていない。
- T1 の待機アニメとスキルの構え・振りのポーズは出なくなる（T1 のアイテム定義が静止画だけを指すため）。既存の3Dモデルとフレームのファイルは消していない。

## 作り方

- 原本はテクスチャ `core-ui-pack/assets/projects/textures/item/weapons/plain/plain_*.png`（1マス=1px、16の倍数の正方形に余白）。
  絵の制作スクリプトはリポジトリの外（~/ProjectS/movsum_weapons/src/starter_kit.py と export_game.py）。
- `python3 scripts/build_plain_weapons.py` が、モデル（`item/generated`）と T1・素材のアイテム定義を書く。
  既存の `build_core_weapon_assets.py` は今コミットされている内容と一致しないので、全体の再生成には使っていない。
- 絵は縦向きに描いてあるので、手に持つ表示はバニラの斜めの剣に合わせて面内で -45° 回してある。
  1マスの大きさを揃えるため、手に持つ表示の倍率に「テクスチャの一辺 / 48」を掛けている（大剣・ランス・杖・大鎌は大きく、聖典は小さい）。

## 未確認（ゲーム内で見てほしいところ）

- 手に持ったときの向きと大きさ。とくに弓（バニラの弓の表示を基にしたので、左右が逆になる可能性がある）。
- GUI で斜めに回した絵がスロットからはみ出さないか。
