# 強くなる道とクラフト（設計案、2026-10-19）

触れる見本：`docs/proposals/progression-2026-10/progression-loop.html`（公開版 https://claude.ai/artifact/TRswEkSEBxbrbECaP4RtrJ ）。
テスト（11月中旬、3〜5人、港町＋巨樹の根の丘、ボス2体）向け。コードはまだ変えていない。

## 決まったこと・決まっていないこと

- **決まり（2026-10-20、藍）**：基本のアイテムは全部プレイヤーが自分で作る。NPC は品を売らない（店・商人・交換所で物が手に入る形にしない）。町や領地の施設は「作り方が開く・設備を貸す」までで、作るのはプレイヤー。売り買いはプレイヤーどうしの市場だけ。
- **決まった（2026-10-20、藍）**：ボスの部位の使い道は、ボスの種類ごとに変える。まずワールドボス（桜牙獣）の分から決める。
- たたき台：ワールドボス＝みんな・町・市場に流れる物／ダンジョンのボス（黒翳竜）＝自分の装備（銘・セット効果など）／狩り場の主＝消耗品の材料。
- **決まった（2026-10-20、藍）**：桜牙獣の落とし物は「社に奉納して町が咲く・桜の相・桜の巻物・職人だけが加工・部位で使い道が違う」の組み合わせ。流れ図 `sakura-drops-flow.html`（https://claude.ai/artifact/JAnJDvbPi75yH244C17jGu ）。
  - **枝角**（正面で折る）→ 桜の社に奉納（売ってもよい）。サーバー全体の本数で港が咲く：10 桜が植わる／30 茶屋（宿の回復が速い）／60 桜の街道（速く歩ける）／100 祭り（満開の桜牙獣）。社の石碑に名前と本数（売れない記録）。
  - **花びら甲殻**（尾を斬る、参加者も1）→ 皮革精製 Lv20（仮）の職人だけが「桜の花弁片」×3 に加工 → 魔術の蒸留で「桜の相」×2 → 刻印で **桜の巻物**（10分 部位破壊+30%、消耗品）／**桜鉄の触媒**（強化 +35）→ 市場 → 戦う人がまた挑む。
  - 数はテスト（3〜5人）向けの仮。湧きは2時間ごと＋決まった時刻にも呼べる。
- **領地（2026-10-20、藍）**：オープンワールドに置く。Albion と同じ感じ。見本 `territory-life.html`（https://claude.ai/artifact/GgTVM3m9a3F1Bkj8zx7HDC ）。
  - 空いた領地も持ち主のいる領地も、戦う **24時間前に宣戦布告** が要る。戦いは決まった時間帯（例 21〜23時、仮）。
  - **維持費** を毎日ギルドの銀貨で払う（基本100＋施設1つ50、仮）。払えないと荒れて中身が止まり、3日で空きに戻る（仮）。銀貨の出口。
  - 中身：**8 そこでしか作れない物**（持ち主が素材で建てた炉・祭壇で）・**9 税**（使用料の一部が持ち主、残りは消える）・**10 採取が多い**（×1.3、仮）。
  - **勝ち方**（藍）：領地の奥の守護獣を倒すとコアが開き、コアを長くチャネリング（60秒、仮）した側が取る。チャネリング中に攻撃を受けると止まる＝相手は殴って止める（PvP）。持ち主がいれば守る側は守護獣を助けて戦える。
  - **奉納はなし**。→ 桜牙獣の **枝角の使い道が空いた**（花びら甲殻の流れはそのまま）。
- **枝角（2026-10-20、藍）**：装備で使う。**3 新しい武器の型「桜牙」・4 装身具（新しい枠）・14 職人しか加工できない**（→ 下の分担で、鍛冶＝器・魔術＝特性に分けた）。属性ではなく **ユニーク特性**：1つの装備に1つだけ。層は Tier → 型（手触りと個性）→ ユニーク特性 → MOD → 強化。見本 `unique-traits.html`（https://claude.ai/artifact/8ziq6K8ZcirU3DPCdr8cPd ）。
  - **特性の決まり方**（藍）：ボスが落とす素材の中に入っている。枝角は落ちた時点で特性が1つ入る（枝角〈桜紋〉など、運）。職人がそれで作ると装備にそのまま付く。枝角は売り買いできる（特性ごとに値段が違う）。いらない特性の枝角3本は職人が合わせて好きな特性の1本にできる（救済、アイテムの出口）。桜牙獣の特性は 散り際・花吹雪の残り香・返り咲き・風に舞う・桜紋（仮）。
  - **分担**（藍）：器（桜牙の型の武器・桜角の首飾り、特性は空）は鍛冶の職人が作る。枝角の特性を器に入れるのも、外れ3本を好きな1本に合わせるのも、**魔術の注入**（祭壇）でやる。
- 全体図（文字を読まずに見る用）：`sakura-map.html`（https://claude.ai/artifact/M1QDTSnWbrUuTmh6ZTbT2Q ）。
- **決まり（藍）**：素材の使い道を考えるときは、必ずアイテムの出口（シンク）も考える。

## 2. 強くなる道

- **Tier は場所で決まる**：T1＝港・根の丘、T2＝根の洞（奥に黒翳竜）、T3＝柱の上の空のフィールド（桜牙獣）、T4＝次の地域（テスト外）。ボスを倒すと次の場所が開く。
- **強化 +30**：今のコードのまま。素材のTierは強化段階で決まる（+9 から T2）。最初の詰まり所は +9〜+15（T2素材が要る・成功率55→35%）。採取の人の売り先になる。+15 から失敗で壊れることがある。
- **MOD・オーブ**：今のまま。数字の組み合わせを試す場所。オーブは売買不可＝自分で拾う。
- **職業Lv**：狩りで上がる。技はLv1・4・8・12・16。Tierごとに10Lvの帯。
- **魔術の研究品**：星鉄の触媒（成功率+25）・修復の封蝋（修理）を研究者が売る。+15 以降で戦闘の人が買う。
- **ボスの部位（新）**：部位破壊で取れる。黒翳竜＝触角（正面）・翼膜（背後）。桜牙獣＝枝角（正面）・花びら甲殻（尾）。部位は売れる。討伐証は売れない（苦労の証）。

## 3. 武器・防具のクラフト

採取（根の丘・根の洞・空のフィールド）／狩り／ボスの部位／市場 → 精製（2→1）→ 製作 → 強化 → MOD →（Cなら）銘。

**今のコードで直すべきところ**（棚卸しで分かったこと）

1. **Tier昇格がUIにつながっていない**。`CoreAction.UpgradeWeapon/UpgradeArmor` と `weaponUpgrade/armorUpgrade` は呼ばれていない。今は新Tierを作り直すしかなく、+値とMODを捨てることになる。→ 工房に「昇格」を出す。討伐証の使い道もここ（今は星織り師の転職条件だけ）。
2. **ボスの部位破壊が報酬につながっていない**（黒翳竜の `partsBroken()` は表示だけ）。桜牙獣はまだ main にない（PR #169）。
3. **防具が重い**：どの部位も革4・布2・石材1。4部位で毛皮32個は最初の1時間に重い。→ 頭・足を軽くする案（見本は 胴・脚＝革3・布1・石材1、頭・足＝革2・布1）。
4. **採取が遠征地図の中だけ**。オープンワールドの根の丘に採取地点と狩り場の湧きを置く（遠征マップのセッションと調整）。
5. 手帳の「次の一行」（`CoreJourneyRules.next`）が遠征の言葉のまま。

## 黒翳竜（ダンジョンのボス）の素材

- 素材：怒りの角（正面、怒った後）・扇の翼膜（横、左右）・翳鱗粉（参加者みんな）。
- **決まった（2026-10-21、藍）**：A 防具の器＋特性。桜牙獣と同じ形で、扇の翼膜 → 鍛冶が「翳の外套（胴）」の器 → 怒りの角〈特性〉（落ちた時に運で1つ）を魔術の注入で入れる。外れ3本は注入で好きな1本に。特性（仮）：触角の予感・翳の外套・鱗粉の殻・翼脚・侵食。2体並べた図 `boss-gear-map.html`。
- **翳鱗粉**：保留。今は決めない（藍「こういうのはちゃんと決めるときに決めよう」）。候補メモ：C 翳のオーブ・D 翳の膜。
