# スキル演出と判定の対応

## 今回の範囲

Playground: `play/gyai/class-combat-rework`。サーバー側の Particle Framework **利用側**のみを改修する。
クライアント・プロトコル・フレームワーク本体・保存形式・リソースパック・スキル係数は変更しない。
起動中のゲームへの操作・自動再起動も行わない。

狙いは「技名を読まずに、何をしたのかが見た目から分かること」。全70技に明示的な演出割り当てを設け、23種類の形を土台に、属性・段番号・半径・奥義で構成する。
**70種類の完全に別個のアニメーションを完成させた、という意味ではない。** 同じ系統の技には共通部分が残る。

## 変更前の問題

- 通常攻撃以外も、職業＋攻撃範囲の分類で `CoreClassEffect` を共有していた。
- Warrior のスキル斬撃は固定サイズの大剣演出になり、MOD適用後の範囲を表しきれなかった。
- スキルの命中も通常攻撃の演出時計を止め、後続の多段演出が実判定より遅れ得た。
- 毒の継続中に、毒が付着していることを示す描画がなかった。
- 遠隔技の射線がほぼ一律に炎／エンドロッドの点列だった。

## 演出の組み立て

| 段階 | 発生元 | 表示 |
| --- | --- | --- |
| 予備動作 | 確定した詠唱時間 | 刃の構え、収束する魔力、地点予告と落下する流星・矢 |
| 攻撃 | サーバーの各ダメージ判定 | 明るい主形状 → 動く刃先／余波 → 薄い残光 |
| 命中 | ダメージが実際に受理された対象 | 敵の位置で短い属性色の火花。最大3対象／tick |
| 毒 | 実際のDOT状態 | 対象の最新位置に毒気、実ダメージ時に明るい毒の脈動 |

- 多段技は8tickごとの既存判定から1つずつ描画し、斬撃の左右・角度を段番号で変える。演出側で架空の追加ヒットを作らない。
- 攻撃演出の新規粒子発生は6tickで終了。次の判定まで間を置く。Vanilla粒子自体にはクライアント既定の残存時間がある。
- 地点攻撃は次段の4tick前から再予告。着弾後に流星を落とし始める構成にしない。
- 遠隔攻撃は現状の即時判定を維持する。遅い弾を見せながら先にダメージを与える演出にはせず、判定フレームに射線を描く。
- 射線長はブロックで止めた実描画長を渡す。射程以上に伸びる点列も修正。
- 毒牙は緑の刃と滴。毒が残る敵は4tickごとに現在位置から描画し、DOTは従来どおり非重複・3回。再付与・死亡・解除／マップ退出時は実状態に従う。
- 通常攻撃の接触停止とスキル演出の時計を分離。スキルと毒の描画は接触停止の間も進む。
- 炎の残り火、氷のきらめき、電気、星光、金属の火花は短い副表現として加える。主形状をランダムな粒子で埋めない。
- 音も斬撃・重撃・矢・毒・炎・氷・防御で分け、各段で鳴らす。

## 主な視覚言語

- 斬撃：厚い明部、色の中層、細い残光。毒牙は毒色。刃の輪・無明連刃・旋風は実段ごとに異なる切断面。
- 刺突：収束した穂先。叩きつけ：縦の刃と地面に分岐する衝撃。現在の実判定が扇なので側面の範囲も示す。
- 氷：六方向の氷柱／霜矢の扇。雷：屈曲した放電。炎：熱い芯と螺旋、流星の着弾柱と火の破片。
- 星：星座の線と星光。矢雨：複数の細い着弾軸。毒罠：噛み合う歯と低い毒気。
- 吸引：外周から内側へ巻く四本の流れ。回復：下から立ち上がる光。障壁：立体的な肋骨状の保護形。
- 残像：盾の形ではなく人型の輪郭。移動技：移動前後の短い残像。

## 負荷・寿命

- 同時アニメーションは利用側で合計12まで。上限時は古い通常攻撃の軌跡を先に捨てる。
- 既存の視聴者180粒子／tick、シーン共通予算、他人の演出減衰・距離LODを維持。
- 主形状と確認済み命中を優先し、装飾は低優先度。
- 毒のスナップショットは48spawnまでの既存短命バッファを使用。大量の毒対象すべてを必ず描く保証ではない。
- エンティティやグローバル遅延タスクは追加しない。`resetActions → vfx.cancel` で両時計とバッファを破棄。

## 主要ファイルとデバッグ入口

1. `CoreSkillEffect.kt`：一番重要な演出定義。形や色がおかしければ `CoreSkillArt.motifs` と各形の分岐を見る。
2. `CorePlayerCombat.kt`：`tick → executeSkill → emitSkillPulse / rangedStrike → hit`。段数／時刻のずれはここを見る。毒は同じtick内の `burns` 処理。
3. `GreatswordVfx.kt`：通常用時計とスキル用時計、予算、キャンセル。表示欠け・退出後の残留はここを見る。
4. `CoreSkillEffectTest.kt`：全割り当て、有限座標、粒子上限、段ごとの形、射線クリップ、範囲補正、予備動作、毒、予算の自動テスト。
5. `GreatswordTest.kt` / `CorePlayerCombatTest.kt`：接触停止中のスキル時計、キャンセル、既存の実ダメージ・多段・毒の回帰テスト。

## 今回理解しておくこと・残件

1. これは戦闘の読みやすさを直す段階。スキル構成とMODのゲームデザイン変更はまだ行っていない。
2. 次の設計では「いつ使い、いつ使わないか」「位置・対象・状態で使い方がどう変わるか」を先に決め、そこから判定と演出を一緒に作る。単純な専用スキルMODの増産はしない。
3. 実機での格好よさ・視界の邪魔にならないか・混戦の読みやすさは人間CreatorのManual Smoke待ち。自動テストで見た目の完成を宣言しない。本編採用前のProduction Issue・Sol Reviewも未実施。
