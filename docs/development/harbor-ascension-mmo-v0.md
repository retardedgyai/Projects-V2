# 開拓航路 / 職業・装備の横幅と成長 v0

2026-09-06 / play/gyai/harbor-ascension-mmo。Creatorの大型実装依頼に基づくPlayground。
Base: main bc81a03。main、protocol、client-fabric、共通Particle Frameworkは変更しない。
新しい専用core-loop保存形式は旧データの正確なバックアップ後に移行する。

## 実装の順序と受け入れ条件

1. 職業と永続成長：戦士 / レンジャー / メイジ、メイジ上位の星織り師。
2. Lv1〜40とT1〜T4内の装備レベル、同系統の武器ベースを選択して製造。
3. 実行した行動で進む導入、通常遠征・上位Tier・転職・深殿への次の目標を同じ手帳で提示。
4. 低Tier素材を上位製造にも使う。MOD・強化・品質を別の成長軸として維持。
5. 各職業の通常攻撃/3スキル、武器型の戦闘上の差、表示と実際の値の一致。
6. オリジナルのピクセルスキルアイコンと既存HP/MP位置を維持したHUD。
7. 提供画像の海辺の密集街・帆布・桟橋・工房・集会所をMinecraftブロック建築に再構成。
8. Vanilla表示Entityと独自モデルによる3Dボス。攻撃判定は従来のserver authorityを維持。
9. 保存読直し・移行・不正な進行・リプレイ・装備売買・戦闘・到達性の自動テストとpack検証。

新規キャラクターの導入から既存の深殿/オーブ厳選/製造市場へ実際につなぐ。
職業選択は港で変更可能。採取者へボス討伐を強制しない。
低Tierを無理に長時間周回させることだけでプレイ時間を水増ししない。
経済成立、100時間の面白さ、大人数性能、実機の最終見た目は検証なしに保証しない。

## 実装した仕様

- T1=Lv1〜10、T2=11〜20、T3=21〜30、T4=31〜40。冒険経験と装備Lvは別保存。
- 通常討伐・採取・深殿の報酬で冒険経験を獲得。技能はLv1/4/8で解放。
- 新規の通常地図はボス討伐で同Tier内のLvが2上がる。Lv上限のボスから次Tierの地図へ。採取実績による非戦闘のTier解放は維持。
- 装備Lv鍛錬は冒険Lv+2、同Tierの上限まで。ID、製作者、品質、MOD、+強化を保持。旧キャラクターのアクセスは取り上げない。
- 開拓・連撃・重断・導脈の大剣4型、長弓、杖の6ベース。全てT1から製造できる。
  - 連撃：回避後のコンボ保持、三段目命中でマナ8回復。
  - 重断：遅めの攻撃、三段目の狭い縦斬りが強い。
  - 導脈：通常命中で最大3蓄積、次の技能を一蓄積あたり15%強化。一振りで複数体に当てても蓄積は一回。
- 上位武器制作に下位各Tierのインゴット、上位防具制作に下位各Tierの革。鍛錬にもT1石材を使用。
- 修理・購入注文は武器系統を区別。大剣の修理用注文に杖を納品できない。同系統なら別の型も修理材に使える。
- 戦士／レンジャー／メイジを港で変更可能。使用不可能な武器は装備庫へ保管し、職業用の売却不可初期武器を渡す。繰り返しても同じ初期武器を再利用する。
- メイジLv20＋T2討伐証2枚で星織り師（Starweaver）。証は消費しない。通常三命中で星を編み、技能に貫通・マナ回復／減速延長・追加の星降りが発生する。
- 弓・魔法はサーバーが射線・距離・遮蔽物を判定。近接の8m上限と遠距離の検証済み攻撃を分離。
- 導入は実際の通常命中、技能命中、戦利品回収、帰還、製造か装備購入、オーブ加工の6段階。文章を読んだだけでは進まない。初回戦利品に変成を一つ保証し、RNGで最初の加工が詰まらないようにした。
- 12技能のオリジナルアイコン。imagegenで作成した原画・プロンプトを `assets/core-ui/skills` に保持し、HUD用ピクセル画像へ変換。Monumenta由来のアイコン画像は取り込んでいない。
- HP/MPは従来のバニラハート・食料位置を維持。その上に職業の技能3つ。暗い扇＋残秒、明るい使用可能、MP不足、鍵付きの未解放を分ける。該当武器・星織り師の蓄積は中央に0/3〜3/3。
- 港は既存5施設と平坦な主要動線を保持し、大屋根集会所、窓・木組みの建物、帆布、工房煙突、荷物、船、桟橋を追加。上階にも階段で到達できる。
- 鉄壁の守護者・熔星の番人・氷獄の巨兵に22部品のオリジナル3D骨格を追加。材質が異なる共通骨格。既存の攻撃・フェーズ処理に追従し、腕・脚の動きと弱体時の速度変化を表示。pack拒否時にもネイティブブロックテクスチャで見える。討伐・破棄で全表示を撤去。
- 既存の生成深殿、深度0〜20、1〜4人の募集／分岐選択、専用ボス／加工オーブ、製造・採取熟練、市場、+30強化・破損修理へ接続。これら全てを今回新規制作したという意味ではない。

## 調整する場所

`run/config/projects/mmo-balance.properties` に既存設定と同様に上書きし、再起動で適用。

- `journey.xp-percent=100`：獲得冒険経験の倍率。
- `journey.equipment-rank-permille=45`：同Tier内の装備Lvごとの基礎性能増分。
- `journey.mob-health-rank-permille=70` / `journey.mob-damage-rank-permille=35`：地図Lvごとの敵性能増分。
- 職業別技能・武器型の具体的な値は `CoreJourney.kt` / `CorePlayerCombat.kt`。全バランスをデータ駆動にしたわけではない。

## 保存と採用の注意

専用保存形式v8。v1〜v7は読み込みだけで書き換えず、最初の永続操作で元の正確なバイト列を `.vN.bak` へ保持する。旧装備、MOD、銀貨、注文、強化を維持。新形式を書いた本番セーブを旧サーバーでそのまま開いてはいけない。

mainは変更せず実験branchへcommit/pushする。保存形式を含むので、本編採用前にProduction Issue・Sol Review・CreatorのManual Smokeが必要。

## 手動確認の入り口と残る限界

1. 新規キャラクターは職業選択から。既存キャラクターは手帳上部の職業／Lv表示から変更する。
2. 手帳の「目標」で次の行動を確認。T1の地図詳細に敵Lv、工房に制作する武器型が表示される。
3. 港の大屋根の階段、全施設、右クリック技能、モデル付き守護者、GUIスケールを実機で確認する。

導入は通常遠征の実行型ガイドであり、専用の長編ストーリーやNPC会話キャンペーンではない。職業スキルツリー全体や全武器種、無限に増える手作りダンジョンを完成させたものではない。100時間の継続率・経済成立・多数同時接続・実機での見た目の完成度は未保証。起動中の以前の環境を差し替えたり、Creatorの代わりにMinecraftを操作したりしていない。

重要な入口は `CoreJourney`（成長ルール）→`CoreAccountService`（永続操作）→`CoreLoopServer` / `CorePlayerCombat`（実行）→`CoreLoopMenus` / `CoreHudLayout`（表示）。不具合時は保存エラーなら `CoreAccountRepository` と `CORE_TRANSACTION_FAILURE` / `CORE_REWARD_RETRY`、UIなら `CoreLoopMenusTest` のスナップショットから確認する。
