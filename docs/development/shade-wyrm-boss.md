# 黒翳竜（shade wyrm）— Blockbench最初のボス

決定D12（Blockbench＋WSEE）で作る最初のボス。制作手順は [boss-model-pipeline.md](boss-model-pipeline.md)。

## 姿と雰囲気（独自デザイン）

- 黒い翼膜を外套のようにまとい、翼の腕（翼脚）で歩く四足の竜。目がなく、頭の2本の長い触角で獲物を感じ取る。
- 体から「翳鱗粉（えいりんぷん）」という薄紫の鱗粉を落とす。技の多くはこの鱗粉と触角の感知を表す。
- 怒ると後脚で立ち上がり、外套の翼膜を大きく開き、頭から2本の角が伸びる（以後、翼を開いたまま動く）。
- 名前・形・技名は既存作品から取らない。参考にしたのは「盲目・翼脚・鱗粉・怒りで翼と角」という雰囲気だけ。

## 技とフェーズ

フェーズは既存の `maximumHealthRatio` をそのまま使う（HP50%以下で第2段階の技が解禁）。予兆は既存の地面予兆（MobGroundTelegraph）で、名前欄に「技名・避け方」を出す。

| id | 名前・避け方 | 形 | 予兆→硬直(ms) | 種別 | 段階 |

| shade-sweep | 翼脚薙ぎ・背後か距離を取れ | 扇 半径7・180° | 1100→900 | 物理 | 1〜 |
| shade-pounce | 飛びかかり・大きく横へ | 前方帯 5.5×6（両手の踏みつけ） | 1400→1200 | 物理 | 1〜 |
| shade-dust | 鱗粉炸裂・竜から離れろ | 竜の周りの円 r8.5（体から鱗粉が広がって爆発） | 1700→900 | 魔法 | 1〜 |
| shade-pulse | 触角の共鳴・竜から離れろ | 竜の周囲 r4.6 | 1200→1100 | 魔法 | 1〜 |
| shade-breath | 翳の吐息・大きく横へ | 前方帯 18×4.8 | 1600→1000 | 魔法 | 怒り後 |
| shade-storm | 鱗粉嵐・竜の懐へ | 外周リング r4〜15（内側が安全） | 2200→1300 | 魔法 | 怒り後 |
| shade-turnsweep | 振り向き薙ぎ・距離を取れ | 扇 半径6.5・180° | 900→900 | 物理 | 1〜（名指しのみ） |

- **怒り（HP35%で1回だけ、2026-10-19に50%から変更）**：攻撃を中断し、2.6秒その場で咆哮（攻撃しない＝殴るチャンス）。翼を開き角が生え、以後は速く、吐息と鱗粉嵐を使う。
- 怒り後の「鱗粉嵐」は距離を取るほど危ない。近接の踏み込みと、遠距離の「吐息を横に避ける」を両方要求する。
- 帰還（リーシュ外）で体力は戻るが、怒りの見た目は戻さない（未決事項）。

## 技の合間の動き（2026-10-17、藍「もっと動き回るように」）

技が出せない合間に、モデルのあるボスはプレイヤーの周りを動く（`QuestEncounterCombat.startManeuver`）。動いている間もモデルはプレイヤーを向く。ワイルズのゴア（噛みつき前の歩き・ダブルダート・サイドダイブ）を参考に、跳ねずに低く重く。

| 動き | いつ | サーバー | クリップ |
|---|---|---|---|
| 跳び退き | 3.5ブロック以内に入られた | 0.28〜0.68秒で約4ブロック後ろへ運ぶ | `hop_back`（1.1秒、一度の羽ばたき） |
| 横移動 | 4〜10ブロック | 1.6秒、周りを回る点へ歩く（速さ0.62倍） | `strafe_l`/`strafe_r`（横歩き、足は地面に固定） |
| 回り込み | 4〜10ブロックで3回に1回 | 0.2〜0.5秒で約5ブロック横へ運ぶ | `dash_l`/`dash_r`（0.9秒、地面すれすれの突っ込みと振り向き） |

| 振り向き薙ぎ | 攻撃中に背後へ回られ、動けるようになった時に0.6秒以上背後にいる | 技 `shade-turnsweep`（扇 半径6.5・180°、名指しでだけ出る） | その場で一気に振り向き背後をなぎ払う |
| 跳び退き→吐息 | 怒り後の跳び退きのあと | 吐息を必ず続ける（待ち時間を無視） | |
| 回り込み→薙ぎ | 回り込みのあと | 翼脚薙ぎを必ず続ける | |
| 飛び上がり急降下 | 12〜30ブロック離れている | 技 `shade-dive`（狙った相手の位置の円 半径4.5）。1.0〜2.3秒で体を落下点の上へ運ぶ | 飛び上がり・空中で羽ばたき・頭から突っ込む |
| 探りの歩み | 14ブロックより遠い、または見えない | 速さ0.3倍 | `search`（低く這い、頭を左右に振る） |

- `_l` はボスの右（WSEEがBlockbenchのXを鏡映するため）。怒り後は `_enraged` 版。
- 歩きは歩幅と周期をサーバーの速さ（0.13ブロック/tick、怒り後×1.2）に合わせ、足が滑らないようにした。

## 3段階と新しい行動（2026-10-19、藍「もっと動き回る・5分飽きない・行動を増やす・怒り形態は3段階目で」）

| 段階 | HP | 見た目 | 増える技 |
|---|---|---|---|
| 第1段階 | 100〜70% | 今の姿 | 薙ぎ・飛びかかり・炸裂・共鳴・急降下・噛みつき3連 |
| 第2形態 | 70〜35% | `awaken` の咆哮（3秒、攻撃しない）の頂点で紫の筋が光る（WSEEのテクスチャ状態 `frenzy` = `shade_wyrm_frenzy.png`。光る画素はアルファ251で、パックの `item.fsh` が自分で光らせる）。速さ×1.1 | しっぽ回転・角の突き上げ・鱗粉弾 |
| 第3段階 | 35%〜 | 今の怒り（扇・角・紫の波） | 吐息・鱗粉嵐 |

- **噛みつき3連**（帯5.5×1.6、0.7・1.15・1.6秒の3回とも当たる＝`MobAbility.earlyHitsMillis`）、**しっぽ回転**（周囲 r6）、**角の突き上げ**（帯4.5×1.8）、**鱗粉弾**（狙った位置 r2.8、1.2秒で口から放ち1.8秒で着弾、落ちた所に鱗粉だまり）、**背後への尾打ち**（背後0.35秒で、振り向かずに後ろを扇 r6・±70°。さらに居座ると振り向き薙ぎ）。
- **飛び移り**（`relocate` 3秒、0.7〜2.3秒で闘技場の別の場所へ8〜20ブロック運ぶ）：最初は15秒後、その後は第1段階26秒・第2形態から18秒ごと。降りたら 炸裂（第1）／鱗粉弾（第2）／吐息（第3）。
- **連携**：噛みつき→しっぽ回転（第2形態から、半分）、角→飛びかかり（半分）。連携しない時は、技のあと必ず動く（横移動・回り込み・跳び退き・飛び移り）。
- HPは2800（1人で約5分の見積もり）。

## 全体レビューの直し（2026-10-19、藍「MH×MMO、突っ立つ・欲張ると痛い」）

- **読み合い**：名前欄は技名だけ（ギミックだけ指示を残す）。技ごとの溜めの音（`WINDUP_SOUNDS`）と、小技は打つ部位の光（`ShadeWyrmShaderFx.cue`）。噛みつき＝頭を左右に揺らし口を開く、角＝深くしゃがむ。
- **振り向きと狙い**：狙っている間の振り向きは1秒に90°まで（`TURN_PER_TICK`、`MobAbilityManager.tick(maxTurn)`）、技の開始は体の向きから。狙いは当たる0.15〜0.25秒前まで追う。噛みつきは噛むたびに向き直して前へ詰める（`driveForward`）。
- **技の選び方**：0.5秒後のプレイヤーの位置に当たる技を3倍、当たらない技を0.35倍（`situationWeight`）、側面ならしっぽ回転、止まっている相手には飛びかかり・鱗粉弾・突進。炸裂は7.5ブロック以内でだけ。
- **張りつきへの罰**：技のあと3.5ブロック以内に居たら6割で回転か共鳴、技のあとに必ず動くのは半分だけ、跳び退きの後は6割で飛びかかり、飛び移り後（第1段階）は飛びかかり。
- **失敗の罰**：大詠唱85・殻は半径22で80（防御無視）、止める量5%・殻7%で9秒、侵食+60。侵食の回復は1秒10まで、発症40＋1.5秒足止め。崩しゲージは6秒後から毎秒5戻る。
- **不具合**：連携が0.35秒の待ちで消えていた／柱の陰で全部当たらない（範囲とギミックは見えなくても当たる、2秒見失うと飛んで回り込む）／引き寄せ・崩しでギミックが消えた／突進は走る体の位置で1人1回／移動は柱の手前で止まる／ギミック表示の片付け、竜の死後のだまり停止／咆哮は空中の技の後。

## 向かってくる竜（2026-10-19、藍「範囲攻撃ばかり・動かない・離れては殴るだけ」→A・B・C）

- **A 技で体ごと動く**（`QuestEncounterCombat.travel`、`TRAVEL`）：飛びかかり（1.12〜1.4秒、相手の手前まで最大8）、噛みつき3連（0.45〜1.7秒、最大3.6）、角（0.85〜1.05秒、最大4）、新しい**突進**（`shade-charge` 3.0秒、帯14×1.8、0.8〜2.0秒で14ブロック走る、半分の確率でもう一度）。当たりは体のいる位置から（突進は走り出した位置からの帯）。
- **B 小技は赤い床なし**（`NO_FLOOR`）：薙ぎ・振り向き薙ぎ・尾打ち・噛みつき・角・しっぽ回転・飛びかかり・共鳴。
- **C 追い込む**：技のあとは必ず動く。10ブロックより離れたら飛んで相手の4ブロック手前へ（`ADVANCE`、8秒に1回まで）→噛みつきか飛びかかり。

## MMOギミック（2026-10-19、藍が選んだ「詠唱を止める」「殻を割る」）

- **翳の大詠唱**（`shade-channel`、第2形態から、目覚めの12秒後→以後40秒ごと）：空中に浮いて翼を広げ6秒詠唱。その間に竜へ最大HPの2.5%を与えると中断→`down`（4秒、攻撃も移動もしない、被ダメ1.3倍）。止められないと急降下して闘技場全体（半径22）に35×Tier、侵食+40。
- **鱗粉の殻**（`shade-shell`、第3段階、怒りの15秒後→以後45秒ごと）：丸まって扇で繭のように包み、殻（シェーダー表示）が12秒。殻の耐久は最大HPの4%で、その間のダメージは殻に入る（竜のHPは減らない）。割ると殻が砕けて`down`。割れないと周り半径10に40×Tier、鱗粉だまり6つ。
- 画面上にボスバー2本（残り時間・止める量／殻の耐久）。ギミックは連携技より先に出る。`QuestEncounterCombat.knockDown`・`tickGimmickBars`。

## ギミック（2026-10-18、藍が選んだ4つ）

`ShadeWyrmGimmicks`（侵食・だまり）と `QuestEncounterCombat.breakParts`（部位破壊）。数字は案のページの値。

- **鱗粉の侵食**：鱗粉の技（炸裂・共鳴・吐息・嵐）に当たると+20、だまりの中で毎秒+8。100で発症（25×Tier倍率のダメージと鈍足III 3秒）して0へ。竜を殴るたび−6、5秒溜まらなければ毎秒−2。ボスHPバーの下に2本目の紫のバーで出す（コアHUDがアクションバーを使うため）。
- **鱗粉だまり**：炸裂のあと円の中に4つ、吐息のあと帯に沿って3つ（半径1.8・25秒・最大8つ）。触角の共鳴の当たる瞬間から0.8秒後に全部爆ぜる（半径2.5、15×Tier倍率）。
- **怒りの角を折る**（怒り後のみ。怒る前の触角は折れない＝藍の判断）：正面60°以内・頭から6ブロック以内で与えたダメージが最大HPの12%で、角の先（`horn_?_tip`）が消え、3秒怯む。その後20秒は狙いが最大3ブロック左右にぶれる。
- **怒りの扇を壊す**：横（向きから45〜135°）から与えたダメージが左右別に10%で、その側の破れる板（`cloak_?_tatters`、外側の羽根に散らばる板）が消え、2秒怯む。右の扇（`_l`）が裂けると翼脚薙ぎ・振り向き薙ぎが半径4.5に縮む。両方裂けると鱗粉嵐を使わない。
- 壊れた瞬間は技を止めて `flinch` クリップ（のけぞって頭を振る）を出す。

## 読んだ人に殴る時間を（2026-10-19、藍「読んで避けたり攻撃できる時間を評価して殴らせたい」）

モンハン（技ごとの後隙・空振りの隙・怒りで隙が短い）、MMO（長い技の最中も安全な場所）、ロストアーク（光る溜めにカウンター）を参考にした。

- **後隙**：技の終わり（clipの硬直）のあと、さらに立ち止まる時間を足す（`OPENING`）。小技0、噛みつき0.4秒、飛びかかり0.7、炸裂0.9、吐息1.2、嵐1.0、突進0.6、急降下0.9 秒など。この間は振り向かず、動かず、次の技も出さない（ギミックだけは待たない）。
- **怒りで短く**：第2形態は×0.85、怒りは×0.6（後隙の足し分だけ）。
- **空振り**：誰にも当たらなかった技（10ブロック以内に誰かいたとき）と、無敵回避にしか当たらなかった技は「空振り」でよろけ、+0.8秒（飛びかかり・突進・急降下・角は+1.5秒）。連携には繋がらない。
- **張り付きへの反撃**：技の直後に6割で返すのをやめ、後隙が終わってから3割、必ず溜めのあるしっぽ回転か共鳴で返す。張り付かれている時に離れる割合は5割→2.5割。
- **安全な場所**：鱗粉炸裂は真下（半径2.5）が安全（嵐は元から内側4が安全、吐息は横と後ろ）。
- **光る溜め（カウンター）**：飛びかかり・角・突進・吐息は、溜めの途中で頭が白く光り鐘の音が鳴る（0.55秒、体が動き出す前まで）。その間に崩しの技（CCのある技）を当てると2.5秒倒れる（被ダメ+30%）。

## プレイヤー側の決まり（2026-10-19、レビュー④）

回避の無敵・出し切り・怯み/吹き飛び・部位倍率・職業ごとの崩しは docs/game/combat-principles.md の「回避」「動きながらの攻撃と被弾」「技選びの手応え」。竜側では、頭×1.25・しっぽ側×0.8（`QuestEncounterCombat.partMultiplier`）と、大詠唱/殻の間の崩し技が止める量に入る（`CC_CAST_HARD/SOFT`）。大詠唱85・殻80はTRUEなので回避の無敵では抜けられない。

## 当たり判定（2026-10-19、藍「頭や羽に当たらない、足も」）

`ShadeWyrmHitbox` の球（体4・首2・頭2・しっぽ4・足12、怒る前は翼36、怒った後は扇20）を骨に貼り、毎回骨の今の位置から作る（`CombatTarget.parts`）。剣（`greatswordInRange`→`meleeHit`）、遠くからの攻撃と地面狙い（`rayHit`）、範囲の技（`distanceTo`）がすべてこの球で当たりを見る。球の位置はモデルの立方体から自動で当て（k-means）、頭だけ手で大きくした。近接の距離上限は、モデルのボスだけ竜の中心から13ブロック。絵は `scripts/boss_preview/hitclip.py`。

## アリーナ「翳の巣」

既存の専用ボス闘技場（半径22の円・4本柱）と同じ形。夜。磨いた凝灰岩の床（紫の光を映す明るさ）に、スカルクの吹き溜まり、紫水晶の染み、8ブロック格子の泣く黒曜石（明るさ10の弱い明かり）。柱の頂は真珠色フロッグライト。

### 紫の光（2026-10-19、26.3の機能）

- **怒りの波と紫の光**（藍「怒ったら竜から波動が広がって周りが紫に」）：翳の巣だけ専用の次元型 `projects:shade_nest`（`BossArenaFactory.registerDimensions`、サーバー起動時に登録）。普段は普通の夜。怒りの咆哮（怒りの2.5秒後、立ち上がる所）で `QuestEncounterCombat.tickRageWave` が、竜から闘技場の壁（半径22）まで1.2秒で広がる紫の輪（シェーダー表示2重）と、輪の先頭に光ブロック（13）を出す。同時に専用の時計 `projects:shade_rage` を動かし、その時計に乗せたタイムライン（0tick＝普通、24tick＝紫：ブロックの光の色#b34cff・環境光・霧・空の光）で、波が壁に届くのと同時に紫になりきる。色は闘技場全体で一緒に変わる（場所ごとには変えられない）。
- **技の光**：`ShadeWyrmLights` が見えない光ブロック（`minecraft:light`）を空気の所にだけ置き、時間で消す。炸裂（真ん中13＋周り11、0.7秒）、飛びかかり・吐息（帯に沿って12、0.9秒）、薙ぎ（弧に12、0.5秒）、だまり（10、だまりが消えるまで）、だまりの破裂（14、0.6秒）、侵食の発症（12）、怒りの角（12、角について動く。折れると消える）。
- **にじみ**：闘技場にいて竜が生きている間、`PostEffectsPacket` でポストエフェクト `projects:shade_glow` を出す（パックの `post_effect/shade_glow.json` と `shaders/post/shade_glow_*.fsh`、`scripts/shaders/post/` から `build_boss_vfx.py` がコピー）。画面の明るい紫だけを抜き出し、細い・太いぼかしを重ねて画面合成。バニラの上書きではない。
- プレビュー：`fightclip.py <dump> t0 t1 out.gif before|violet|glow|rage [倍率]`（`lightfx.py` が光の式とにじみをCPUでまねる）。実機未確認。
