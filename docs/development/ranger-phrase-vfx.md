# レンジャー10技の射撃・矢雨・罠

2026-09-08 / `play/gyai/class-combat-rework`。全エフェクトの品質目標は未達。

## 技ごとの構成

| 技 | 演出 |
|---|---|
| 狙い射ち | 手元で引く矢、射線終端の短い矢、射線に沿ってほどける16コマのピクセル残光 |
| 霜矢の扇 | 正面5方向の氷矢と残光。通常の全周霜波とは別の形 |
| 矢の嵐 | 各攻撃波の前に6群・計18本が降下し、着弾後に羽根が舞う |
| 後退射撃 | 後退後も照準方向へ撃つ。転移門は使わない |
| 貫き矢 | 鉤のある矢尻と、サーバーが渡す最後の対象までの射線 |
| 狩猟罠 | 左右の半円の顎と歯。各実判定で閉じて開放し、内側に毒滴 |
| 獲物の印 | 発射時は矢だけ。確定命中した敵で4つの角印が内側へ寄る |
| 速射 | 1判定ごとに1発の矢。3判定を1枚の矢へまとめない |
| 終の一矢 | 長い構え、強い矢と太めの残光。汎用の魔法爆発音を使わない |
| 狩場の支配者 | 1波8群・計24本の広い矢雨。6回の実判定で落下位置も変化 |

## 判定と見た目の境界

射撃のゲーム判定は従来どおり即時。演出のために遅い弾を飛ばして命中を遅らせない。
矢は判定時に6tickだけ見せ、残光は18〜28tickの中で形を変えながら射線の先へほどける。
全モデルの進行軸を0〜16に正規化し、上向き・下向き・至近距離でも
サーバーが渡す壁で切られた射線からはみ出さない。

矢雨は既存のPREPAREで降下、PULSEで同じ場所へ着地する。
着地点・向き・矢の長さを共通計算し、各群の中心の矢先が地面から0.12の位置へ届くようにする。
1つの表示に3本を組み込み、表示エンティティ数を増やさず密度を出す。
攻撃波を別タイマーで増やさず、既存の `pulse` ごとに配置を変える。
罠の顎は実PULSEごとに8tickの開閉だけを持つ。次の波のPREPAREでは重複した罠を作らない。
毒の付与・ダメージ・回数・移動距離・クールダウンは変更していない。

## 主な処理とファイル

`CorePlayerCombat` の既存PREPARE / PULSE / CONTACT → `CoreSkillChoreography.parts`
→ `CoreRangerChoreography` → `CoreSkillChoreography.pose` → `CoreCombatMeshes`。

最初に見るファイルは `CoreRangerChoreography.kt`。
射撃は `draw` と `parts`、扇は `fan`、落下は `rain`、罠は `snare`、実命中は `contact`。
形は `scripts/build_core_combat_models.py` の `ranger_arrow` と `build_ranger_phrases`。
音は `CoreSkillAudio.kt` のレンジャー専用分岐。

矢柄・4枚の羽・鏃を持つ独自のMinecraft立体モデル、変形する射線残光16コマ、
罠の顎、羽根片、4分割の標的印を作った。射線残光は独自生成のPNG連番へ置換。
原画・プロンプトは `assets/combat-vfx/shot-wake-pixel-v1.md`。外部ゲームの画像取り込みはない。
既存UI・フォント・スキルアイコン・クライアント側コードは変更しない。
本人48体・シーン384体の上限を維持。今回の1演出は最大16体。
他人向けには扇の5本の残光と主矢3本、矢雨の主群6〜8個を残す。

## 検証と残件

即時射撃と残光の寿命の分離、16コマの参照、短い／垂直な射線のモデル頂点、
全矢のPREPAREからPULSEへの連続性、各波の配置変化、前方5方向の扇、
実判定だけに従う罠の開閉、実命中だけの獲物の印を追加テストする。
全技全フェーズのモデル参照検査も継続する。

全713テスト（失敗・エラー・スキップ0）と `:server-minestom:distZip` が成功。
連続投影だけの射撃原点を実装と同じ高さ1mへ修正後、専用8テストも再実行して成功。
この原点修正は検証用の出力のみで、ゲーム本体の射撃原点は変更していない。

ピクセル残光追加後は全715テストと配布ビルドが成功。
最後の粒度・区間重なり調整後も関連54テスト（失敗・エラー・スキップ0）と
`:server-minestom:distZip` が成功。7技29tickの配布モデル投影で、
初期の連続した光と後半の破片を確認。投影スクリプトはモデル内のZ回転と
部分UVも読むよう修正し、交差面や端の切り詰めを省略しない。

射撃の残光に使っていた細い連続立体線は廃止し、3階調・2×2画素の塊を持つ
16コマのテクスチャへ変更。長い射線では約2mごとの区間へ分けて交差面を配置し、
境目を重ねる。手元側から先に崩れ、1射線1表示のまま壁の外へは伸ばさない。
古い12コマ×2色の残光モデルと対応アイテム定義（48ファイル）は削除。Git履歴から復元可能。
連番画像の画素・透明境界・破片への減衰、区間数・交差面・UV範囲も検査する。
実機での完成判定は未実施。矢や罠の立体形状と、ドット絵による表現を区別して評価する。

配布モデルと実座標による連続投影はMinecraft画面ではない。
連続投影はカタログの基準startupと8tickごとの実装周期を使用する。
装備による攻撃速度補正、通信遅延、表示予算による省略はこの投影には含まない。
実機の地形遮蔽、一人称の見え方、多人数の同時射撃・矢雨、音と最終的な手触りは未確認。
