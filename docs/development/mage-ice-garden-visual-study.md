## 一つの案：「氷の芽吹き」

地面全体を白く光らせる代わりに、暗い霜の根から5か所の氷の結晶群が育つ。
中心には高い結晶を置かず、術者と敵が横切る空間を残す。
結晶群は太い暗い側面と短い淡色の先端を持ち、小さな白線に見えない形にする。
途中に低い芽も置き、離れた5群が同じ庭から生えていることを示す。

| 時間 | 演出の役割 | 試作の表現 |
|---|---|---|
| 0–0.3秒 | 準備する場所を読む | 現行の支持床の角をそのまま使う |
| 0.3–0.85秒 | 一度だけ形成する | 有効境界は即時に見せ、低い芽と結晶群だけが中心から育つ |
| 形成後–5.3秒 | 他の術を使える場が残る | 床と結晶は静止。反復点滅・回転・粒子の常時噴出はしない |
| 初回の受理命中から0.5秒 | 敵が庭に触れたことを読む | 足元の小さな根が割れ、局所の5片が飛んで落ちる |
| 5.3–6.3秒 | 残り1秒を読む | 色を抑え、先端を折り、結晶の背を約半分にする |
| 6.3–6.8秒 | 効果終了を読む | 有効境界と青を消し、結晶群にだけ少量の無彩色の欠片を残す |

形成の遅れはダメージ波ではない。0.3秒の展開時点で全支持床の境界が読める。
初回接触は現在の「最初の受理命中」から発生する案であり、再入場で無限に派手になる案ではない。
終了片にはdamageもslowもない。壁・衝突・root・敵の封じ込めを意味する造形にしない。
