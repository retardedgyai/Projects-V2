# 吸引の鎖・魔力障壁の展開

2026-09-08 / `play/gyai/class-combat-rework`。全技の品質目標は未達。

## 変更

- 集束: 外周4本の鉤＋中心へつながる4本の立体鎖。地面の大きな渦図形は撤去。
- 空間圧縮: 外周6本の鉤＋6本の立体鎖。実際の攻撃波ごとに内向きに引き絞る。
- 魔力障壁: 胴の周囲で開く4枚の面。正面に照準を通す隙間を残す。
- 吸引の音は鎖＋引き戻し、魔力障壁は共鳴＋防御音。既存の演出濃度設定に従う。

新素材は `build_pull_chains` が作るMinecraftモデル。1〜12節のバリエーションがあり、
交互に向きが違う中空の立体リンクを使う。新規PNG・外部素材・クライアント改造はない。
距離に応じて節数を選び、少数の巨大な輪を引き伸ばさない。

## 処理の流れ

サーバーの攻撃波 → `CoreSkillChoreography.chainPull` →鉤の軌道 →
`pose` が同時刻の鎖の中点・長さ・向きを再計算 → `CoreCombatMeshes` のItemDisplay。
鎖は端点を中心と鉤に固定する。見た目だけの物理演算や追加の命中判定は持たない。
本人上限48・シーン384を維持。通常吸引は8体、大技は12体。
他人向けの主層8体で鉤だけにならないよう、最低4組の鉤と鎖を主層として扱う。

障壁は `arcaneWard` が4枚を胴の内側から開く。既存の本人追従を使う。
防御バフ時間や衝突を変更せず、発動時の展開演出として扱う。

鎖の立体体積、障壁の展開と正面の隙間を確認する。
