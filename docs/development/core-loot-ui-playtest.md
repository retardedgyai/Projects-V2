# ProjectS コアループ：装備MOD・戦利品・UI拡張

対象：`play/gyai/astra-core-loop`。既存の素材・採取・T1〜4製作・ランダムマップを維持した追加実験。
**クライアントコード・protocolは変更しない。Vanilla 26.2とサーバー配信の任意リソースパックだけで動く。**

## 今回つないだ一周

港の冒険の手帳 → 地図台 → 遠征 → 敵・精鋭・ボス／隠し宝箱 → 戦利品へ近づいて回収
→ 港へ帰還 → 刻印工房 → 武器／防具へMODを装着 → 数値・スキル・属性効果が変わった装備で次の遠征。

採取 → 精製 → 装備Tier更新の動線も存続する。防具は従来どおりセット1つの扱いで、
見た目の4部位にMOD効果を4重計上しない。T1/T2/T3/T4で各装備1/2/3/4枠を持つ。
Tierとレアリティを対応させたのはこの実験の暫定判断で、旧仕様の独立した2軸を確定変更するものではない。

## 追加したもの

### 装備MOD：16種類 × T1〜4

旧資料に効果の記載があった11種類：剛力（攻撃力）、疾撃（攻撃速度）、技力（スキル威力）、
集中（CD短縮）、会心（会心率増加）、痛撃（会心倍率）、連撃（通常攻撃）、速詠（発動短縮）、
火炎、氷結、雷鳴。

独自追加5種類：魔力（最大マナ）、循環（マナ回復）、生命（最大HP）、守護（被ダメージ軽減）、軽歩（移動速度）。
名前、数値幅、ドロップ率、加工費用、T4の値は今回の仮設計。

- 火：追加ダメージ＋3回の燃焼。氷：追加ダメージ＋2秒の減速。雷：追加ダメージ＋近くの別の敵1体へ連鎖。
- 敵の弱点と一致する属性を持つと、最初の命中に弱点倍率を適用。二次効果は再帰連鎖しない。
- ダメージ数字・会心・弱点のフィードバックを短時間のTextDisplayで表示。
- 同じ装備の中へ同種MODを重複装着することはできない。武器と防具に1個ずつは可能。

詳しい範囲・旧資料パス・計算上限：[装備の刻印石・戦利品仕様](core-affix-loot-v0.md)。

### 敵と探索

- 通常兵、盾兵、距離を取る術師、精鋭の狂戦士。地図seedによる混成。
- ボスは執行官・鉄壁の守護者・裂け目の預言者の3種。攻撃形状、移動、HP低下時の技が異なる。
- 通常敵は必ず刻印粉＋戦利品券。35%で刻印石1個。精鋭は2個、ボスは3個確定。
- 元からある発見地点へ、右クリックで開く可視の宝箱を追加。近くに敵が残っている間は開けられない。
  宝箱からは精鋭相当の刻印石2個＋粉＋戦利品券。
- 戦利品は名前・アイテム表示・音・光で見せ、近づいて回収する。帰還／切断時は残りも自動回収する。
- 薄い赤い面のAOE予兆を復帰。追尾→固定→発動→消滅。サーバーの命中形状と同じ定義を使い、
  表示に失敗する場所・同時表示上限を超えるときは攻撃を開始しない。

全敵・技一覧：[敵コンテンツ仕様](core-encounter-content-v0.md)。

### 刻印工房

冒険の手帳の中央、通常工房、素材倉庫から刻印石保管庫へ移動できる。
石の保管庫はページ切り替え付き。Eインベントリの石を武器／防具へ重ねても装着確認を開ける。

- 空き枠へ付与：無料。石を装備へ移動する。
- 上書き：古い石は刻印粉になる。**石は失われるため確認画面に効果と変換数を表示する。**
- 抽出：粉を消費して装着中の石を戻す。残したいMODは上書き前に抽出する。
- 再抽選：粉＋同Tierの石材で数値だけ再抽選。値が下がる可能性も事前表示。
- 分解：不要な石を粉へ変換。確定前に消失を明示。
- 保管庫256個を超える新規ドロップだけ粉へ変換。既存の石を削除しない。

## UIと表示

- 以前のProjectSの4レア度ツールチップ枠と性能アイコンを再利用。
- 装備名は上中央、本文は左。COMMON等とMOD見出しは太字。
- MOD効果、数値範囲、品質%、アイテムレベル、内部Tierを常時表示。Shift操作は不要。
- 港の全6行メニューをcharcoal／goldの共通パネルへ。Minecraftの通常スロット・クリック位置は変えない。
- HP・マナゲージ、3スキルのアイコン・操作番号・残り秒数・再使用ゲージをアクションバーにまとめる。
  Vanillaで提供できる固定の表示位置を使い、クライアントMODのHUDレイアウト機構は取り込まない。
- HPはサーバー独自値。Vanillaのハートは10個のまま割合表示し、大量のハートで画面を埋めない。
- リソースパックは任意。適用成功の通知を受け取った接続だけ専用グリフを使い、拒否・失敗・破棄時は通常日本語に戻す。
  日本語・英字の標準フォントそのものは置き換えない。

参考：[Hypixel Ravengard公式紹介](https://hypixel.net/threads/dev-blog-13-a-look-at-ravengard.6023553/)、
[公式プレイテスト案内](https://hypixel.net/threads/ravengard-0-1-public-playtest-weekend.6104973/)。
技能画像3個は[UnofficialMonumentaMod](https://github.com/Njol/UnofficialMonumentaMod)から再利用。
クライアントMOD本体・コードは取り込んでいない。出典・配布条件はパック内にも同梱。

## 保存と失敗時

既存`.account`は初回更新時にv1の原文を`.account.v1.bak`へ保存してからv2へ移す。
表示アイテムの数ではなくUUID付きの台帳が正本。保存成功前に報酬を消さず、同じ敵／宝箱の再通知は二重計上しない。
帰還開始時には戦闘・採取・開封を停止し、戦利品の回収と保存完了を待って遠征を終了する。
強制プロセス終了・電源断時の未回収／保存前のインメモリ報酬までは保証しない。

重要な入口：`CoreLoopServer.kt`（動線統合）、`CoreAffixCatalog.kt`（MOD定義）、
`CorePlayerCombat.kt`（実際の効果）、`CoreLoopMenus.kt`（工房）、`CoreUiPackServer.kt`（配信）。
問題があれば`server-minestom/run/core-loop-*.log`と`.error.log`の`CORE_UI_PACK`／`CORE_REWARD_RETRY`から確認する。
