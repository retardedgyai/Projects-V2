# 防具4部位（Issue #144）

防具は頭・胴・脚・足の4個の装備として、サーバーのアカウントに保存する。各部位は識別番号、Tier、品質、レアリティ、MOD、強化値、破損状態を個別に持つ。制作、装備交換、強化、鍛錬、修理、売買も対象部位を指定する。武器は従来通り1枠。

## 旧セーブからの移行

- v10以前の装備中の防具一式は4部位へ展開する。胴は元の識別番号を維持し、ほかの3部位は元の識別番号から決定的に導出する。Tier、品質、レアリティ、強化、破損、装備Lvを引き継ぐ。既存MODは胴だけに移し、効果を4倍にしない。
- 保管中の防具一式も4個に分割する。胴が元の識別番号を維持する。出品中だった一式は自動で出品を取り下げる。旧「防具一式」の購入注文は預託中の銀貨を返して取り消す。返金で銀貨の上限を超える注文だけは旧注文のまま残し、銀貨を使ったあとに注文画面から取り消せる。旧注文は新しい1部位の購入には転用しない。
- v2の防具MODも胴へ移し、隠れた旧「防具一式」MODを残さない。
- 読み込みだけでは旧セーブを書き換えない。最初の保存で元ファイルを `.v10.bak` として残し、v11を保存する。導出した識別番号は再読み込みしても同じ。

## 戦闘への反映

最大HPと防御値への基礎寄与は、頭15%、胴40%、脚30%、足15%の重みで合計する。同一性能の4部位をそろえた場合は旧防具一式と同じ値になる。破損した部位はその部位の追加性能とMODだけを失う。

## 手動確認

1. 本編サーバーとVanillaクライアントを起動し、港の鍛冶師を右クリックする。
2. 工房左側で頭・胴・脚・足を順に選び、中央の名前と右の費用・成功率が選んだ部位に切り替わることを確認する。
3. 1部位を強化し、確認画面・素材消費・結果更新の後、ほかの3部位の強化値が変わらないことを確認する。
4. 装備庫で各部位の装備、制作、MOD、修理、保管品との交換を確認する。
5. 旧データを使う場合はバックアップと移行後の4部位・銀貨返却を確認する。

最終的なMinecraft上の見た目と操作感はCreatorが判定する。
