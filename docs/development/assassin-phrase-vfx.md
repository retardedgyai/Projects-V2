# アサシンの刺突・毒・離脱の演出

2026-09-08 / `play/gyai/class-combat-rework`。全エフェクトの品質目標は未達。

## 今回の6技

- 影刺し: 近い位置から短剣が前へ突き出る。残光の後端は発動地点、先端は短剣に固定。
- 追影: 同じ短剣の動作に、左右の加速残光を追加。移動距離で刃を巨大化しない。
- 死の契約: 太い一本の刃と4方向の刺突残光。回転斬撃や汎用の発動爆発音にはしない。
- 毒牙: 左右の鉤状の牙が独立して閉じ、5粒の毒液が飛び出して落下する。
  汎用の緑色の剣の斬痕は外す。実際の命中点にも毒滴を出す。
- 影抜け: 出発地点では影の裂け目が閉じ、到着地点では開く。
  裂け目は早く消えるが、3層の煙は高さ・方向・時間差を持って上がり、裂けて残る。
- 残像: Minecraft体形の2つの人影が左右・後方へずれ、体の形を崩しながら4層の煙へつながる。
  煙の主層2つは本人から見える手元の左右前方、残りは人影の側に置く。
  本人に追従する盾や、一枚の人型マークの表示ではない。

## 素材と実装

影煙は imagegen スキルで生成した専用の16コマ原画。
原画・採用元・全プロンプト・インポート条件は `assets/combat-vfx/shadow-smoke-pixel-v1.md`。
人影8コマ、刺突の残光、左右の鉤牙、立体の滴は `build_assassin_phrases` が作る独自モデル。
UI・既存の職業アイコン・フォント・クライアント側コードは変更しない。

実スキルのPREPARE / PULSE / CONTACT → `CoreSkillChoreography.parts` →
`assassinThrust` / `shadowDeparture` / `venomBite` → `pose` → `CoreCombatMeshes`。
刺突の残光は毎フレーム先端と長さを計算し、刃から離れないようにする。
煙と人影はコマを切り替えながら位置・角度も変える。全体を縮めるだけではない。
影抜けの消失点・到着点は既存サーバー処理が渡す2地点を使用する。

毒の継続ダメージは `CorePlayerCombat` の既存 `burns` と `CorePoisonEffect` が担当する。
今回の毒液は発動・実命中の見た目だけ。毒の付与、攻撃回数、ダメージ、移動距離、
クールダウン、防御時間は変更しない。追加のゲーム判定や独立タイマーは作らない。
本人48体・全体384体の上限を維持。今回の1演出は最大7体。

異常時はまず `CoreSkillChoreography.kt` の上記3関数。
先端のずれは `pose` の `piercing_wake`、煙は `SHADOW_SMOKE`、立体形状は
`scripts/build_core_combat_models.py` の `build_assassin_phrases`、音は `CoreSkillAudio.kt`。
