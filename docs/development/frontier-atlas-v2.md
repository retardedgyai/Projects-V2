# 開拓大陸 v2：地続きの一枚マップ

状態：設計案。v1（海域・群島）を置き換える。見た目の見本はデザインキャンバスの「開拓大陸」。

## なぜこの仕組みがあるか

本当は MMO らしいオープンワールドにしたい。ただ、広い世界を手で建てるのは現実的でない。
そこで、遊ぶ地形は**ランダム生成のマップ**に任せる。
大陸の地図は「どこへ行くか」を選ぶ入口で、場所ごとに意味と時間（季節・期間限定）を持たせる。
こうして、建てなくても世界が続いている感覚を作る。

## 大陸の形

- 開拓港（拠点）を手前の海岸に置き、奥へ行くほど危険になる。敵Lv の帯は場所ごとに決める（例：風見の丘 1〜10、霧氷の城 40）。
- 場所は全部地続き。地形（緑野・桜の森・塩沼・断崖・高地・獄炎の地）は境目が混ざり合う。
- まだ行けない場所は霧で見えない。季節ごとに大陸の縁へ新しい土地を足して、世界を広げていく。

## 場所の種類

| 種類 | 中身 | 地形 |
|---|---|---|
| 拠点 | 開拓港。工房・倉庫・市場・成長。戦闘なし | 固定（手で建てた港） |
| 遠征 | 入るたびに地形を生成。道の先にボス、寄り道あり | ランダム生成（今の遠征マップ） |
| 開拓地 | 区画を買って自分で建築する土地。許可した人も建てられる | 固定の平地 + プレイヤーの建築 |
| PvP | 自分から入った人だけが戦う場所 | 固定の荒野（建築不要の地形） |
| 大陸の主 | 人数 1〜4 のボス戦。週ごとに報酬 | 固定の会場（今の専用ボス会場） |
| 期間限定 | 一定期間だけ地図に現れる場所。終わると消える | ランダム生成 |

## マップからなくすもの

- **採取の石板・地図の採取MOD**：やめる。マップの中身を変えるのは「場所」と「季節」の役目にする。
  - 持っている石板は、戦利品券か素材に換金する。
  - 採取の上限や品質の伸びは、場所の特産（密集地域の出やすさ）と季節の効果に移す。
- **地図アイテム**：v0 と同じく、なくす。場所を直接選んで出発する。

## 期間限定（季節とイベント）

- **季節**：大陸全体に 1 つ（例：桜の季、約 2 週間）。特定の場所の敵とボスが季節限定の品（装備の見た目・刻印・勲章）を落とす。
- **出現地**：季節とは別に、数日だけ現れる場所（例：星降りの結晶地）。限定の鉱石や、建築用の限定ブロックが採れる。期限が来ると消える。
- 画面の左上に「開催中」を出し、押すとその場所へ地図が飛ぶ。

## 建築（開拓地）

- 港の近くの平地を区画に分け、プレイヤーが借りる（1 人 1 区画から）。
- 建てられるのは、遠征や採取で集めた素材のブロックと、期間限定で手に入る建築用ブロック。
- 自分の区画では自由に建築でき、許可した人は一緒に建てられる。それ以外の人は見学だけ。
- 技術：開拓地は永続するインスタンス 1 つ。区画ごとに保存する（Anvil か Polar 形式）。遠征マップと違って、使い捨てにしない。

## PvP（境界の荒野）

- 自分から荒野に入った人だけが対象。港や遠征では起きない。
- 荒野でだけ「季の印」が拾える。倒されると、持っている季の印の半分をその場に落とす。**装備は落とさない**。
- 週ごとに季の印の数で順位を付け、勲章（見た目の報酬）を配る。
- 技術：共有インスタンス 1 つ（人数上限あり）。戦闘の判定は既存の戦闘処理を、プレイヤー同士にも当たるように広げる。

## 保存するもの（個人）

```text
continent.revealed : Set<SiteId>
continent.records  : Map<SiteId, { clears, bestLevel }>
plot               : PlotId?              // 開拓地の自分の区画
season.marks       : Int                  // 季の印（PvP で増減）
season.collected   : Set<LimitedItemId>
```

## 決めること

- 季節の長さと、季節ごとの限定品。
- 開拓地の区画の借り方（買う／借りる／維持費）と、建築に使えるブロックの範囲。
- PvP のルール（人数、季の印の落とし方、順位の報酬）。
- 石板を換金するレート。
