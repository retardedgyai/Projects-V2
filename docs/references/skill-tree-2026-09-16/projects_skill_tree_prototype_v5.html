v5 — 形ではなく経路の違いを作る

v4の問題：二重の円環に同じ4ノードの塊を36個並べていました。能力配置は無作為で、全クラスタが道路からの袋小路。キーストーンは実質的に数値の足し引きでした。

今回の変更：円環を廃止し、不規則に配置した大小のクラスタを局所的な道路網で接続。開いた弧・環・楕円・三叉の分岐・二つの小環を持つ塊を混在させています。入口と出口が複数あるため、短い経路と欲しい能力を拾う経路が一致するとは限りません。

能力には地域の傾向がありますが職業別に封鎖しません。同じ能力も複数の場所へ配置。キーストーンへ一律に余分な3ポイントを払う仕組みは廃止し、性質の交換を記述した6つのルール案にしています。

境界：これは独立したWeb試作です。Minecraft版、サーバーUI、戦闘計算、既存セーブとは接続していません。ルール変更はテキストと相性警告で表示し、ダメージ計算済みとは扱いません。PoEの画像・ノードデータ・座標は使用していません。
