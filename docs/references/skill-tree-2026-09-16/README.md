## 取り戻した構造

- 中央に職別開始位置、その周囲に同じ主目的を育てる3本の序盤ルート。Small → Small → Notableの3点で最初のまとまった能力へ届く。6職×3ルートすべてで、その主目的が最初の3点に残ることを再検査した。
- 広い共通盤面に47クラスタ。形状はoval 8、fork 8、wheel 14、arc 10、double 7。半径の違う円へ15 Keystoneを均等配置する構造ではない。
- Notableはクラスタで目指す強い中核。例「流れる連撃」は攻撃速度+7%と資源獲得+5%の旧仮値。「鎧の内側」は防御+16%とHP+4%。すべてを新しい条件付き技能にする必要はない。
- Keystoneは数値合算とは別に、利益と制約を持つルール変更。例「余波の契約」は近接半径×1.5と直接hit×0.75。原本も実戦計算へ未適用と表示する。
- 移動する接続点は、HP+2%・与ダメージ+2%・資源獲得+3%から1種類を選べる旧案。目的に無関係な固定能力を強制しないための案であり、採用済みの仕組みではない。
- 同じ到達先へ、追加費用・途中の能力・接続点の数を比較する2経路を提示。未取得Keystoneを途中の通過点にする推薦や、他職起点の無料通過を拒否する。
- ブラウザ内で取得、先端返還、孤立させる返還の拒否、戻す／やり直す、配分コードの検証、全返還、パン・ズーム、ミニマップを備える。現ゲームのaccount/ledger/packetとは独立。
