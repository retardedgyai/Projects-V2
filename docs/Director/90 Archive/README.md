# Archive

古くなった仕様、解消済みBlocker、採用しなかった案を置く。

## Rules

- 削除して経緯を失うより、日付と理由を付けて移す。
- 現行SystemからArchiveへリンクし、廃止理由を残す。
- ArchiveをCurrent ContractとしてAIへ渡さない。
- Day 1 plans等の既存history docsは移動せず、[[Director/50 Reference/Source Register|Source Register]]でHistorical分類する。

## Archived Blocker Format

`YYYY-MM-DD — Blocker — 解消方法 — Decision/Issue`
