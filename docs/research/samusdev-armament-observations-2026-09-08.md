# SamusDev 武装・演出の追加観察 — 2026-09-08

## 確認方法と扱い

公開YouTubeプレーヤーで映像を表示し、装備展示と技の区間を静止フレームで確認した。
下記7本は部分確認であり、全編を連続視聴した/全アニメーションや音を精査したとは扱わない。
パーセント位置はプレーヤーの数字キーによるシーク位置。シーク直後に旧フレームが残る場合は、
次の取得で読み込み後の映像を確認してから記録した。動画自体や配布アセットはダウンロードしていない。

この資料は観察と制作判断を分ける。古い作品の表現をそのまま品質の上限にはしない。
最優先の質感基準は、ユーザー指定の [MatE / The Dark Sister](https://x.com/MatE312001/status/2096478906299699459)。
立方体の積み重ねで作る武器へ戻す理由に、ここで見た厚い武器を使わない。

## Phantom Set / The Ghost Reaper

[映像](https://www.youtube.com/watch?v=JxfgI4lBviE) — プレーヤー表示1:51。
確認位置: 5秒、10秒、30%（33秒）、50%（55秒）、70%（77秒）。

観察:

- 5秒の展示は、紫紺の防具、緑色の目、骨色の胸/腰の模様。頭と胴で同じ生物的なモチーフが読める。
- 大きい鎌の刃は正面では幅広い。10秒では向きが変わり、非常に薄い線のように見える。
  元モデルの構造は未取得なので、完全な2D面と断定はしない。
- Phantom Slashの区間には、白〜紫の曲線状の斬撃と、黒/紫の小粒が見える。
- Shadow Curseの区間は敵の周囲の黒/紫の粒が中心。Ghost Wrathの区間はキャラ付近の濃い紫の塊が見える。

制作判断:

- 厚みを増す前に、刃の絵の外周と色面を作る。斜め/側面確認を省略しない。
- 防具の胸と腰は「金の共通ベルト」だけにせず、セット固有の模様とつながりを描く。
- 粒だけの呪い表現は、今回ユーザーが求める明確で派手な技の完成形としては採用しない。

## Prismarine Set / The Ocean Soldier

[映像](https://www.youtube.com/watch?v=hCwsV8O9g_8)
確認位置: 5秒（暗い遷移）、10秒（展示）、30%/50%/70%。

観察:

- 明るい展示では、淡い緑白の面に青緑の大きい色の塊がある。額/頬/胸/足元で色の配置が違う。
- 顔の周囲が開く兜の形、肩と足元の輪郭が読める。
- 刀身は幅広く反り、明るい縁と濃い緑の鍔で構成される。武器と防具が同じ配色でまとまる。
- Prismarine Slashの一人称区間では、手持ちの刀身と前方の青緑の帯状の形が見える。
- Marine Spinの夜の区間では、白い強い光の塊が見える。輝度の一部が撮影シェーダーかどうかは未判定。
- 70%の一人称区間では、縦に大きく見える刀身の色面を確認した。

制作判断:

- 防具の各部位には、その面の立体/材質を表す固有の陰影を描く。共通素材タイルの繰り返しでは代用しない。
- 装飾の細密さより、手持ちサイズでも読める刃の明色帯と、鍔の暗い区切りを先に作る。
- 白飛びする光をVanillaの発光で再現できると推定しない。絵の色面だけでも形が読める設計にする。

## Amethyst Set / The Amethyst Spearman

[映像](https://www.youtube.com/watch?v=tqkiSYae1OQ) — プレーヤー表示1:41。
確認位置: 10秒、30%/50%/70%。5秒は黒い画面のため造形の根拠に使わない。

観察:

- 紫〜青紫の防具に、薄い黄白色の明点が額・胸・膝付近にある。
- 槍の柄は暗く、先端は大きな紫の結晶形。暗い柄が結晶の色面を引き立てる。
- 30%の戦闘区間では、槍の方向に伸びる紫の尖った形と、周囲の白/紫の小粒が見える。
- Amethyst Sparkleは周囲に広がる小さい白/紫の形。
- Shooting Starは、明確な紫の塊を持つ頭部と長い明るい尾が見える。単に同じ点を増やした表現ではない。

制作判断:

- メイジ/星織り師の武器は、柄と頭部を同じ明るさにしない。頭部の空間・結晶の輪郭を焦点にする。
- 星や彗星の技は、頭部・進行方向に沿う尾・補助の小粒を分ける。
  星織り師の「青い点が出るだけ」への改善候補として、彗星の塊と尾の構成を使う。
- これは演出案であり、今回新しいスキルやダメージ判定を追加したわけではない。

## Terra Warhammer

[映像](https://www.youtube.com/watch?v=SvwhqF-z-kE) — プレーヤー表示1:27。
確認位置: 5秒、10秒、30%/50%/70%/80%。

観察:

- 冒頭のインベントリと左上の表示には、青緑の頭部と金色の縁を持つ戦槌がある。
  手持ちの接写は暗く、細部の作画を判断する十分な根拠にはしない。
- Earth Poundの区間では、敵の周りや地面付近の小片を確認した。
- Earthquakeの複数区間では、黄〜橙の芯、赤い大きな曲線/塊、暗い外周、小さい火点が重なる。
  光点を均一に散布しただけとは違い、大きい形と小さい形の役割が分かれている。
- 終盤は敵と地面の近くに複数の赤橙の塊と小片が残る。

制作判断:

- 衝撃系は「主になる衝撃の形」「地面に沿う形」「破片」を分けて用意し、攻撃の向き/場所に合わせる。
- この映像は技の構成の参考にはなるが、戦槌の最終テクスチャ設計を暗い接写から埋め合わせない。
- 土系の技を全クラスへ流用しない。技ごとの形を増やす方針を保つ。

## Class Awakened / Cleric

[映像](https://www.youtube.com/watch?v=c0Qh7vLjruI)
確認位置: 5秒、20%/40%/60%/80%、60%から5秒後。
再生中にSacred Comboの「4th: Heal」表示も観察したが、時刻未記録のため厳密なタイミング資料にしない。

観察:

- Divine Revelationの表示中は足元の金色の輪と、キャラ付近の小さな十字形がある。
- Cruciform Judgementでは、白黄の太い帯が交差し、技の名前に対応する十字の形を作る。
- Bell of Absolutionは大きく見やすい金色の鐘。小粒を見なくても何を出した技か判別できる。
- Divine Cathedralの区間では、地面の大きい紋様、中央の立つ形、周囲の小粒、羽状の形を確認した。
- 終盤には鐘・交差する帯・大きな地面の紋様が同時に見える。同じ金色でも形が異なる。

制作判断:

- ヒーラーの技を全部「金色の円と点」にしない。何を出す技かを示す、固有の大きい形を持たせる。
- 攻撃/回復/継続範囲の主形状を分ける。粒の色だけで用途を説明しない。
- 本の武器も、ページ・綴じ・表紙の模様で聖職者のモチーフを表現する。
  ただし鐘の技やコンボ回復のゲームルールを、この観察だけで既存クラスへ追加しない。
- 撮影時のブルームや本編のメッシュ構成は未確定。Vanillaで同じ発光手段が使えるとは断定しない。

## Samus Cosmetics / VOL 1

[映像](https://www.youtube.com/watch?v=OfEWPNtU9sI) — プレーヤー表示1:00。
確認位置: 5秒、20%から90%まで10%刻み。冒頭の再生中に鶏頭の展示も確認。

観察:

- 5秒は選択インベントリ。20%/30%は青/赤のCyborg Visor、40%はHeadphones。
  いずれも頭全体を覆わず、暗い枠と局所的な明色で装飾位置を示す。
- 50%はTop Hat。暗い帽子に赤い帯。小さい模様を増やすより大きい色の区切りが読める。
- 60%はHelmet of Rage。頭より横に広い曲がった角と、小さい黄色の目。
- 70%はPhoenix Helm。暗い兜から後上方へ長く伸びる黄〜橙〜赤の細い炎形。
  兜本体の厚みと、炎の細く尖る輪郭の見え方が異なる。元メッシュや炎の実装方式は未取得。
- 80%はDragon's Head (Aether)。横に伸びる角、前へ突き出る鼻先、淡い黄白の大きい色面。
- 90%は暗い遷移で、紫色の顎付近だけが見える。ここから詳細形状を推定しない。
- 展示は主に静止した装備台。身体の歩行に対する装飾追従を証明する映像としては使えない。

制作判断:

- 兜の全表面へ同じ明色を置かず、視線を集めたい額・目・角先へ配分する。
- Phoenix Helmのような飾りは、厚い突起を増やすより薄い絵の輪郭を独立させる候補。
  今のヘルメットの共通箱組みを、この動画に箱形の帽子があることを理由に完成扱いしない。
- 帽子の色替えを全職装備の違いの代用にはしない。今回の質感基準はDark Sisterのまま。

## Minecraft RPG Items / VOL 2

[映像](https://www.youtube.com/watch?v=SZ2HjCRNSnc) — プレーヤー表示3:06。
確認位置: 5秒、10%から90%まで10%刻み。

観察:

- 5秒はスキル選択画面。10%の暗い装備展示は、作画の細部を読む根拠として不足。
- 20%はBattledancer / Pathfinder。足元から後ろへ残る、小さい明点による道筋。
  画面にはSpeed (Self & Allies)と表示。効果の正確な時間やゲーム内部処理は未検証。
- 30%はLightbinder / Convergence / Stun。対象の頭上に小さな金色の輪状の点列。
- 40%は同じLightbinderのIncinerator / Burn。前方の縦に長い金色の形と散る粒。
- 50%はGhost Fang / Ghostblades / Poison。手持ちの曲がった黄緑の刃に加え、
  前方へ並ぶ小さい曲線状の刃、緑の丸い模様が見える。60%でも刃の列と緑の模様を確認。
- 70%はTerra Warhammer / Earth Pound。地表の大きい橙赤の塊と暗い輪郭、
  上に浮いた対象、小さい破片。80%はEarthquakeの表示だが大きい発動形は出ていない瞬間。
- 90%は緑の大きな粒が前景に多く重なり、中央のキャラと黄緑の刃が見える。
  その瞬間のスキル名は表示されておらず、技名や発動順を断定しない。

制作判断:

- アサシンの毒は刃の明色と緑の状態表現を別々の形にし、斬撃の進行方向を消さない。
- 複数回の攻撃なら複数の刃が見えることが参考になる。ただし映像の形の数から
  実際のダメージ判定回数は推定せず、ProjectS側の成立済み各判定に合わせて描画する。
- この映像の後半には前景を覆う粒もある。単に同じ密度を再現するのでなく、
  敵の予兆・攻撃の向き・手元の武器が残ることを受け入れ条件にする。
- タイトルにItemsとあっても、防具の歩行アニメーションの根拠にはならない。
  今回追加した2本では、身体の動きへの追従は確認できなかった。

## 現在の実装に対して変わった判断

1. 防具は部品数より先に、部位固有の作画が必要。今の共通縁取り・平たい配色を完成品扱いしない。
2. 武器は正面の絵と薄い側面で成立する例がある。箱組みへの逆戻りは不要。
3. 技は色だけでなく、鎌の弧・槍の尖り・彗星の塊と尾・鐘など、識別できる形を持つ必要がある。
4. 古い作品に粒中心の技があっても、現在ユーザーが拒否した表現を正当化する根拠にしない。
5. 全動画確認、音/動作の連続精査、全職の最終作画と実機確認は引き続き未完了。
