# パッシブツリーの決定記録

2026-10-28、藍「一旦今の決まり全部消そう、0から作る」。2026-09-19 の記録のうちスキルツリーに関わる部分（D09 共通パッシブツリーの方針、D10 β15キーストーン、D11 のツリー画面の方針）は白紙にした。

## 決めたこと

- **型**：Path of Exile 型の、全職で一枚の大きなパッシブツリー。レベルが上がったときに分かりやすく進んだと感じられるものにする。
- **キーストーン**：置く。個数と中身はまだ決めていない（第1版は6枠を「準備中」として置き、取れない）。
- **ポイント**：レベルが1上がるごとに1点（Lv40 で39点）。
- **振り直し**：取るのは無料。戻すと銀貨を消費する（ゴールドシンク）。1点ごとに 銀貨 10×Lv 枚、1つ戻すと先につながった分も戻り、その分も払う。
- **技ごとの改造**：あってもよい（藍）。今回は作らない。

## 今の作り（2026-10-31 時点）

- 配置は `scripts/build_passive_tree.py` が生成する `passive-tree.tsv`（PoE と同じ、群れと軌道の配置）。726ノード（起点6・小535・主要142・極意28・キーストーン15）。Lv70 で 69 点＋ボスの初撃破ごとに1点。
- 画面は地図・Forge と同じカメラ＋表示エンティティの `PassiveTreeFlow`。UI パックがないときだけチェスト型 9×5 の `passiveList`。触れる見本は `docs/proposals/skill-tree-2026-10/screen-prototype.html`。
- 職ごとの古い18ノードの木はコードごと消した（v13 の読み込みで返還済み）。
- セーブにはツリーの指紋（`passive-tree` 行）を書く。ツリーを作り直して指紋が変わると、そのセーブの割り振りは全部無料で返す（番号が別のノードを指さないように）。

## 2026-10-31 ゲーム全体と突き合わせて決めたこと

- **ツリーは全員に平等**（PoE と同じ）。クラス専用のキーストーンやノードは作らない。クラス専用の MOD（余震・反響など）はツリーに入れない。
- **ツリーの値は％だけ**（一旦）。固定値は装備の MOD 側。
- **魔法貫通**をツリーに足す。
- **回復力**は全員が一定の土台を持つ。回復力は「悪用できる」値にする：吸収（ライフスティール）と自然回復にも回復力が乗る。
- **伸ばす値を足す**：CC の時間、CC 抵抗、ボスのブレイク力、継続ダメージ、回避。
- **前のクラス別タレントの残り**（`build.has` / `keystone` の分岐）は消してよい。
- **レベル上限を 70** に上げる（69点）。上がった分だけツリーも大きくしてよい。
- 後で決める：属性値の扱い、クラス資源を伸ばすか、クラス切り替え（キャラクターを替える形にする予定）、上位クラス。魔導師の作り直し（#189）は一旦置く。生産職・地図の進行はツリーと関係させない。

## まだ決めていないこと

キーストーンの個数・中身、ノードの総数と配置の見直し、広いキャンバスの画面、ボスなどでの追加ポイント、技ごとの改造。
