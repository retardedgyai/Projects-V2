## 2. 設計の軸（Creatorの言葉から）

- **ゲームは地面。** メタ認知が強すぎて足場を失った人に、フレームワーク（不必要な障害）で足場を作るもの。
- **好奇心の核は組み合わせ。** 「この数字とこの数字を組み合わせたらどうなる？」が一番楽しい。手触りの作業は、組み合わせにつながる時だけ輝く。
- **目標は与えるが、一本道にしない。** 全員が同じ順番で進むTerraria型にはしない。
- **狩りだけのゲームにしない。** 採取・製造（鍛冶）・魔術などの道を、やりたい人がやる。
- **エゴイストの連合。** 各自が自分の得のために動いた結果、他人の目標が生まれる（アダム・スミスのパン屋）。
- **お金の使い道を装備以外にも置く。** 魔術は資源を買って研究を進め、採取は効率化に投資する。経済を回し、インフレを抑え、戦闘以外の道が戦闘の下請けにならないようにする。
- **苦痛は選んだ人だけが払う。** 苦労の証は売買できないようにする。
- **収益モデル**（2026-10-10決定）：ランク/サブスク・ブースト・見た目の3本柱。サブスクはリアルマネーで買える「アイテム」として売り、使うか市場で売るかをプレイヤーが選ぶ（Hypixelのブースタークッキー型）。強さは変わらない。

各道をレビューするときは「それ自体が楽しいか／自分の目標があるか／他の道とつながっているか／頑張りが見えるか」を点検する。

## 3. 現状（2026-10-14時点）

- **できていること**：市場（出品の預かり・買い注文・手数料5%・オフライン売買）。採取素材は戦闘からは出ない。精製と製造の職業Lv。強化+30（破損あり）。オーブ/MOD。7職。開拓図（大陸地図）、パーティ画面、注入祭壇Playground。最初の魔術（コロニー・異質素材・六角盤の相研究、`/colony`）。
- **足りないこと**：
  - 魔術の研究が経済とつながっていない。研究素材は拾うだけで市場の品目ではなく、解明しても製造レシピや売れる物が開かない。
  - 銀貨の出口（シンク）がほぼ手数料だけで、入ってくる一方。
  - 鍛冶が他人へのサービスになっていない。
  - 道ごとの目標の段階や、市場の検索・価格履歴がない。
  - 課金設計の文書がない。

## 4. 次の優先順位（提案）

1. **経済の一周を検証できるようにする**：蛇口（入口）とシンク（出口）の表、銀貨シンクの追加、取引できる品目の見直し。
2. **魔術の道を main に入れて経済とつなぐ**：研究に買った素材を消費させ、研究の解放で製造レシピが開くようにする。
3. **少人数のテストプレイ**。それまでVFX・UIの磨き込みは控える。
