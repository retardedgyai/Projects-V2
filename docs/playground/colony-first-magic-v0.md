# Colony + First Magic v0

Playground branch: `play/gyai/colony-first-magic-v0`

## 遊び方

1. 港の海側、銅の門の下にある「自分のコロニー」の地図台を右クリックする。`/colony` でも入れる。
2. Main Hut の帰還の帳、Work Corner、Arcane Yard、封印区画を見て回る。
3. 港へ戻り、地図台から遠征する。道沿いで `?` と表示される異質素材へ近づくと自動で回収・保存する。
4. `/hub` または遠征の帰還操作で港へ戻り、コロニーへ入る。持ち帰った素材で研究区画が反応する。
5. 研究机を右クリックして修復し、素材を分析する。分析は素材を消費しない。
6. 蒸留器で研究済み素材を選ぶ。約3秒後に1個消費され、性質ごとのEssentiaがJarへ移る。
7. Jar棚を右クリックして各瓶の量を見る。研究机から魔導記録帳の第一頁も読める。

コロニーの帰還の帳、または `/hub` で港へ戻る。魔術記録は `server-minestom/run/config/projects/first-magic/<UUID>.magic` に保存され、再接続時に読み直される。破損データは上書きせずログインを止める。

## v0の境界

- 1人用固定空間。家具配置・建築・Jarの取り出しは後続。
- 素材6種、性質4種、Jar容量は各16。
- 封印区画は予告のみ。高位儀式・戦闘魔法は未実装。
- 最終の画面構図と手触りはCreatorがMinecraftでManual Smokeする。
