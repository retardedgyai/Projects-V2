ウォーリアーの手触り

2026-11-03。今のコードの全体レビューと、ロストアークのデストロイヤー、モンハン（ライズ・ワイルズ）、Vermintide / Darktide、ドラゴンズドグマ2、ディアブロ4、PoE2 を調べた結果。ここに並べたのはすべて案。技の中身は藍が決める。

結論

技が似ている理由全部が同じ動詞「押す → 大剣を振る → 正面の地面が割れる → 敵が浮く」。違うのは大きさと数字だけ。押し方も全部タップ1回。
デストロイヤーの芯差は「押し方」で付いている溜める・押しっぱなしで走る・押し直して続ける・跳ぶ・吸い寄せる。技ごとに入力が違うので、威力が近くても別物に感じる。
体の硬さ数字は中くらい、実際は脆い守りの手段がなく、回復もなく、「怯まない」技も敵の CC で止まる。デストロイヤーの硬さは「使う技を撃つと障壁」「振っている間は被ダメ減」から来ている。

3. デストロイヤーは何が気持ちいいのか

  • 溜める→吐くが「守り」にもなる。コアを使う技を撃つと、コア1つで威力+10%と最大HP10%の障壁、3つで+45%と30%の障壁。全力の一撃を撃つほど硬くなる。
  • 技ごとに入力が違う。パーフェクトスイングは最大2秒溜めて、踏み込んで叩く。ランニングクラッシュは押しっぱなしで走って、離すと爆発する。パワーストライクは3連の叩きつけ。グラビティインパクトは場を作って吸い寄せる。ジャンピングスマッシュは跳ぶ。
  • 改造（トライポッド）が入力そのものを変える。溜め技が即撃ちになる。通常の技が押しっぱなしになる。走りながら当てる技が、地点まで突っ込む技になる。数字だけの改造は少ない。
  • 振っている間だけ硬い。「振っている間の被ダメ−30〜60%」「押されない」が多くの技に付く。重く遅い技を、安心して振り切れる。
  • 追わずに寄せる。吸い寄せで敵を自分の前に集める。一人称では追いかけるのが一番つらいので、ここは特に効く。
  • 悪い所も参考になる。「遅くて重い」「動けない」「超重力モード中は左クリック押しっぱなしだけ」と言われている。一人称で動きを全部取り上げると、ただ立っているだけになる。

4. 技を似せない作り方：動詞を4つの軸で分ける

調べたどのゲームも、大剣の戦士に「振る」以外の動詞を持たせている。技ごとに、下の4つの軸の少なくとも2つが、ほかの技と違うように並べる。

押し方タップ／溜めて離す／押しっぱなしで続く／押し直して続けるモンハン大剣の溜め、ランニングクラッシュ、ガンブレイカーの追撃
体の動きその場／一直線に突き抜ける／跳ぶ（上→下）／歩きながらブルラッシュ（Darktide）、スレイヤーの跳躍（Vermintide）、引き摺り

5. 脆くないが、タンクでもない：攻めると硬くなる

調べたゲームに共通する決まりは「殴っている間だけ生き残れる」。止まると硬さが消えるので、守りではなく攻めの手触りになる。

  • 獣を使うと障壁。デストロイヤーと同じ形で、獣1つにつき最大HPの数%（例：5% / 10% / 15%）。全力で吐くほど硬くなる。自己回復ではない。
  • 振っている間だけ被ダメ減。使う技の発生から最後の当たりまで、被ダメ−30%に加えて、敵の CC で止まらない（いまの抜け穴を塞ぐ）。
  • 突っ込むと硬さが戻る。Darktide のチャスティス（突進で守りが回復）と同じ考え方。轟進を押しっぱなしの走りにするなら、当てた数だけ障壁が少し戻る形が合う。
  • 暴れ続けると速くなる。ディアブロ4のバーサーキングと同じ。使う技を2体以上かボスに当てると、数秒だけ移動と振りが速くなる。続ければ切れない。

6. ビルドの幅：数字ではなく動詞を変える改造

  • いま、ウォーリアーの技の遊び方を変えるビルドは一つもない。パッシブツリー733個はすべて汎用の数字で、獣や戦士の技に触れる物はない。戦士専用の改造（余波）も範囲が上書きされて、威力が減るだけになっている。
  • 案：技ごとに2〜3個の「型」を用意する（デストロイヤーのトライポッド、ディアブロ4の強化の分岐と同じ）。型が変えるのは「どこに結果が出るか」「いつ出るか」「何が返ってくるか」のどれか。「威力+20%」の型は作らない。
    例：地割りに「長く走る（線が伸びる）」「短く深い（転倒）」。轟進に「群れの向こうまで抜ける」「最初の敵で止まって肩で崩す」。
  • 技どうしが変え合う形もある（PoE2：叫びの後の叩きつけに余震が付く）。技の数を増やさずに組み合わせが増える。
