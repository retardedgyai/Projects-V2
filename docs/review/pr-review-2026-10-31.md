## #189 メイジの作り直し（重い順に3つ）

1. **燃焼が5秒を超えると、消えた炎へ `teleport` して毎 tick 例外**（`CoreMageFire.kt:118`）。燃焼中の炎は SAFETY=100tick で自分を remove するが、火が当たり直すと `burning` が延びて `Burn` が死んだ Sprite を持ち続け、removed entity への `teleport` が `IllegalStateException` になる（Minestom の `Entity.remove` は instance を null にし、`teleport` はそこで投げる。javap で確認）。流星→火炎弾、反響の繰り返し、元素の極み（火）で起きる。起きると燃焼が切れるまで `CorePlayerCombat.tick` 全体が止まる。
2. **凍結でも同じ構造**（`CoreMageFrost.kt:132`、SAFETY=80tick）。冷えたボスに氷を当て直し、ボスが動いた tick に落ちる。
3. **全メイジが色付きの光の枠 6・7 を固定で使う**（`CoreMageLight.kt:66`）。`SakuraLight` は同じ枠の2つの光が互いを上書きするので、同じ戦場にメイジが2人いると光が飛び、点滅する（藍が嫌った点滅が多人数で再発）。

ほか：火属性MODの燃焼が mageLand の4秒燃焼を3秒に上書き（`hit()` 947行、差分外なので PR 全体のコメントに）、火炎弾の爆発に巻き込まれた敵は燃えず砕けもしない（mixing の中で mageLand が走らない）、弾かれた hit でも凍結・燃焼が付く、反響の再生が外した旧メッシュを出す、元素の極み（風）の射程1.5倍が FIELD 技の狙い点に効かない、死に分岐と spawn の三重化。
