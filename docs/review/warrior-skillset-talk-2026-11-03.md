# ウォーリアーの技の話し合い（2026-11-03、途中）

## 藍の感想
- 溜める技は「溜める以外に使い道がない」のがつまらない。
- 轟進と引き摺りは同じ（どちらも敵を運ぶ）。
- 跳び叩きは避けるのに使えて、避けながらダメージを出せたのが面白かった。ウォーリアーには普通に動ける技がない。
- 今のスキルセットは面白くない。使って楽しいのは狂乱くらい。
- 乗りは要らない。打ち上げからつなげる技はほしい。守る技も考える。

## 決まったこと
- 跳び叩き（溜める方の跳ぶ技）は残す。
- 引き摺りは消す（まだ消していない。作り直しでまとめて、セーブの移し替えと一緒に）。
- 天落とし（使う方の跳ぶ技）は未決。

## 分かったこと
- ボスは打ち上がらない（打ち上げは崩しに変わる）。つなぐ技は「浮いた雑魚」と「倒れたボス」の両方に効かせる。
- 狂乱だけが「押した瞬間から自分の手で斬り続ける」技。ほかは「止まって待つ→1回当たる→地面が割れる」の同じ形。
- 一人称で感じられるのは自分の振りの手応えとリズム。足元の割れは見えにくい。
- デストロイヤー寄せで「溜める」「踏ん張る」の止まる時間を増やしたのは、一人称では逆効果だった可能性。
- 一人称の近接ゲーム（Vermintide、Dark and Darker、Skyrim）は近接に技をほとんど持たせず、深さを武器の振りに入れている。
  例外は Wynncraft と、モンハンライズの鉄蟲糸技（振りの延長としての技、入れ替えでビルド）。
