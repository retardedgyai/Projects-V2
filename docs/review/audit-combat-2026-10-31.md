# 武器・職の技・待ち時間の突き合わせ

2026-10-31、main（`030c88a9`）の実装を、設計書（`docs/game/combat-principles.md`、`docs/game/mana-and-class-resources.md`、`docs/development/class-combat-rework.md`、`class-combat-formula-recovery.md`、`class-cd-rework.md`、`core-greatsword-v0.md`、`plain-weapons-v0.md`、`shade-wyrm-boss.md`）と、技のカタログに書いてある説明文（`CoreSkillCatalog.kt`）に突き合わせた。
スキルツリーの調査（回復力％・魔力％・防御％が効かない件）はこの前の調査で済んでいるので、ここでは繰り返さない。

数値は一時テスト（`CorePlayerCombatTest` と同じ土台で、T1・ボスHP300・防御0の実験場）で確かめた。テストはコミットしていない。「確かめ方」に書いた数値はそのテストの出力そのまま。

注意：メイジは PR #189（play/gyai/mage-rework）で技一式が作り直し中。ここで見たメイジは main の古い技で、#189 が入れば消える。

## 1. 直さないとまずい（効かない・逆効果）

7件。重い順。

### 1-1. 技の命中に渡した倍率が捨てられる：狂乱の最後の振り、天落としの外側の輪

- 場所：`CorePlayerCombat.kt:796`（`hit()` の `baseDamage = definition?.baseDamage(sheet) ?: (formula.evaluate(sheet) * multiplier + element)`）。技のときは `multiplier` を使わず、通常攻撃のときだけ使う。
- 影響：狂乱の最後の振り下ろし（`CorePlayerCombat.kt:661`、倍率2.0）が他の振りと同じ威力。天落としの外側の輪（`CorePlayerCombat.kt:977`、0.7）が内側と同じ全力。説明文「最後は真上から振り下ろす」の重さが出ない。
- 確かめ方：獣3で狂乱を撃つと5振りの減りが `33.6, 33.6, 33.6, 33.6, 33.6`（最後は67.2のはず）。天落としを5mの敵に当てると2つ目の輪だけ当たり、減りは74.9（0.7なら52.4）。
- 直し方の案：`hit()` の技の分岐でも `multiplier` を掛ける（`definition.baseDamage(sheet) * multiplier`）。属性の固定加算を倍率の外に置くかは要判断。

### 1-2. 斬り上げと引き摺りはボスの崩しゲージを削らない

- 場所：`CoreBreak.kt:16-17`。戦士の崩しの表に `war_breach`（斬り上げ）と `war_cry`（引き摺り）がなく、`WARRIOR[icon] ?: 0.0` で0になる。ボスには CC が効かず崩しだけが効く（`CorePlayerCombat.kt:869-872`）ので、この2つはボスに「ダメージだけ」。
- 確かめ方：ボスに斬り上げを当てるとHP 300→269.4、崩しゲージは100のまま。引き摺りも 300→268.4、ゲージ100。`CoreBreak.skill(WARRIOR, "war_breach") == 0.0`。
- 直し方の案：`CoreBreak.WARRIOR` に2つを足す（打ち上げ系の斬り上げは地割り寄りの値、引き摺りは轟進寄り）。ツールチップの「ボスの崩し」行も `breakPower > 0` のときだけ出るので、足せば表示も直る。

### 1-3. 黒翳竜の「光る溜めのカウンター」と「大詠唱・殻の間の崩し技」は、プレイヤーの技から届かない

- 場所：`CorePlayerCombat.kt:869-877`。ボスへの命中は `applyBreak(amount)` だけを呼び、`applyCrowdControl` は雑魚のときだけ呼ぶ。ところが竜側の2つの決まりは `breakBoss(..., cc = kind)` の `cc != null` 分岐（`QuestEncounterCombat.kt:463-466` カウンター、`474-486` 止める量）にあり、`applyBreak` 経由（`cc = null`）では通らない。
- 設計書：`shade-wyrm-boss.md:113`「その間に崩しの技（CCのある技）を当てると2.5秒倒れる」、`:117`「大詠唱/殻の間の崩し技が止める量に入る」、`combat-principles.md:118`「大詠唱・殻の間は1回で最大HPの2%（軽い崩しは0.8%）」。
- 確かめ方：`grep -rn "applyCrowdControl(" server-minestom/src/main` の呼び出し元は `CorePlayerCombat.kt:875,876`（雑魚の分岐の中）と `:985`（叩き落とし＝雑魚のみ）だけ。`ShadeWyrmBossTest.kt:575-578` は `applyCrowdControl` を直接呼んで確かめているので、テストは通るがプレイヤーの経路が存在しない。
- 直し方の案：`hit()` のボス分岐で、技に `crowd` があれば `applyBreak` の代わりに（または加えて）`applyCrowdControl(id, crowd, millis)` を呼び、`breakBoss` 側で CC の `breakDamage` と `CoreBreak` の量の二重取りを整理する。

### 1-4. 導脈大剣の「資源消費技の威力+12%」は誰にも効かない

- 場所：`CorePlayerCombat.kt:235`（`weaponBase() == CONDUIT && definition.spend > 0`）。導脈大剣は戦士専用（`CoreJourney.kt:45-46`）だが、戦士の技は全部 `spend = 0`（獣は「全部使う」方式。`CoreWarriorReworkTest` も `spend == 0` を保証している）。「通常命中で固有資源を追加4獲得」（`CoreJourney.kt:38`）も、戦士では獣+0.1（通常攻撃と同じ量、`CorePlayerCombat.kt:836`）。
- 確かめ方：導脈で獣0の地割り → 56.096（= 20 + 12×0.94×3.2。+12%なら62.8）。
- 直し方の案：導脈の特典を獣の仕組みで書き直す（例：獣を使う技の威力+12%、通常の獣+0.2）。説明文（`CoreJourney.kt:38`）も合わせる。

### 1-5. 余波の刻印石（aftershock）は地割り・天落とし・跳び叩きには「威力-15%」だけ

- 場所：`CoreSkillCatalog.kt:126-129` が半径+8v%・威力85%を付けるが、地割りの半径は獣の数で上書き（`CoreCombatFeel.kt:116-121`）、跳び叩きの着地は定数 `LANDING_RADIUS`（`CorePlayerCombat.kt:407-408`）、天落としの輪は定数 `SKYFALL_RINGS`（`:969-970`）。威力85%だけ残る。
- 確かめ方：余波4で装備中の地割りの半径は5.94と出るが、5.5mの敵に当たらない（HP300のまま）。3mでは 49.64（= 58.4×0.85）。跳び叩きも半径4.62と出て実際は3.5。
- 直し方の案：`shape()`・着地・輪の半径を「カタログ値に対する比」で広げる（例：`slam()` の4/6/8に `definition.radius / 4.5` を掛ける）か、余波の対象から3技を外して説明に書く。

### 1-6. 狂戦士（大成）の「獣2以上：威力+20%」は、獣を使う技には乗らない

- 場所：`CorePlayerCombat.kt:802`（命中時に `resource >= 2`）。獣を使う技は撃った瞬間に `takeStacks()` で0になる（`:246`）ので、地割り・狂乱・天落とし・大地崩し・全力の一振りの命中では常に外れる。+20%が乗るのは通常攻撃と溜める技だけ。被ダメ+10%（`:1151`）は獣を持っている間ずっと掛かるので、重い技ほど損。
- 確かめ方：狂戦士＋獣3の地割り → 110.376（= 58.4×1.08×1.75。+20%なら132.5）。
- 直し方の案：使う技は `skillAction.empowered >= 2`（撃った時の獣）で判定する。古い木は PR #190 で入れ替わる予定なので、新しいキーストーンを作るときの注意点として残すのでもよい。

### 1-7. 旗手（大成）と、ツリーの「固有資源の消費-15%」「奥義：固有資源の消費-20%」は戦士には何もしない

- 場所：旗手は `CorePlayerCombat.kt:701`（GUARD 動作のときだけ）だが、今の戦士に GUARD の技はない（根張りは外した）。消費-15%/-20%は `CoreSkillCatalog.kt:158,163` で `spend` を縮めるが、戦士の `spend` は全部0。
- 確かめ方：ノード1を取った戦士の装備技の `spend` は `[0,0,0,0,0]`。
- 直し方の案：PR #190 の新しい木で、戦士向けには「獣」を単位にした別の効果にする。旧木を消すまでは、戦士の技選び画面でこの3つに「戦士には効果なし」と出すだけでもよい。

## 2. 説明と違う

- **全力の一振り「担いで溜め（押している間、最大2秒）、離すと…」**（`CoreSkillCatalog.kt:195`）：長押しの仕組みはない（`skill()` は押した瞬間に発生10tickで確定）。確かめ方：`CorePlayerCombat.skill()` に押し続け・離すの状態がない。案：説明を「大きく構えてから一振り」に直すか、溜めを作る。
- **全力の一振りの半径12が、装備すると10.5になる**（`CoreSkillCatalog.kt:163` の `radius.coerceAtMost(10.5)` が余波の上限として全技に掛かる）。確かめ方：`equipped(...)[4].radius == 10.5`。案：上限は余波の分岐の中だけに掛ける。
- **ライフスティール「範囲攻撃は効率33%」**（`class-combat-formula-recovery.md:35`）：実装は近接職の全命中を33%にする（`CorePlayerCombat.kt:883` の `|| classId.melee`）。短剣の突きも一本の矢も関係なく、近接は常に1/3。確かめ方：吸命10%で12ダメージ → 回復0.396。案：`AREA` タグだけで判定する（通常攻撃の薙ぎは AREA を付ける）。
- **狙い射ち「同じ獲物を狙い続けるほど集中を得る」**（`CoreSkillCatalog.kt:210`）：技の獲得は一律15。獲物による増減は通常攻撃だけ（`CoreClassState.kt:48-54`）。案：技の命中にも `focusHits` を足す。
- **追影「離脱と同じ機会を消費」**（`:226`）：影抜け（離脱）は機会を使わない（`spend=0`、`:224`）。案：どちらかに揃える。
- **閃光歩・影抜けの減速**：ツールチップ「減速：敵の移動を40%低下」（`:63`）だが EVADE の減速は50%・2.5秒（`CorePlayerCombat.kt:693`）。案：数値を揃える。
- **援護突進「周囲の敵の狙いを自分に向ける」**（`:239`）：挑発は命中した敵だけ（`CorePlayerCombat.kt:845`）。踏み込みの扇に入らなかった敵は向かない。案：着地点の半径で `taunt` を回す。
- **重力の主「ボスには防御低下を付与」**（`CoreClassBuild.kt:80`）：吸引した敵全部に付く（`CorePlayerCombat.kt:713`）。実害はないが説明より強い。
- **狂乱3獣はボスの崩しを80削る**：崩しは1命中ごと（`breakAmount` が撃った時に決まり、5振りそれぞれに乗る。`CorePlayerCombat.kt:248`）。地割り3獣は24×1.5=36。確かめ方：獣3の狂乱後、ゲージ残り20。`class-cd-rework.md §3.9`「戦士ひとりで約15秒に1回」の見積もりより大きく速い。案：多段技は崩しを合計で持たせる（1振りごとは `breakAmount / pulses`）。
- **設計書の古い数値**：
  - 攻撃中の歩き：`combat-principles.md:111`「近接の通常攻撃中は0.6倍」、`class-cd-rework.md:134-138`「45%減/20%減/40%減」。実装は大剣0.8倍・短剣0.9倍・騎槍0.8倍（`CoreWeaponAttacks.kt:60,67,73`、10/24 藍の指示）。
  - 崩しの表 `class-cd-rework.md §3.9`：押し薙ぎ・地走り・根張り・鉄槌の旧名で、天落とし8・大地崩し12・斬り上げ・引き摺りがない。
  - 技能ポイント `class-combat-rework.md:40`「初期2、Lv8ごとに1追加、最大6」→ 実装は Lv4ごと・最大12（`CoreClassBuild.kt:48`）。
  - 戦士の表 `class-cd-rework.md §3`（闘気・叩きつけ・薙ぎ払い…）は10/23の獣方式で全部入れ替わっている。本文に「§3は旧名」とあるが、数値も違う。

## 3. 説明がない実装

- **武器の素の速さが物理技の発生を変える**：`CoreSkillCatalog.kt:31-32` は `(attackSpeed-1)*100` を渡すので、連撃大剣（1.18）は地割り12→11tick、重断大剣（0.88）は14tick、騎槍（0.85）は空間圧縮12→15tick、短剣（1.35）は断命4→3tick。武器の説明（`CoreJourney.kt:35-43`）に書いていない。**副作用**：回避で切れない「重い技」の線は発生12tick以上（`CorePlayerCombat.kt:482`、`HEAVY_STARTUP`）を短縮後の値で見るので、速い武器だと重い技が回避で切れるようになる。
- **弱点部位の判定が技の半径で変わる**：半径7超の技は「射撃」扱い（`CorePlayerCombat.kt:820`）。全力の一振り・天落とし・絶対零界・狩場の支配者は、頭の近くで撃っても「正面から」の判定になる。
- **戦士の奥義（狂戦士の甲冑・獣の目覚め）のツールチップに「獣：当たると1つ溜まる」が出る**（`CoreSkillCatalog.kt:50`）。どちらも何にも当たらない。
- **不落の聖域の防御姿勢は3秒**：`duration=180` でも構えは `min(duration, 60)`（`CorePlayerCombat.kt:734`）。説明「自分へ防御姿勢」に長さがない。
- **戦士の HUD 文字「根張り n秒」**（`CoreWarriorSkillPresentation.kt:28`）と、構えの読みの演出（`CorePlayerCombat.kt:1157-1162`）は、根張りを外したので届かないコード。
- **獣の獲得+20%（ツリーのノード3）で獣が小数になる**：`feedBeast` → `gain(1.0×1.2)`（`CorePlayerCombat.kt:1298`、`CoreClassState.kt:27-30`）。使う技は整数分だけ取る（`takeStacks`）ので実害は小さいが、HUD は `toInt()` で見せる。
- **氷の庭はメイジ専用の分岐が `CorePlayerCombat` に多数**（`:209-220, :376-394, :1261-1288`）。#189 で消えるなら一緒に消す。

## 4. 問題なしと確認した範囲

テストの数値、またはコードの一致で確認したもの。

- **計算式**（`CoreCombatMath.kt`）：AD/AP は `(武器+固定)×(1+%)`、杖・聖典だけ独立の AP、防御 `300/(300+防御)`、貫通の順（低下→割合→固定）、増加系は1層で加算、会心5%×(1+率)・上限75%・倍率1.5+加算・上限4倍、被ダメ軽減は防御の後で上限80%。元素の直撃加算は各値の65%（技・通常とも）。回復薬 `最大HP45%+回復力`。
- **武器の基礎値**（`CoreCombatMath.kt:57-58, 89`）：`12×1.65^(T-1)×種別倍率×装備Lv×(1+品質%)×(1+0.04×強化)`、攻撃速度 `種別×(1+(MOD%上限60+0.8×強化)/100)`、HP `(100+30(T-1))×…×(1+0.02×強化)`、防具4部位の重み 15/40/30/15。`CoreWeaponPresentation` の表示と `CoreCombatSheet` が一致（既存テスト）。強化+30の成功率・天井・費用は `core-enhancement-v0.md` と `CoreEnhancementCatalog` が一致。
- **武器の特殊効果**：連撃大剣の「回避後も連撃を保持」（`holdSequence`）と「三段目でマナ8回復」、重断大剣の「三段目は幅0.7m×3.05」、各職の連撃表（大剣150°×1.0/1.15/縦1.85、短剣0.8/1.0/1.0/1.4、騎槍1.0/1.1/1.5）は `class-cd-rework.md §3.12` と一致。騎槍は名前だけで中身は槌のまま（`plain-weapons-v0.md` に書いてある通り）。
