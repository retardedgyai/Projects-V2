# 斬撃の固定面・軌跡アニメーション

## 目的と変更

戦士・アサシンの斬撃が「PNGが回転しているだけ」に見える問題を修正する。ゲームの起動・操作・稼働中リソースパックの更新は行わない。

旧方式は画像コマの途中でも向きが変わり、モデル側の回転と遅延した二枚目の斬撃が重なっていた。新方式では既存の完成した斬撃テクスチャを変更せず、固定した面上で表示するUV領域を進める。切っ先から出現し、後尾から消える12コマを、通常方向・逆方向で生成する。

- 通常斬り・踏み込み斬り: 一つの固定軌跡。二重表示を撤去。
- 縦斬り: 上から下へ進む固定面。
- アサシンの切断・無明連刃: 短い二本の交差軌跡。無明連刃は実際の5回の命中に合わせて表示。
- 全周技: 四方向の短い固定軌跡を順に表示。画像そのものを公転させない。
- 刺突・毒などの専用演出は維持。ダメージ・命中回数・範囲・クールダウンは変更しない。

## 主なファイルと処理

`CoreSkillChoreography.parts` → `CoreSlashChoreography.parts` で攻撃の面・向き・寿命を決め、`CoreSlashChoreography.pose` が表示コマを選ぶ。`scripts/build_directional_slash_models.py` は既存テクスチャのUVを切り出す24モデルと、11パレット分の264アイテム定義を生成する。通常の `build_core_combat_models.py` からも呼ばれる。

絵が回る場合は `CoreSlashChoreography` の姿勢、表示されない場合は `combat_vfx/stroke` のアイテム・モデルとリソースパックの `index.txt` を最初に確認する。クライアントコード・共通Particle Frameworkは変更していない。

## 検証

- 対象Kotlinテスト96件成功（Choreography / CoreCombatMesh / CoreCombatAtlas）。
- UV領域の単調な出現・消失、左右反転を確認するPythonテスト2件成功。
- Vanilla 26.2の実際のCuboidModelパーサーで新規24モデルを受理。異常回転軸の負例は拒否。
- Vanilla 26.2のアトラス列挙で参照136スプライトを検出。標準ディレクトリのみの負例では検出されない。
- 実際の命中間隔を含むKotlin姿勢出力から、モデル・UV・色を使用して確認画像を描画。03 / 06 / 24コマを目視確認。
- ゲーム内のGPU表示・手触りは未検証。稼働中のサーバーとパックは変更していない。
