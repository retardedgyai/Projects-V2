# 魔術の芯（2026-10-17、藍と相談中）

藍「自分で考えたのに複雑すぎて分からない」から、魔術を削り直した。ゲームのコードはまだ変えていない。

## 決まったこと
- 芯は「見る・解く・抜く・混ぜる・作る」。
  - 見る：観測の眼鏡で物の相が分かる。初めて見る物は研究インクになる。
  - 解く：研究机の相パズル（Thaumcraft 4 の六角型）で混ぜ方を覚える。
  - 抜く：蒸留器で物から基本の6相（風・水・火・地・秩序・混沌）だけを抜いて瓶に溜める。
  - 混ぜる：光＝風＋火のような組み合わせの相は瓶で混ぜて作る（A案。物から直接抜くB案は不採用。理由は混ぜる複雑さと魔術をやっている感）。
  - 作る：魔術のレシピが普通の素材と一緒に相を材料として要求する。
- 相は売れる。他の道（鍛冶など）のレシピに相が入るのは中盤・後半から（序盤は魔術をやる人が少ないため）。
- 相パズルはしんどくしない：1件1〜2分の小さい盤面／研究インクは眼鏡で普通に見ていれば足りる／1件1回、覚えた組み合わせは自動で置ける／知っている組み合わせが増えるほど速く解ける／パズル嫌いは産物を買えば済む。
- 解いた報酬は両方：その混ぜ方とレシピが魔術書に載る＋研究ポイントが少し入る。ポイントは工房の便利さ（瓶の容量・蒸留・混ぜの手際など）だけに使い、混ぜ方そのものや戦闘の強さには使えない。
- 地脈・秩序と混沌の章・魔導工学・部品の Tier・枝分けは、芯が楽しくなるまで外す。
