# 強くなる道の見本（2026-10-19）

- `progression-loop.html` — 最初の1時間の絵地図／素材→精製→製作→強化→MOD→銘の一周（ボス部位の使い道 A/B/C を切り替え）／Tierの階段／要るUI。公開版 https://claude.ai/artifact/TRswEkSEBxbrbECaP4RtrJ

- `boss-parts-ideas.html` — ボス部位の使い道24案（☆で選ぶ）。公開版 https://claude.ai/artifact/MHHThbU2Cv3jDQnRhxJDrF
- `world-boss-items.html` — ワールドボス（桜牙獣）の落とし物10案とボスの種類ごとの分け方。公開版 https://claude.ai/artifact/AGdnYxFtKSGwVAEPdmQZwg
- `sakura-drops-flow.html` — 決まった5案をつなげた桜牙獣の素材の流れ。公開版 https://claude.ai/artifact/JAnJDvbPi75yH244C17jGu
- `offering-rewards.html` — 枝角を奉納した本人への見返り22案（☆で選ぶ）。
- `territory-ideas.html` — オープンワールドの領地の形12案（☆で選ぶ）。
- `territory-life.html` — Albion 型の領地の一生（宣戦布告・領地戦・維持費・荒れる）を動かす見本。
- `horn-gear-ideas.html` — 枝角を装備で使う14案（☆で選ぶ）。
- `unique-traits.html` — 装備の層と、桜牙の型・桜角の首飾りのユニーク特性を組む見本。
- `sakura-map.html` — 桜牙獣の素材の流れを1枚で見る全体図（いちばん新しい）。公開版 https://claude.ai/artifact/M1QDTSnWbrUuTmh6ZTbT2Q
- `shade-drops.html` — 黒翳竜（ダンジョンのボス）の素材の使い道4案を流れの絵で比べる。公開版 https://claude.ai/artifact/KUnemAXtSD9FLwPFNqVwm8
- `boss-gear-map.html` — 桜牙獣と黒翳竜を並べた、素材→器→特性→装備の図。
- `progression-map.html` — 強くなる道筋の地図（決まった／まだ）と、Tierの上がり方の比べ。公開版 https://claude.ai/artifact/EpYJyuU2uMjm39xuHTDPWe
- `tier-up-sinks.html` — Tierの上がり方とシンクの4案（丸ごと引き継ぎはなし）。
