# オープンワールド試作（2026-10-17、絵だけ・ゲーム未組み込み）

ランダム生成の遠征をやめてオープンワールドにする方向で、ゲームの外で描いた試作。
コードは `scripts/world_prototype/`、画像はこのフォルダ。

## 決まったこと（藍）

- 世界の形：港から街道が伸び、地域が数珠つなぎに並ぶ（Wynncraft／FF14 型）。大陸一枚型は不採用（`10-`）。
- 地形はプレイヤーに親切に：遊ぶ範囲はジャンプなしで歩ける傾斜、峠は道付き、高い山や崖は見るだけ。
- 建物は買わない。コードで建てる。見た目は Wynncraft 基準・派手め・生活感と道案内（色で行き先）。
- フィールドに店・宿・依頼・村は置かない（町でやること）。フィールドは採取と狩り。
- 狩り場は「普通のフィールドにモブが湧く場所がある」原始的な形。専用のファーム施設は作らない。

## 動かし方

作業フォルダで実行する（出力もそこに出る）。ブロックの絵は Minecraft 本体から取り出す（repo には入れない）：

```
mkdir tex && unzip -q -j ~/.minecraft/versions/26.2/26.2.jar 'assets/minecraft/textures/block/*.png' -d tex
python3 harbor2.py          # 港（harbor2.png）、guide.py で道筋入り
python3 spine.py            # 街道型の世界（spine-map.png、spine_*.npy）
python3 closeup2.py 0.16 0.62 160 out.png 6   # 世界の一部をブロックで描く
python3 zone2.py 5          # 羊飼いの原（spine_*.npy が要る）、zone2_guide.py / zone2_shots.py で案内図と拡大
```

`continent.py` / `closeup.py` は不採用の大陸案。
