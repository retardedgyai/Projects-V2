巨樹の根の丘

500×500 ブロックのフィールド1枚。高さの違う3段を道でつなぎ、ガウル平原風の岩の柱と桜のボスがある。今回は WorldPainter の地形の作り方を調べて、地面と崖のブロックを作り直した。

WorldPainter の作り方から取った決まり

  1. 地面の材料は傾きで決める。平地は草の混ぜ物、25〜45°は「丘」の混ぜ物（草・粗い土・石・安山岩・砂利＝3:3:3:2:1）、45°より急なら「岩」の混ぜ物（石65・安山岩10・丸石5.5・灰色の粉5・砂利4・土2・鉱石と苔石を少し）。
  2. 混ぜ物は1ブロックずつばらまかず、かたまり（ブロブ）で置く。境目だけ少しまだらにして、2つの地面がなじむようにする。
  3. 森の床は別の混ぜ物（ポドゾル・粗い土・草・苔）。水のそばは苔・草・泥。
  4. 崖は、上と外側に明るい石（石・安山岩）、真ん中につなぎの石（砂利・凝灰岩・丸石）、下とくぼみに暗い石（深層岩）。横じまにせず、縦の不規則なすじにする。苔は上のふちから水が伝うように縦に垂らす。
  5. 水辺は草を水ぎわまで残し、砂の帯を作らない。底は砂利と粘土。道は中央が踏み固めた土、縁ほど砂利と粗い土。
  6. 草花は全体に薄くまかず、草はかたまり、花は1種類ずつの群れ、森の中は羊歯。丘には苔むした小石を少し。
  7. （今回追加）自然の地形でまっすぐな線を7ブロック以上続けない。段の高さは1〜3ブロックを混ぜる。
  8. （今回追加）崖の足元には崩れ落ちた石の山（ガレ場）がある。砂利・丸石を下地に、ところどころ苔むした小岩。
  9. （今回追加）崖面の仕上げは苔・光る地衣類・つる・垂れ根。滝の下は上より荒らす（砂利の縁、苔石）。
  10. （今回追加）森の縁は段々に：草地 → 茂み → 若木 → 大木。木の下に落ち葉。

ボス周りで取った決まり

  1. 闘技場は広く平らで、中に引っかかる物を置かない。境目（段差・柵）がひと目で分かる。入口は1つ。
  2. 目印（御神木の大桜）は闘技場の外、入口の正面奥に置き、入った瞬間に見える。
  3. 鳥居は明神鳥居の形：石の台、朱の柱、柱の外まで出る貫、額、反り上がった笠木。石灯籠は台・竿・火袋・笠・宝珠。
  4. 和の色は朱・黒い瓦・白い石・桜色の4つにしぼり、床に模様（同心円と放射線）を入れる。
ボス闘技場の作り方 鳥居（笠木と貫） 鳥居の比率 注連縄 桜の闘技場の作品（Planet Minecraft）
