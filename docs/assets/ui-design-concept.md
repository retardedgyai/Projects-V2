# UI デザインコンセプト

決定：2026-10-10（開拓大陸の地図画面の作り直しで合意）

## 一言で

**Minecraft の素材 × 2026 年の MMO の UI。**

- 画面の組み立て・文字・余白・動きは、今のゲームの UI として作る。
- Minecraft らしさは飾りではなく素材で出す（ドット絵のアイコンとアイテム、等倍のブロック）。
- MMO らしさは情報の層で出す（イベントと時刻、推奨の強さ、報酬のレア度、仲間と自分の位置、表示の切り替え）。

## 今っぽさの原則

1. **飾りより文字と余白。** 大事さは文字の大きさと太さで決める。枠や飾りで目立たせない。
2. **平らな面。** パネルは単色の板。浮かせたカードより、画面の端に付けた板を基本にする。
3. **強調色は 1 つ。** 押すべきもの（主ボタン、今の選択）にだけ使う。ほかは白・灰の濃淡。
4. **区切りは細い線。** 1px の線と余白で区切る。箱で囲まない。
5. **地図や世界の上の文字は箱に入れない。** 文字と小さな影だけ。
6. **キーを添える。** 主な操作には対応するキー（Space、Esc など）を小さく表示する。
7. **動きは短く意味のあるものだけ。** 開く・選ぶ・出現の合図。常に揺れる飾りは使わない。

## Minecraft らしさ

- アイコン、アイテム、素材はドット絵。拡大は整数倍で、ぼかさない。
- 地図や世界の絵は、ブロックの縁が見える倍率で使う（縮小してにじませない）。
- 数字（個数、レベル、時刻）はドット書体（DotGothic16）。本文は M PLUS 2。
- 持ち物の枠など、Minecraft の部品の形は残してよい。ただし平らな色で描く。

## MMO らしさ

- **時刻のあるもの**を常に見せる：ワールドボスの出現、領地戦、期間限定。
- **強さの目安**を数字で見せる：推奨の強さと自分の強さ、敵のレベル帯。
- **報酬**はレア度の色で分ける。
- **自分と仲間の位置**、ギルドの領地の色を地図に出す。
- **表示の切り替え**（ボス、採集、領地など）で、情報が多くても散らからないようにする。

## やらないこと

- 金の角飾り、額縁のような枠、ゴシック装飾。
- 黒い札に入れたラベル、ピル型のチップの多用。
- 明朝体などの「ファンタジーっぽい」飾り書体。
- 色調整で全体をくすませること。

## 色と文字（目安）

| 用途 | 値 |
|---|---|
| 地の色（パネル） | `#0E1014` |
| 区切り線 | `#1D2026` |
| 本文 | `#F2F0EB` |
| 補足 | `#A8A39A`〜`#B4AFA6` / 見出しラベル `#8F8A82` |
| 強調色（主ボタン・選択） | `#F5C451` |
| ボス / 荒野 / 港・味方 | `#FF4D3D` / `#FF9A3D` / `#6EE28A` |
| レア度 | 普通 `#C8C4BC`・上質 `#6EE28A`・希少 `#5AA8FF`・英雄 `#B57BFF`・伝説 `#FF9A3D` |

文字：見出し M PLUS 2 ExtraBold、本文 M PLUS 2、数字 DotGothic16。

- **細い字は使わない。** 本文は Medium（500）以上、項目名は ExtraBold（800）、見出しラベルは Bold（700）。Regular（400）は暗い地では細く見えて読みにくい。
- **1080p で 13px 未満の文字は使わない。** 補足は 14px、見出しラベルは 13px が下限。
- **灰色を暗くしすぎない。** 補足 `#A8A39A`〜`#B4AFA6`、見出しラベル `#8F8A82` より暗くしない。
- 地図や世界の上の文字は Bold 以上で、小さな影を付ける。

## ゲーム内で作るときの制約

- **半透明の絵は使わない。** ゲームでは半透明の絵が、その奥にあるものを消してしまう。霞や影、ぼかしなど半透明の効果は、絵の側に焼き込んでから不透明な絵として出す。
- **文字は、用意した大きさのページだけを使う。** 用意のない大きさを指定すると、代わりの文字になって位置がずれる。
- 作り方の流れ：HTML で見本 → ヘッドレス Chrome で動かない部分を絵にする → 位置を測る → ゲームでは文字と動く部品だけを描く。
