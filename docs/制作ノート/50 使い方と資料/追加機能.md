# 追加機能

## 今は何も追加しなくてよい

最初はObsidianに最初から入っている機能だけで使える。

- 普通の文章
- ページ同士のリンク
- 検索
- テンプレート
- 毎日のメモ

## 後で困った時だけ考えるもの

- Dataview: 状態ごとの一覧を自動で作りたくなった時
- Tasks: 色々なページの未完了項目を1か所へ集めたくなった時

## 入れなくてよいもの

- 見た目を細かく変えるだけの追加機能
- グラフを整理するためだけの追加機能
- 複雑な看板やデータベース
- 目的のない自動化

2週間ほど普通に使い、「この手作業が面倒」と具体的に分かってから追加する。
