# Obsidianの使い方

## 最初の1回だけ

1. Obsidianを開く。
2. **Open folder as vault** を押す。
3. `C:\Users\xgaiz\Documents\Codex\Projects-V2\docs` を選ぶ。
4. `00 ここから.md` を開く。
5. 右上のメニューからピン留めする。

## 毎日

1. [[00 ここから|最初の画面]]を開く。
2. [[制作ノート/30 今/今日|今日]]を開く。
3. 「今日これが終わればOK」を1つ書く。

## 思いついた時

1. [[制作ノート/30 今/思いつき置き場/使い方|思いつき置き場]]を開く。
2. テンプレートから「思いつきメモ」を選ぶ。
3. 単語だけでもいいので書く。

## ChatGPTと一緒に仕様を作る時

1. 書いたメモをChatGPTに渡す。
2. 次のように頼む。

> 勝手に決定せず、分からない部分を質問して。この案をゲーム仕様にするために必要な項目を、簡単な日本語で整理して。

3. 出てきた内容を「システム仕様」か「コンテンツ仕様」へ入れる。
4. 自分で全部読む。
5. 合っていれば「仕様確定」にする。

## 何を使えばいいか分からない時

| 作りたいもの | 使うテンプレート |
| --- | --- |
| 雑な思いつき | 思いつきメモ |
| 戦闘、属性、装備などの仕組み | システム仕様 |
| ボス、町、クエスト、アイテムなど | コンテンツ仕様 |
| 選択肢から自分で決めた内容 | 決めたこと |
| その日の作業 | 毎日のメモ |

## やらなくていいこと

- プラグインを探し続ける
- 見た目やテーマを細かくいじる
- グラフをきれいに整理する
- 最初から完璧な文章を書く

分からなくなったら、`00 ここから.md`へ戻ればよい。
