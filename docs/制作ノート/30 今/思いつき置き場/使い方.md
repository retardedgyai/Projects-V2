# 思いつき置き場

ここは頭の中にあることを、とりあえず外へ出す場所。

## 書き方

1. 新しいメモを作る。
2. テンプレートから「思いつきメモ」を選ぶ。
3. 単語、箇条書き、意味の分からない断片でもいいので書く。

文章にしなくてよい。数字を決めなくてよい。作れるかどうかも考えなくてよい。

## 書いた後

- いらない → 消すか保管庫へ移す
- 後で考える → そのまま置く
- もっと考えたい → ChatGPTと一緒に詰める
- 作りたい → システム仕様かコンテンツ仕様へ育てる

> [!warning] ここは正式仕様ではない
> この中身をそのまま実装へ渡さない。自分で確認した仕様だけを実装する。
