# 今作っているもの

## 装備によって戦い方が変わる仕組み

現在は、同じ武器でも炎装備と氷装備で戦い方が変わるようにしている。

### 炎装備

`攻撃する → 炎が溜まる → 爆発する`

### 氷装備

`攻撃する → 冷気が溜まる → 凍る → 次の攻撃で砕く`

## 今回つなげているもの

- ダメージ計算
- 装備とMOD
- 実際の攻撃
- 炎と氷の状態
- ボスや敵への効果
