# 状態の意味

覚える必要はない。分からなくなった時だけこのページを見る。

## 仕様の状態

| 状態 | 簡単な意味 |
| --- | --- |
| アイデア | 思いついただけ |
| 考え中 | ChatGPTなどと内容を詰めている |
| 判断待ち | 自分が選ばないと先へ進めない |
| 要確認 | AIや昔の資料から作ったので、自分の確認が必要 |
| 仕様確定 | 自分で全部読み、これを作ると決めた |

## 実装の状態

| 状態 | 簡単な意味 |
| --- | --- |
| 未予定 | まだ作り始めない |
| 実装準備完了 | 作る内容と範囲が分かっている |
| 実装中 | コードや素材を作っている |
| 試遊確認中 | ゲーム内で触って確かめている |
| 完了 | 現在の仕様どおりに動いている |

仕様と実装は別物。

たとえば、仕様だけ完成していてコードがまだない場合はこうなる。

`仕様状態: 仕様確定`
`実装状態: 未予定`

## 「仕様確定」にしてよい条件

- [ ] 何を作るか分かる
- [ ] プレイヤーに何を感じてほしいか分かる
- [ ] ルールと必要な数字が分かる
- [ ] 失敗や特別な場合が分かる
- [ ] 他の仕様とのつながりが分かる
- [ ] 未決定が残っていない
- [ ] 自分で最初から最後まで読んだ

全部できたら、ページ上部を次のように変える。

`仕様状態: 仕様確定`
`確認した人: 本人`
`確認日: 日付`
