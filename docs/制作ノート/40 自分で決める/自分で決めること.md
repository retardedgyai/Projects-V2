# 自分で決めること

[[00 ここから|最初の画面へ戻る]]

## 今すぐ決めなくてよい

現在の実装が試せるようになるまでは、新しい属性やクラフト全体を決めなくてよい。

## 次に自分が確認すること

1. 炎装備と氷装備を実際に使う。
2. 説明を読まなくても、炎の爆発と氷の凍結・粉砕が分かるか確かめる。
3. 本当に別の装備構成として感じるか判断する。
4. その後、次に作るものを1つだけ選ぶ。

## 実装前に決める必要があるもの

| 重要度 | 決めること | 今の状態 |
| --- | --- | --- |
| 高い | 最初の討伐で死んだ時、復活・失敗・再挑戦をどうするか | 未決定 |
| 高い | ボス報酬から最初の装備更新までをどうつなぐか | 未決定 |
| 普通 | ツインブレードを正式採用するか、どんな武器にするか | 試作品だけある |
| 普通 | 共通スキルツリーと武器・クラス専用成長をどう分けるか | 方向だけある |

## 後で決めればよいもの

- 雷属性
- 必殺技の使い方
- 各クラス専用ゲージ
- 装備強化の細かい数字
- プレイヤー間取引や大規模経済
- オープンワールドやGvG
