# 氷属性

> [!warning] 自分の確認待ち
> 既存の実装課題から整理した候補。自分で確認するまでは正式仕様ではない。

## ひとことで

敵へ冷気を溜めて凍らせ、次の攻撃で砕く属性。

## プレイヤーが狙うこと

`攻撃して冷気を溜める → 敵が凍る → 次の攻撃で砕く`

## こう感じてほしい

- 敵が凍った瞬間に「次の一撃を当てたい」と思う。
- 砕いた一撃に手応えがある。
- 炎属性よりも、攻撃する順番を考える。

## こうはしたくない

- 凍らせた同じ攻撃で、勝手にすぐ砕ける。
- ボスを何度も凍らせて、何もできなくする。
- ただダメージが常に増えるだけ。

## ルール

- 敵ごとに冷気の溜まり具合を持つ。
- 冷気は「少し冷たい → かなり冷たい → 凍結」の順で進む。
- 敵を凍らせた攻撃では砕けない。
- 凍った後の次の有効な攻撃で砕ける。
- 1回凍らせるごとに、砕けるのは1回だけ。
- 砕いた後も冷気を40%残す。
- 凍っている敵への直接ダメージは1.08倍。

## 砕いた時の数字

- 砕く衝撃: 会心判定前の直接ダメージの1.25倍。
- 氷部分: 凍結を作った攻撃の氷ダメージの0.5倍。
- 砕く追加ダメージは会心にならず、1体だけに当たる。

## もう一度凍らせられない時間

| 敵の種類 | 時間 |
| --- | --- |
| 普通の敵 | 3秒 |
| 強い敵 | 4秒 |
| 中ボス | 5秒 |
| ボス | 8秒 |

この時間中も冷気は満タンまで溜められる。時間が終わった後、次の氷攻撃で凍る。

## 特別な場合

- 1回の攻撃で凍結と粉砕を同時に起こさない。
- 1回の凍結から何度も粉砕を起こさない。

## まだ決めていないこと

- 実際に遊んだ時、凍らせてから砕く狙いが自然に分かるか。
- ボスが凍っていることを、動きを止めずにどう見せるか。
