# 採取システム v0.1~

## 採取システム


## プレイヤーにどう感じてほしい？
基本的にはほかのコンテンツよりはコツコツしたもの、積み上げるもの。
市場や評判を見て、聞いた結果何が高いかとかを把握しながらその高い採取物を見つけた時に少しの喜びを感じながら採取してもらいたい。
また、すこしのRNGでレアな採取物、普段よりたくさんとれる採取のものがあったらうれしい
あと採取にもマスタリーがあってちゃんと積み上げていくもの。専門の人がいてほしい。
あと採取道具もなんか育てれたら面白そうだなとも思います
## 決めたこと

- 採取方法:長押し検知が可能な場合は左クリック長押しで採取物にカーソルを合わせて採取できる。
- マスタリー:その種類の採取物を採取すればそれに対応したマスタリーが上昇
- マスタリーが上昇した場合、対応した採取物の採取速度、採取量が増える
- 動物の死体から皮、木から木、岩から岩、鉱石から鉱物、草てきな奴から繊維
- すべて対応したツールがあります。死体ならナイフ、木なら斧、鉱石ならツルハシ、草なら鎌
- 生成マップで各採取物は生成される採取物の量を増やすことができたり、レアな採取物の生成率をあげたりすることができる。
- 採取の方法は大きな木や岩、対応する見た目のオブジェクトにエンティティをかぶせるかなにかして長押しで採取ができるようにして、採取をしたらそのオブジェクトが削除される、採取した時の崩れるパーティクルや演出があればいいかもしれない。
- また、レアな採取物のオブジェクトにはパーティクルを発生するように
- マスタリーの上昇値は比較的低め、幅を出すのはマスタリーツリーで、そこからとれる量や出てくる採取物の出現率やキーストーンみたいなのまで実装したい。用途によって基本的にツリーをとっていく。POEでいうアトラスツリーてきな。
